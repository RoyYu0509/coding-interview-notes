03 · Sliding Window

主线: window 的合法性对"缩小/扩大"是单调的 → left 永远不用回退 → 双指针各走 n 步, 把枚举所有 (left, right) 的 O(n²) 降成 O(n)。

概念链: Longest Substring Without Repeating (模板) → Max Consecutive Ones III (合法 = 违规数 ≤ k) → Longest Repeating Character Replacement (合法条件要算一下) → Permutation in String (固定长度) → Minimum Size Subarray Sum (求最短: 合法才缩) → Minimum Window Substring (need / missing) → Subarray Product Less Than K (计数) → Subarrays with K Different Integers (exactly K = atMost(K) - atMost(K-1))

0. 第一性原理: brute force 在浪费什么

连续 subarray / substring 的问题, brute force 都是: 枚举每个 (left, right), 检查 window 合不合法, 更新答案。枚举 O(n^2) 个 window, 每个检查 O(n), 合起来 O(n^2) ~ O(n^3) (检查用增量维护可以压到 O(n^2))。

浪费在哪: (left, right) 和 (left, right+1) 是两个高度重叠的 window, 却被当成两个独立的问题。更关键的是, 合法性有方向: 如果 [left..right] 已经不合法, 那 [left..right+1], [left..right+2] ... 一定也不合法 (window 越大越差)。这些格子 brute force 全都还要看一遍。

所以 left 的走法是: right 每扩一步, left 只可能不动或向右, 永远不回退。right 最多走 n 步, left 最多走 n 步, while 循环虽然嵌在 for 里面, 但所有 while 加起来最多 n 次 → 总共 O(n) (amortized)。

前提只有一条: 合法性单调。求最长时是"window 越大越容易不合法" (重复字符、0 太多、乘积太大); 求最短时是"window 越大越容易合法" (正数的和 ≥ target、覆盖了 t)。两种方向对应两个模板:

def window_longest(arr): left = 0 state = ... # window 内的统计量 (计数 / 和 / 积 ...) best = 0 for right, x in enumerate(arr): # right 只增不减 # 1. x 进 window: 更新 state while window 不合法: # 2. 不合法 -> 缩 left, 直到重新合法 # 把 arr[left] 移出 state left += 1 # left 也只增不减 best = max(best, right - left + 1) # 3. 此刻 window 合法, 更新答案 return best
def window_shortest(arr): left = 0 best = inf for right, x in enumerate(arr): # x 进 window while window 合法: # 合法了: 先记答案, 再尽量缩短 best = min(best, right - left + 1) # 把 arr[left] 移出 state left += 1 return best

三个固定动作: right 进 → 检查 → 动 left。每一题只是把"state 是什么"和"合法条件是什么"换掉。

记:sliding window = 合法性单调 + 两个只增不减的指针。最长: 不合法才缩, 缩完记答案。最短: 合法才缩, 缩之前记答案。反例: 数组里有负数时, 加一个数可能变好也可能变坏, 单调性消失, 要改用 prefix sum + Hash Table (见 04 · Prefix Sum)。

1. Longest Substring Without Repeating Characters: 最基础的模板题

题目: 给定字符串 s, 求不含重复字符的最长 substring 的长度。例: "pwwkew" → 3 ("wke")。

Brute force: 枚举所有 (left, right), 用 set 检查有没有重复, O(n^2) 个 window × O(n) 检查 = O(n^3)。浪费: 如果 s[left..right] 已经有重复, 把 right 再往右扩没有意义, 但它还是会被试一遍。

关键观察: 合法 = 没有重复, 而"window 变大 → 更容易有重复"。所以一旦 right 扩进来的 ch 让 window 重复了, 就只往右缩 left, 缩到 ch 不再重复为止。而且只有刚进来的 ch 可能重复, 因为进来之前 window 是合法的。

def length_of_longest_substring(s): cnt = defaultdict(int) # window 里每个字符出现几次 left = best = 0 for right, ch in enumerate(s): cnt[ch] += 1 # ch 进 window while cnt[ch] > 1: # 不合法: ch 重复 (进来之前合法, 所以只可能是 ch) cnt[s[left]] -= 1 # 最左边的字符出 window left += 1 best = max(best, right - left + 1) return best

Time O(n): right 走 n 步, left 最多走 n 步。Space O(Σ): cnt 最多存字符集大小那么多项 (ASCII 最多 128)。

记:最长 + 没有重复: cnt[ch] > 1 就缩 left。这是所有"最长"题的母版。

2. Max Consecutive Ones III: 合法条件换成"违规数 ≤ k"

题目: 0/1 数组 nums, 最多把 k 个 0 翻成 1, 求最长的连续 1 的长度。例: nums = [1,1,0,0,1,1,0], k = 2 → 6。

Brute force: 枚举 (left, right), 数 window 里 0 的个数, ≤ k 就合法, O(n^2)。浪费同上: 相邻 window 重叠, 数 0 的工作被重复做。

关键观察: "最多翻 k 个 0" 翻译成 "window 里 0 的个数 ≤ k"。相比上一题: state 从 Hash Table cnt 换成一个整数 zeros, while 条件从 cnt[ch] > 1 换成 zeros > k, 其余一行不变。

def longest_ones(nums, k): zeros = 0 # window 里 0 的个数 = 需要翻转的次数 left = best = 0 for right, x in enumerate(nums): if x == 0: zeros += 1 while zeros > k: # 不合法: 要翻的 0 超过预算 k if nums[left] == 0: zeros -= 1 left += 1 best = max(best, right - left + 1) return best

Time O(n), Space O(1)。

记:"最多 k 次修改 / 删除 / 翻转" → window 里违规元素的个数 ≤ k。同一个模板还能做 Longest Subarray of 1's After Deleting One Element (k = 1) 和 Fruit Into Baskets (种类数 ≤ 2)。

3. Longest Repeating Character Replacement: 合法条件需要推一步

题目: 字符串 s (大写字母), 最多替换 k 个字符, 求能得到的最长的"全是同一个字符"的 substring 长度。例: s = "AABABBA", k = 1 → 4。

Brute force: 枚举 (left, right), 统计 window 里出现最多的字符个数, O(n^2) 个 window。

关键观察: 一个 window 能变成全同字符, 最省的做法是保留出现最多的字符, 其余都替换。所以需替换数 = len - max_count, 合法 ⇔ len - max_count ≤ k。相比上一题, 违规数不再是单独维护的整数, 而是由 window 长度和 cnt 里的最大值算出来。

def character_replacement(s, k): cnt = defaultdict(int) left = best = 0 for right, ch in enumerate(s): cnt[ch] += 1 # window 长度 - 出现最多的字符数 = 需要替换的字符数 while (right - left + 1) - max(cnt.values()) > k: cnt[s[left]] -= 1 # 注意: 不 del, 值变 0 不影响 max left += 1 best = max(best, right - left + 1) return best

Time O(26 n) = O(n) (每次 max(cnt.values()) 最多 26 项), Space O(26)。

记:合法条件不一定是单个计数器: 可以是 len - max(cnt) 这种由 state 算出来的量, 只要它随 window 变大单调不降就能用同一个模板。

4. Permutation in String: 固定长度 window

题目: 判断 s2 里有没有 substring 是 s1 的 permutation。例: s1 = "ab", s2 = "eidbaoo" → True ("ba")。

Brute force: 对 s2 的每个长度 m 的 substring 排序后和 sorted(s1) 比较, O(n × m log m)。浪费: 相邻两个 window 只差头尾各一个字符, 却整个重排。

关键观察: permutation ⇔ 每个字母的个数相同, 且长度必须恰好 m。窗口长度固定, 所以不用 while 缩 left, 只需要每进一个就出一个 (if right >= m)。相比上一题: while 变成 if, 合法条件变成 win == need。

def check_inclusion(s1, s2): m = len(s1) need = [0] * 26 # s1 里每个字母要几个 win = [0] * 26 # 当前 window 里每个字母有几个 for ch in s1: need[ord(ch) - 97] += 1 for right, ch in enumerate(s2): win[ord(ch) - 97] += 1 # 右边进一个 if right >= m: # window 变成 m + 1 了 win[ord(s2[right - m]) - 97] -= 1 # 左边出一个 (left = right - m) if win == need: # 长度恒为 m 且计数相同 = permutation return True return False

Find All Anagrams in a String 是同一个模板, 唯一改动是不 return, 把起点收集起来:

def find_anagrams(s, p): m = len(p) need, win, res = [0] * 26, [0] * 26, [] for ch in p: need[ord(ch) - 97] += 1 for right, ch in enumerate(s): win[ord(ch) - 97] += 1 if right >= m: win[ord(s[right - m]) - 97] -= 1 if win == need: res.append(right - m + 1) # 唯一区别: 不 return, 记下起点 return res

Time O(26 n) (每步比较两个长度 26 的 list), Space O(26)。

记:固定长度 m: 进一个、出一个, window 大小恒定。同类: Maximum Average Subarray I, Maximum Points You Can Obtain from Cards (取反: 找长度 n-k 的最小和)。

5. Minimum Size Subarray Sum: 求最短, "合法才缩"

题目: 正整数数组 nums 和 target, 求和 ≥ target 的最短连续 subarray 的长度。例: target = 7, nums = [2,3,1,2,4,3] → 2 ([4,3])。

Brute force: 枚举 (left, right) 求和, O(n^2)。

关键观察: 全是正数 → window 越大和越大, 所以合法性方向反过来了: 越大越容易合法。right 扩到刚合法时, 当前 window 是一个候选, 再缩 left 只会让它更短, 所以"合法就缩", 缩一次记一次答案。相比前面: while 条件取反, 记答案挪到 while 里面。

def min_subarray_len(target, nums): total = 0 # window 里所有数相加 (nums 全是正数) left = 0 best = inf for right, x in enumerate(nums): total += x while total >= target: # 合法 (够大了): 先记答案, 再试着缩短 best = min(best, right - left + 1) total -= nums[left] left += 1 return 0 if best == inf else best

Time O(n), Space O(1)。(另有 prefix sum + 二分的 O(n log n) 解法, 这里不展开。)

记:求最短: while 合法: 记答案, 然后 left += 1。别把记答案放到 while 外面, 会漏掉连续缩两次的情况。

6. Minimum Window Substring: 最短 + 覆盖, 用 need / missing 做 O(1) 判断

题目: 字符串 s 和 t, 求 s 中包含 t 所有字符 (含重复次数) 的最短 substring。例: s = "ABAECBA", t = "ABC" → "CBA"。

Brute force: 枚举 (left, right), 用两个 Counter 比较, O(n^2 × |t|)。

关键观察: 和上一题同构 (越大越容易合法, 求最短), 难点只在"怎么 O(1) 判断 window 覆盖了 t"。用 need[c] 记还缺几个 c, 用 missing 记所有还缺的字符总数, missing == 0 就是合法。只有"缺的"字符进来才让 missing 减 1; 只有出去后变成"缺"的字符才让 missing 加 1。

def min_window(s, t): need = Counter(t) # >0: 还缺; =0: 刚好; <0: window 里多了 missing = len(t) # 还缺的字符总个数 (重复的字符按个数算) left = 0 best_len, best_start = inf, 0 for right, ch in enumerate(s): if need[ch] > 0: # ch 是"缺的", 才让 missing 减 1 missing -= 1 need[ch] -= 1 while missing == 0: # 合法: window 覆盖了 t if right - left + 1 < best_len: best_len, best_start = right - left + 1, left need[s[left]] += 1 # s[left] 出 window if need[s[left]] > 0: # 出去之后变成"缺"了 -> 不合法 missing += 1 left += 1 return "" if best_len == inf else s[best_start:best_start + best_len]

Time O(|s| + |t|), Space O(Σ)。

记:覆盖 / 包含类: need 做差额 + missing 做总缺口, 合法判断从 O(Σ) 降到 O(1)。

7. Subarray Product Less Than K: 计数, 一个 right 贡献一批答案

题目: 正整数数组 nums, 求乘积 < k 的连续 subarray 的个数。例: nums = [10,5,2,6], k = 100 → 8。

Brute force: 枚举起点, 往右乘到 ≥ k 为止, O(n^2)。

关键观察: 乘积随 window 变大单调递增 (正整数), 所以是"最长"型模板。但这次不是求最长, 而是求个数: 固定 right, 合法的 left 是连续的一段 left..right, 所以以 right 结尾的合法 subarray 恰好有 right - left + 1 个。相比前面: best = max(...) 换成 ans += right - left + 1。

def num_subarray_product_less_than_k(nums, k): if k <= 1: # 正整数的乘积 >= 1, 一个都不合法 return 0 prod = 1 # window 里所有数相乘 left = ans = 0 for right, x in enumerate(nums): prod *= x while prod >= k: # 不合法: 乘积太大 prod //= nums[left] left += 1 ans += right - left + 1 # 以 right 结尾的合法 subarray 数 (起点 left..right) return ans

Time O(n), Space O(1)。

记:求个数: 每个 subarray 只按右端点数一次, ans += right - left + 1。要求 "全是正数" 才单调。

8. Subarrays with K Different Integers: exactly K = atMost(K) - atMost(K-1)

题目: 整数数组 nums, 求恰好有 k 种不同整数的连续 subarray 个数。例: nums = [1,2,1,2,3], k = 2 → 7。

Brute force: 枚举 (left, right), 用 set 数种类, O(n^2)。

关键观察: "恰好 K 种" 不单调 (window 扩大种类可能多一, 缩小可能少一, 两个方向都会破坏), 模板用不了。但"最多 K 种"单调, 并且能用上一题的计数写法。而恰好 K = 最多 K - 最多 (K-1)。相比上一题: 写一个 at_most(k), 调用两次相减。

def subarrays_with_k_distinct(nums, k): def at_most(k): # 最多 k 种不同数字的 subarray 个数 cnt = defaultdict(int) left = total = 0 for right, x in enumerate(nums): cnt[x] += 1 while len(cnt) > k: # 不合法: 种类超过 k cnt[nums[left]] -= 1 if cnt[nums[left]] == 0: del cnt[nums[left]] # 必须 del: len(cnt) 就是种类数 left += 1 total += right - left + 1 # 以 right 结尾的合法 subarray 数 return total return at_most(k) - at_most(k - 1) # exactly k = (<= k) - (<= k-1)

Time O(n) (两次扫描), Space O(k)。

记:"恰好 K" 不单调 → 拆成 atMost(K) - atMost(K-1)。同类: Binary Subarrays With Sum, Count Number of Nice Subarrays。
