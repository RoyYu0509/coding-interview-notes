1. Spiral Matrix

题目在问什么

给一个 m × n 的矩阵, 按顺时针螺旋的顺序返回所有元素: 先往右走第一行, 再往下走最后一列, 再往左走最后一行, 再往上走第一列, 然后进入里面一圈, 重复。

看例子

Brute force

模拟一个人在走: 用一个 visited 矩阵记录走过的格子, 加一个方向 (右、下、左、上)。撞到边界或者走过的格子就右转。

Time O(m·n), 但多用了 O(m·n) 的 visited。浪费: 用一整张表去记一个其实很规则的集合。

Intuition: 还没走的部分永远是一个矩形

每走完一条边, 走过的都是最外面的一圈, 剩下没走的永远是一个矩形。一个矩形只要 4 个数就能描述: top、bottom、left、right。

所以不需要 visited: 走完上面一行, top 加 1; 走完右边一列, right 减 1; 走完下面一行, bottom 减 1; 走完左边一列, left 加 1。

一个细节: 走"下面一行"和"左边一列"之前, 要先检查矩形是否还存在 (top ≤ bottom、left ≤ right)。比如只剩一行时, 走完上面那一行就没有了, 不能再往回走一遍。

算法

  1. top, bottom, left, right = 0, m-1, 0, n-1。
  2. 当 top ≤ bottom and left ≤ right: 往右走 top 行, top += 1; 往下走 right 列, right -= 1;
  3. 如果 top ≤ bottom: 往左走 bottom 行, bottom -= 1; 如果 left ≤ right: 往上走 left 列, left += 1。

手动走一遍

复杂度

Time O(m·n), 额外 Space O(1)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def spiralOrder(matrix): res = [] top, bottom = 0, len(matrix) - 1 left, right = 0, len(matrix[0]) - 1 while top <= bottom and left <= right: # 区域还没缩没 for c in range(left, right + 1): # 1. 走上边 → res.append(matrix[top][c]) top += 1 # 上边用完, 上边界下移 for r in range(top, bottom + 1): # 2. 走右边 ↓ res.append(matrix[r][right]) right -= 1 if top <= bottom: # 守卫: 只剩 1 行时不能再倒着走 for c in range(right, left - 1, -1): # 3. 走下边 ← res.append(matrix[bottom][c]) bottom -= 1 if left <= right: # 守卫: 只剩 1 列时不能再往上走 for r in range(bottom, top - 1, -1): # 4. 走左边 ↑ res.append(matrix[r][left]) left += 1 return res

记:矩阵按圈走: 4 个边界变量代替 visited, 走完一条边收缩一个边界。

2. Rotate Image

题目在问什么

把一个 n × n 的矩阵顺时针旋转 90 度, 必须原地修改。

看例子

Brute force

开一个新矩阵, 把每个元素放到旋转后的位置, 再复制回来。O(n²) 额外空间。

Intuition: 先写出坐标怎么变, 再拆成两个简单的操作

看例子: 原来在 (i, j) 的元素, 旋转后到了 (j, n-1-i)。比如 1 在 (0, 0), 转到了 (0, 2)。

直接按这个公式原地挪很难写 (要四个一组地转圈)。但这个变换可以拆成两步, 每一步都很容易原地做:

  1. transpose (沿主对角线翻转): (i, j) → (j, i)。交换 m[i][j] 和 m[j][i] (只对 j > i 做)。
  2. 每一行左右反转: (j, i) → (j, n-1-i)。

两步合起来就是 (i, j) → (j, n-1-i), 正好是顺时针旋转。逆时针的话, 先 transpose 再上下反转 (或者先反转每一行再 transpose)。

算法

  1. i 从 0 到 n-1, j 从 i+1 到 n-1: 交换 m[i][j] 和 m[j][i]。
  2. 每一行 row.reverse()。

手动走一遍

复杂度

Time O(n²), Space O(1)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def rotate(matrix): # 顺时针 90 度, 原地 n = len(matrix) for i in range(n): # 第 1 步: transpose, (i, j) → (j, i) for j in range(i + 1, n): # 只走上三角, 每一对只换一次 matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j] # 第 2 步: 每行 reverse, (j, i) → (j, n-1-i) for row in matrix: row.reverse()

记:矩阵旋转: 先写出坐标变换, 再拆成 transpose + 反转。

3. Set Matrix Zeroes

题目在问什么

如果矩阵里某个格子是 0, 就把它所在的整行和整列都变成 0。原地修改, 最好只用 O(1) 额外空间。

看例子

难点: 一边扫一边改, 新变成的 0 会被误以为是原来的 0, 又去清别的行列。

Brute force

先扫一遍, 用两个 set 记下哪些行、哪些列有 0; 再扫一遍, 把这些行列清零。Time O(m·n), Space O(m + n)。

Intuition: 用矩阵自己的第一行、第一列当标记

brute force 里的两个 set, 其实就是"每一行一个标记"和"每一列一个标记"。矩阵的第一列正好每行有一个格子, 第一行正好每列有一个格子。所以可以把标记直接写在第一行和第一列上: 如果 (i, j) 是 0, 就把 m[i][0] 和 m[0][j] 设为 0。

但第一行和第一列自己也可能原本有 0。所以先用两个变量 row0、col0 记下第一行、第一列原本有没有 0。

处理顺序: 先根据标记清掉内部 (第 1 行以后、第 1 列以后) 的格子, 最后再根据 row0 和 col0 处理第一行和第一列。如果先改第一行, 标记就被破坏了。

算法

  1. 记下 row0 = 第一行有没有 0, col0 = 第一列有没有 0。
  2. 扫内部的格子: (i, j) 是 0 就 m[i][0] = m[0][j] = 0。
  3. 再扫内部: m[i][0] == 0 or m[0][j] == 0 就把 (i, j) 设为 0。
  4. 最后按 row0、col0 清第一行、第一列。

手动走一遍

复杂度

Time O(m·n), Space O(1)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def setZeroes(matrix): m, n = len(matrix), len(matrix[0]) # 第一行 / 第一列要拿来当 flag, 先记住它们自己原本有没有 0 row0 = any(matrix[0][j] == 0 for j in range(n)) col0 = any(matrix[i][0] == 0 for i in range(m)) for i in range(1, m): # pass 1: 扫内部, 遇到 0 就留言 for j in range(1, n): if matrix[i][j] == 0: matrix[i][0] = 0 # 留言: 第 i 行要清零 matrix[0][j] = 0 # 留言: 第 j 列要清零 for i in range(1, m): # pass 2: 内部按留言清零 for j in range(1, n): # (留言区这时不能动, 还要读) if matrix[i][0] == 0 or matrix[0][j] == 0: matrix[i][j] = 0 if row0: # 最后才处理留言区本身 for j in range(n): matrix[0][j] = 0 if col0: for i in range(m): matrix[i][0] = 0

记:要 O(1) 空间的标记: 借输入的一部分 (第一行 / 第一列) 来存, 注意处理顺序, 别提前破坏标记。

4. Pow(x, n)

题目在问什么

实现 x 的 n 次方。n 可以是负数, 也可以非常大 (到 2³¹)。

看例子

Brute force

把 x 乘 n 次, O(n)。n = 2³¹ 时要 20 亿次乘法, 太慢。

Intuition: 把 n 拆成二进制

观察: x¹⁰ = x⁸ · x², 因为 10 的二进制是 1010 (= 8 + 2)。而 x², x⁴, x⁸ 可以不断平方得到: x → x² → x⁴ → x⁸, 每次只要一次乘法。

所以: 从 n 的最低位开始看, 同时维护当前的 x^(2^k)。这一位是 1, 就把它乘进结果; 然后 x 平方, n 右移一位。n 有 log n 位, 所以只要 O(log n) 次乘法。

负数次方: 先算 x^|n|, 再取倒数。

算法

  1. n < 0 时: x = 1/x, n = -n。
  2. res = 1。当 n > 0: 如果 n & 1, res *= x。然后 x *= x, n >>= 1。
  3. 返回 res。

手动走一遍

复杂度

Time O(log n), Space O(1)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def myPow(x, n): if n < 0: # x^(-n) = (1/x)^n x, n = 1 / x, -n res = 1.0 while n: # 每轮处理 n 的一个 bit, 共 log2(n) 轮 # 这一位是 1 → 乘上当前的 x (= 原 x 的 2^k 次方) if n & 1: res *= x x *= x # x 平方: x^1 → x^2 → x^4 → x^8 ... n >>= 1 # 看下一位 return res

记:n 很大的重复操作 (幂、矩阵幂): 按 n 的二进制拆, 不断平方, O(log n)。

5. Palindrome Number

题目在问什么

判断一个整数是不是回文 (正着读和反着读一样)。不转成字符串。

看例子

Brute force

str(x) == str(x)[::-1]。可以, 但题目要求不转字符串。

Intuition: 用 % 10 和 // 10 拆数字, 只反转一半

处理整数的每一位, 只需要两个操作: x % 10 拿到最后一位, x // 10 去掉最后一位。

把 x 的后半部分反转出来: 每次从 x 末尾拿一位, 接到 rev 后面 (rev = rev * 10 + x % 10), x 去掉这一位。当 rev ≥ x 时, 说明已经处理了一半。

然后比较: 偶数位时 x == rev; 奇数位时中间那一位跑到了 rev 末尾, 比较 x == rev // 10。

只反转一半还有一个好处: 不会溢出。特殊情况先排除: 负数不是回文; 末尾是 0 的 (除了 0 本身) 也不是。

算法

  1. x < 0 或者 (x % 10 == 0 且 x != 0), 返回 False。
  2. rev = 0。当 x > rev: rev = rev * 10 + x % 10, x //= 10。
  3. 返回 x == rev or x == rev // 10。

手动走一遍

复杂度

Time O(位数), Space O(1)。Reverse Integer 用同样的 % 10 / // 10, 只是要注意溢出。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def isPalindrome(x): if x < 0 or (x % 10 == 0 and x != 0): # 负数不是; 末位 0 反过来有前导 0 return False rev = 0 while x > rev: # 只反转后半: rev 追上 x 就停 rev = rev * 10 + x % 10 # x % 10 取末位, 接到 rev 末尾 x //= 10 # x // 10 丢掉末位 # 偶数位: x == rev; 奇数位: rev 多一位中间数 return x == rev or x == rev // 10

记:处理整数的每一位: % 10 取末位, // 10 去末位。

6. Single Number → Missing Number

题目在问什么

Single Number: 数组里每个数都出现两次, 只有一个数出现一次, 找出它。Missing Number: 数组里有 n 个不同的数, 取自 0..n, 少了一个, 找出它。都要求 O(n) 时间、O(1) 空间。

看例子

Brute force

用 Counter 或 set (01), O(n) 时间但 O(n) 空间。

Intuition: XOR 让成对的数互相抵消

XOR (异或, Python 里是 ^) 有三个性质: a ^ a = 0 (自己和自己抵消); a ^ 0 = a; 而且顺序无所谓 (满足交换律和结合律)。

所以把所有数 XOR 起来, 出现两次的都抵消成 0, 只剩下出现一次的那个。

Missing Number 也能这样做: 把"应该有的" 0..n 和"实际有的"数组里的数全部 XOR 在一起。每个出现了的数都出现两次 (一次在 0..n 里, 一次在数组里), 抵消掉; 缺的那个只出现一次, 留了下来。代码里用下标 i 代替 0..n-1, 再补上 n。

算法

  1. Single Number: res = 0, 对每个 x: res ^= x。
  2. Missing Number: res = n, 对每个 i: res ^= i ^ nums[i]。

手动走一遍

复杂度

Time O(n), Space O(1)。Missing Number 也可以用求和公式: n(n+1)/2 - sum(nums)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def singleNumber(nums): res = 0 for x in nums: res ^= x # a^a = 0, a^0 = a, 顺序无所谓 → 成对的全部抵消 return resdef missingNumber(nums): # nums 是 0..n 少一个数, 长度 n res = len(nums) # 下标只有 0..n-1, 先把 n 放进来 for i, x in enumerate(nums): res ^= i ^ x # 下标 i 和值 x 各一次, 没缺的数都出现两次 return res

记:成对出现、找落单的: XOR 全部, 成对的抵消。

7. Number of 1 Bits

题目在问什么

给一个正整数, 返回它的二进制表示里有几个 1。

看例子

Brute force

一位一位看: n & 1 是最低位, 然后 n >>= 1。要看所有 32 位。

Intuition: n & (n - 1) 每次正好消掉最低位的 1

看 n - 1 的二进制: 它是把 n 最低位的那个 1 变成 0, 并把它右边的 0 全变成 1。比如 n = 1100, n - 1 = 1011。

所以 n & (n - 1) = 1000: 最低位的 1 被消掉了, 其他位不变。

每做一次消掉一个 1, 做到 n 变成 0 为止, 做了几次就有几个 1。只需要循环"1 的个数"次, 不用看所有 32 位。

相关的技巧: n & -n 取出最低位的那个 1; n > 0 and n & (n - 1) == 0 判断 n 是不是 2 的幂 (只有一个 1)。

算法

  1. count = 0。当 n: n &= n - 1, count += 1。
  2. 返回 count。

手动走一遍

复杂度

Time O(1 的个数), Space O(1)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def hammingWeight(n): cnt = 0 while n: n &= n - 1 # 消掉最低位的 1: 每个 1 恰好被消一次 cnt += 1 return cnt

记:n & (n - 1) 消掉最低位的 1; n & -n 取出最低位的 1。

8. Minimum Absolute Difference (以及排序的用法)

题目在问什么

数组里的数互不相同。找出所有差的绝对值最小的 pair, 按从小到大的顺序输出。

看例子

Brute force

两两比较算差, O(n²)。

Intuition: 排好序之后, 差最小的一定是相邻的

排序后, 对任意 i < j < k, 有 a[k] - a[i] ≥ a[j] - a[i]。也就是说, 隔着别的数的 pair, 差一定不会比相邻的更小。所以只需要看相邻的 n - 1 对。

这是一个很通用的思路: 排序当预处理。排完序之后很多问题都只需要看相邻的元素, 比如区间合并 (10)、Meeting Rooms (10)、去重、找最接近的两个数。排序本身 O(n log n), 往往比 brute force 的 O(n²) 快很多。

自定义排序: 用 key= (比如 sort(key=lambda x: (x[1], -x[0])) 按第二个元素升序、第一个降序); 需要"两两比较"的规则时用 functools.cmp_to_key (比如 16 里的 Largest Number)。

什么时候不用通用排序: 只要第 k 个用 quickselect 或 heap (09); 值的范围很小用 counting sort; 值分布均匀用 bucket sort。

算法

  1. 排序。
  2. 算所有相邻的差, 找最小值。
  3. 再扫一遍, 收集差等于最小值的相邻 pair。

手动走一遍

复杂度

Time O(n log n), Space O(n) (排序)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def minimumAbsDifference(arr): arr.sort() # O(n log n): 预处理 best, res = float("inf"), [] for a, b in zip(arr, arr[1:]): # 只看相邻: n - 1 对 diff = b - a if diff < best: # 更小: 重置 best, res = diff, [[a, b]] elif diff == best: # 一样小: 追加 res.append([a, b]) return res
from functools import cmp_to_keydef largestNumber(nums): strs = [str(x) for x in nums] # a 排前面当且仅当 a+b > b+a (拼起来更大); 返回负数 = a 排前 strs.sort(key=cmp_to_key(lambda a, b: -1 if a + b > b + a else 1)) ans = "".join(strs) return "0" if ans[0] == "0" else ans

记:"最近 / 最小差 / 重叠 / 去重": 先排序, 之后只看相邻的。

9. Roman to Integer

题目在问什么

把罗马数字转成整数。I=1, V=5, X=10, L=50, C=100, D=500, M=1000。一般大的在左、小的在右, 加起来; 但如果小的写在大的左边, 表示相减, 比如 IV = 4, IX = 9, CM = 900。

看例子

Brute force

列出所有的减法组合 (IV、IX、XL、XC、CD、CM), 先匹配两个字符, 匹配不上再按一个字符算。可以做, 但规则写起来比较多。

Intuition: 只看右边那个字符

规则可以简化成一句: 一个字符如果比它右边的字符小, 就减去它; 否则加上它。最后一个字符没有右边, 一定是加。

算法

  1. 建一个 dict 存 7 个字符的值。
  2. 从左往右: 如果当前值 < 右边的值, total -= 当前值; 否则 total += 当前值。

手动走一遍

复杂度

Time O(n), Space O(1)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def romanToInt(s): val = {"I": 1, "V": 5, "X": 10, "L": 50, "C": 100, "D": 500, "M": 1000} total = 0 for i, ch in enumerate(s): if i + 1 < len(s) and val[ch] < val[s[i + 1]]: # 左小右大 → 减 total -= val[ch] else: total += val[ch] return total

记:查表 + 看相邻: 规则如果只取决于相邻两个元素, 扫一遍时看一眼右边。

10. 识别信号: 看到什么, 就想到什么

题目特征做法complexity
矩阵按圈 / 螺旋遍历4 个边界变量, 走完一条边收缩空间 O(m·n) → O(1)
