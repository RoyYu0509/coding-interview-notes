06 · Stack

这篇讲什么

Stack (栈) 是一种只能从顶上放、从顶上拿的容器: 最后放进去的, 最先拿出来 (LIFO, last in first out)。Python 里用 list 就行: append 是放, pop() 是拿, stack[-1] 是看栈顶。都是 O(1)。

什么时候想到 stack? 当你从左往右扫的时候, 需要记住"最近的、还没处理完的东西", 而且后来的要先处理。最典型的就是嵌套结构: 括号、嵌套的字符串、表达式里的括号、目录的进入和退出。它们都是"最里面的先结束"。

不用 stack 的 brute force, 通常是每遇到一个"结束"的东西, 就往回扫去找它对应的"开始", O(n²)。stack 让"往回找"变成看一眼栈顶, O(1)。

1. Valid Parentheses

题目在问什么

字符串里只有 ( ) [ ] { } 六种字符。判断它是不是合法的: 每个开括号都要被同类型的闭括号关上, 而且后开的必须先关。

看例子

Example 3 说明, 只数个数是不够的, 顺序也要对。

Brute force

每遇到一个闭括号, 就往左扫, 找离它最近的、还没配对的开括号, 检查类型是否一致。每次往左扫 O(n), 共 O(n²)。

浪费在哪: 每次都从头往左扫, 但其实我们每次要找的都是"最近的还没配对的开括号"。

Intuition: 把还没配对的开括号放进 stack

从左往右扫, 把还没配对的开括号按顺序放进 stack。那么 stack 顶上的, 就是最近的、还没配对的开括号, 正是我们要找的。

遇到闭括号, 看一眼栈顶: 类型对上, 就 pop 掉 (这一对配好了); 对不上或者栈是空的, 就不合法。

为什么是 stack? 因为括号的规则是"后开的先关", 和 stack "后放的先拿" 完全一样。

算法

  1. stack = [], 准备一个 dict: 闭括号 → 对应的开括号。
  2. 遇到开括号: push。
  3. 遇到闭括号: 栈空, 或者栈顶不是对应的开括号, 返回 False; 否则 pop。
  4. 扫完后, 栈必须是空的 (没有多出来的开括号)。

手动走一遍

复杂度

Time O(n): 每个字符最多 push 一次、pop 一次。Space O(n)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def is_valid(s): pair = {')': '(', ']': '[', '}': '{'} # invariant: 从底到顶 = 还没闭合的开括号, 栈顶是最内层的 stack = [] for ch in s: # 闭括号: 只能和"最近一个没闭合的开括号"配对 if ch in pair: # 栈空 = 多余的闭括号; pop 出来不对 = 交叉 if not stack or stack.pop() != pair[ch]: return False else: # 开括号: 先存着, 等后面的闭括号来找它 stack.append(ch) return not stack # 结尾栈非空 = 有开括号一直没被闭合

记:嵌套结构 / 括号配对: 还没处理完的放进 stack, 栈顶就是最近的那个。

把第 1 题抽象一下: 什么时候用 stack

第 1 题的结构是: 从左往右扫, 每个"开始"先存起来, 等到对应的"结束"出现时再处理, 而且最近开始的最先结束。

后面的题都是这个结构, 区别在于 stack 里存什么:

  • 存元素本身 (第 1、4、7、9 题)
  • 存元素 + 额外信息, 比如当时的最小值、连续个数 (第 2、8 题)
  • 存"进入括号之前的状态", 出括号时恢复 (第 3、6 题)
对比: 往左扫找配对 (brute force) 和 用 stack
# O(n^2): 每个 ')' 都往左扫, 找最近的、还没被用掉的 '('def match_brute(s): used, pairs = set(), [] for j, ch in enumerate(s): if ch == ')': # 往左扫 —— 每个 ')' 都重扫一遍 for i in range(j - 1, -1, -1): if s[i] == '(' and i not in used: used.add(i) pairs.append((i, j)) break return pairs# O(n): 栈 = "往左扫会依次碰到的候选", 已经按"最近优先"排好def match_stack(s): stack, pairs = [], [] for j, ch in enumerate(s): if ch == '(': # 还没被匹配的 '(' 入栈, 栈顶 = 最近的 stack.append(j) elif ch == ')' and stack: # pop = 最近的、没被用掉的 '(' , O(1), 不用扫 pairs.append((stack.pop(), j)) return pairs

记:看到"最近的、还没处理完的"或者嵌套结构, 就想 stack。关键是想清楚 stack 里存什么。

2. Min Stack

题目在问什么

设计一个 stack, 支持 push、pop、top, 再加一个 getMin: 返回当前栈里最小的数。每个操作都要 O(1)。

看例子

Brute force

getMin 时把栈扫一遍, O(n)。不满足要求。

另一个想法: 用一个变量 cur_min 记最小值, push 时更新。但 pop 掉的恰好是最小值时, 不知道新的最小值是谁, 还是要扫一遍。

Intuition: 每个元素记住"它放进来的时候, 栈里的最小值"

关键观察: stack 只能从顶上拿。所以当某个元素在栈顶时, 它下面的元素和它被放进来那一刻完全一样。

那么在 push 的时候, 就把"包括我在内, 当前栈里的最小值"和元素一起存进去: (val, min_so_far)。之后任何时候, 栈顶的 min_so_far 就是整个栈的最小值。pop 掉以后, 新的栈顶自带它那一刻的最小值, 也是对的。

算法

  1. push(x): 新的最小值 = min(x, 栈顶的 min) (栈空时就是 x)。push (x, 新的最小值)。
  2. pop(): 直接 pop。
  3. top(): 返回栈顶的 val。
  4. getMin(): 返回栈顶的 min。

手动走一遍

复杂度

每个操作 Time O(1)。Space O(n)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
class MinStack: def __init__(self): # 每个元素 (val, min_so_far): min_so_far = 从栈底到它自己的最小值 self.stack = [] def push(self, val): # 只看下面的元素, 写入后永不改变 cur_min = min(val, self.stack[-1][1]) if self.stack else val self.stack.append((val, cur_min)) def pop(self): # min_so_far 跟着元素一起走; 新栈顶的 min_so_far 本来就是对的 self.stack.pop() def top(self): return self.stack[-1][0] def get_min(self): return self.stack[-1][1] # O(1): 不用扫整个栈

记:stack 的每个元素可以带额外信息。因为栈顶下面的部分不会变, "放进来那一刻的信息"一直有效。

3. Decode String

题目在问什么

编码规则是 k[s]: 把 s 重复 k 次。可以嵌套, 比如 3[a2[c]]。把字符串完全展开。

看例子

Example 2 说明, 嵌套时必须先展开里面的, 再展开外面的。

Brute force

反复找最里面的一对 [ ] (里面没有别的括号), 展开它, 拼回字符串, 再找下一个。每次查找和拼接都是 O(长度), 嵌套多时很慢。

Intuition: 进括号前把"外面的状态"存起来

从左往右读。用 cur 记当前这一层已经拼出来的字符串, k 记刚读到的数字。

遇到 [: 要进入新的一层了。但外面这一层还没完, 它的 cur 和 k 要先存起来, 进去以后才能回来接着拼。于是 push (cur, k), 然后 cur 清空, 开始拼里面这一层。

遇到 ]: 里面这一层拼完了。pop 出外面的 (prev, k), 把里面的 cur 重复 k 次接到 prev 后面, 这就是外面这一层新的 cur。

和第 1 题一样: 最后进入的一层最先结束, 所以用 stack。

算法

  1. cur = "", k = 0, stack = []。
  2. 数字: k = k * 10 + 数字 (数字可能有好几位)。
  3. [: push (cur, k), 然后 cur = "", k = 0。
  4. ]: prev, times = stack.pop(), cur = prev + cur * times。
  5. 字母: cur += 字母。最后返回 cur。

手动走一遍

复杂度

Time O(n + 输出长度)。Space O(n + 输出长度)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def decode_string(s): # 每层存 (prev_str, k): 进入 '[' 之前外层拼好的字符串, 和这个 '[' 的重复次 # 数 stack = [] # cur = 当前这层 [] 里已经拼出的字符串; num = 正在读的数字 cur, num = "", 0 for ch in s: if ch.isdigit(): num = num * 10 + int(ch) # 多位数 "12[a]" elif ch == '[': stack.append((cur, num)) # 保存外层现场 cur, num = "", 0 # 进入内层: 从空字符串重新拼 elif ch == ']': prev_str, k = stack.pop() # 回到外层 # 内层拼好的 cur 重复 k 次, 接在外层字符串后面 cur = prev_str + cur * k else: cur += ch return cur

记:嵌套结构: 进入新的一层前, 把当前层的状态 push; 离开时 pop 回来, 合并结果。

4. Evaluate Reverse Polish Notation

题目在问什么

RPN (逆波兰表达式) 把运算符写在两个操作数后面: 2 1 + 就是 2 + 1。给一个 token 列表, 算出结果。除法向 0 取整。

看例子

Brute force

反复找第一个运算符, 用它前面两个数算出结果, 替换回列表。每次替换 O(n), 共 O(n²)。

Intuition

读到运算符时, 它要用的两个操作数, 恰好是最近算出来的两个数。所以把数都放进 stack: 读到数就 push; 读到运算符就 pop 两个, 算完 push 回去。

注意顺序: 先 pop 出来的是右边的操作数 b, 后 pop 的是左边的 a。减法和除法要算 a - b、a / b。

算法

  1. 数字: push。
  2. 运算符: b = pop(), a = pop(), push a op b。除法用 int(a / b) 向 0 取整。
  3. 最后栈里只剩一个数, 就是结果。

手动走一遍

复杂度

Time O(n), Space O(n)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def eval_rpn(tokens): # invariant: 栈里 = 已经算出来的操作数, 栈顶是最近算出的 stack = [] for t in tokens: # 运算符: 它的两个操作数一定是栈顶两个 if t in ("+", "-", "*", "/"): b = stack.pop() # 先 pop 出来的是右操作数 a = stack.pop() # 再 pop 出来的是左操作数 if t == "+": stack.append(a + b) # 顺序: a - b, 不是 b - a elif t == "-": stack.append(a - b) elif t == "*": stack.append(a * b) # 向 0 取整; 不能用 // (负数会向下取整) else: stack.append(int(a / b)) else: stack.append(int(t)) # 数字: 先存着, 等运算符来取 return stack[0]

记:后缀表达式: 数 push, 运算符 pop 两个算完 push 回去。先 pop 的是右操作数。

5. Basic Calculator II

题目在问什么

字符串里有非负整数、+ - * / 和空格, 没有括号。按正常优先级 (先乘除、后加减) 算出结果。除法向 0 取整。

看例子

Brute force

先扫一遍把所有 * / 算掉, 再扫一遍算 + -。或者反复找优先级最高的运算符替换。

Intuition: 加减先存着, 乘除马上算

难点是优先级: 读到 3 + 2 时不能马上加, 因为后面可能是 * 2。

换个角度看: 整个表达式其实是若干"项"相加, 每一项是由 * / 连起来的。比如 3 + 5*2 - 6/3 = 3 + (5*2) + (-6/3)。

所以用一个 stack 存每一项:

  • 一个数前面是 +: push 这个数 (新的一项)。
  • 前面是 -: push 它的相反数 (把减法当成加一个负数)。
  • 前面是 * 或 /: 它属于上一项, pop 出栈顶, 乘或除完再 push 回去。

最后把 stack 里所有项加起来。

算法

  1. num = 0, op = '+' (第一个数前面假装有个 +)。
  2. 读到数字就拼进 num。读到运算符 (或者到了字符串末尾) 时, 按上一个运算符 op 处理 num: + push, - push 负数, * / 和栈顶合并。然后 op 换成当前的运算符, num 清零。
  3. 返回 sum(stack)。

手动走一遍

复杂度

Time O(n), Space O(n) (可以只用一个变量记最后一项, 降到 O(1))。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def calculate(s): # op = num 前面的运算符; 要等 num 读完 (遇到下一个运算符) 才能处理它 stack, num, op = [], 0, '+' for i, ch in enumerate(s): if ch.isdigit(): num = num * 10 + int(ch) # 读到下一个运算符 (或到结尾): 处理 "op num" if ch in '+-*/' or i == len(s) - 1: # + - 先记成带符号的项, 后面可能有 * / 抢先 if op == '+': stack.append(num) elif op == '-': stack.append(-num) # * / 立即和栈顶那一项合并 elif op == '*': stack.append(stack.pop() * num) else: stack.append(int(stack.pop() / num)) op, num = ch, 0 return sum(stack) # 栈里全是 "项", 最后一次性相加

记:有优先级的表达式: 加减的项先 push, 乘除马上和栈顶合并, 最后求和。

6. Basic Calculator

题目在问什么

字符串里有非负整数、+ -、括号和空格 (没有 * /)。算出结果。括号可以嵌套, 括号前面可以是负号。

看例子

Brute force

反复找最里面的一对括号, 算出里面的值, 替换回去。O(n²)。

Intuition: 和第 3 题一样, 进括号前存状态

没有括号时很简单: 用 result 记到目前为止的结果, sign 记下一个数前面是 + 还是 -, 读到数就 result += sign * num。

加上括号: 遇到 ( 时, 括号里是一个独立的小表达式, 要先算。外面的 result 和括号前的 sign 要存起来。于是 push (result, sign), 然后 result 清零, 开始算括号里面。

遇到 ): 括号里算完了, 值是 result。pop 出外面的 (prev_result, prev_sign), 合并: result = prev_result + prev_sign * result。

这和第 3 题 Decode String 是同一个结构: 进入一层前存状态, 出来时取回状态并合并。

算法

  1. result = 0, sign = 1, num = 0。
  2. 数字: 拼进 num。+ / -: 先 result += sign * num, num 清零, 再设 sign = 1 或 -1。
  3. (: push (result, sign), 然后 result = 0, sign = 1。
  4. ): 先把 num 加进 result, 然后 pop 出 (prev, s), result = prev + s * result。
  5. 最后 result += sign * num。

手动走一遍

复杂度

Time O(n), Space O(括号深度)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def calculate(s): stack = [] # result = 当前括号层已累加的值; sign = num 前面的符号 (+1 / -1) result, num, sign = 0, 0, 1 for ch in s: if ch.isdigit(): num = num * 10 + int(ch) elif ch in '+-': result += sign * num # 把刚读完的 num 并进 result num, sign = 0, (1 if ch == '+' else -1) elif ch == '(': # 保存外层: 外层累加到哪了, 以及 '(' 前面的符号 stack.append((result, sign)) result, sign = 0, 1 # 括号内部从 0 重新算 elif ch == ')': result += sign * num # 先把括号内最后一个 num 并进来 num = 0 prev_result, prev_sign = stack.pop() # 整个括号当成一个数, 乘上 '(' 前面的符号 result = prev_result + prev_sign * result return result + sign * num

记:表达式里的括号: ( 时 push (result, sign) 并清零, ) 时 pop 合并。和 Decode String 是同一个套路。

7. Asteroid Collision

题目在问什么

一排小行星, 每个用一个整数表示: 绝对值是大小, 正数向右飞, 负数向左飞。两颗迎面相撞时, 小的爆炸; 一样大就一起爆炸。同方向的永远不会撞。求最后剩下的小行星。

看例子

只有"左边的向右飞、右边的向左飞"才会相撞。Example 3 里一颗向左飞的可以连续撞掉好几颗。

Brute force

反复扫整个数组, 找相邻的一对 (正, 负), 让它们相撞, 直到没有可以撞的。每轮 O(n), 最多 n 轮, O(n²)。

Intuition: 新来的只会和"最近的幸存者"相撞

从左往右处理。已经处理过的、目前还活着的小行星放在 stack 里。一颗新的小行星来了:

  • 如果它向右飞, 或者栈顶向左飞, 不会撞, 直接 push。
  • 如果它向左飞, 而栈顶向右飞, 会撞。比较大小: 栈顶小, 栈顶爆炸 (pop), 新的继续和下一个栈顶撞; 一样大, 都爆炸; 新的小, 新的爆炸。

为什么只看栈顶? 因为新来的向左飞, 第一个碰到的一定是它左边最近的那个幸存者, 也就是栈顶。

算法

  1. 对每颗 a: 当 a < 0 且栈顶 > 0: 比较 -a 和栈顶。
  2. 栈顶小: pop, 继续比较 (while 循环)。一样大: pop, a 也没了, 停。栈顶大: a 没了, 停。
  3. a 还活着, push。

手动走一遍

复杂度

Time O(n): 每颗最多 push 一次、pop 一次。Space O(n)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def asteroid_collision(asteroids): # invariant: 栈里没有会相撞的一对 (栈顶向右 + 下一个向左) stack = [] for a in asteroids: alive = True # 只有 "栈顶向右 + 新来的向左" 才会撞 while alive and a < 0 and stack and stack[-1] > 0: # 栈顶更小: 栈顶炸掉, 新来的继续去撞下一个 if stack[-1] < -a: stack.pop() elif stack[-1] == -a: # 一样大: 同归于尽 stack.pop() alive = False else: # 栈顶更大: 新来的炸掉 alive = False if alive: stack.append(a) return stack

记:新元素和"最近的幸存者"反复抵消: 用 stack, while 循环和栈顶比, 能消就 pop。

8. Remove All Adjacent Duplicates in String II

题目在问什么

给一个字符串 s 和整数 k。只要有 k 个相同的字符连在一起, 就把它们删掉, 左右两边接上。接上之后可能又凑出 k 个, 继续删, 直到删不动为止。

看例子

Brute force

反复扫字符串, 找连续 k 个相同的, 删掉, 重新扫。每次 O(n), 最多删 n/k 次, O(n²/k)。

Intuition: stack 里存 (字符, 连续个数)

从左往右, 用 stack 记录"目前还留着的字符串"。但如果 stack 只存字符, 每次都要往回数有几个相同的。

所以存 [字符, 连续个数]: 新来的字符和栈顶字符一样, 就把栈顶的个数加 1; 不一样, push [字符, 1]。个数到了 k, 就把这一项整个 pop 掉。

pop 之后, 下面那一项自动成了栈顶。如果后面来的字符和它一样, 就会继续累加, 这正好对应"删完两边接上"。

算法

  1. 对每个字符 c: 栈顶字符是 c, 个数加 1; 否则 push [c, 1]。
  2. 栈顶个数 == k: pop。
  3. 最后把每项的 字符 × 个数 拼起来。

手动走一遍

复杂度

Time O(n), Space O(n)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def remove_duplicates(s, k): # 每个元素 [char, count]: 栈顶这一段 char 已经连续出现 count 次 stack = [] for ch in s: if stack and stack[-1][0] == ch: # 和栈顶同字符: 这一段变长 (不用回头数) stack[-1][1] += 1 # 凑够 k 个: 整段删掉, 它下面的段自然变成相邻 if stack[-1][1] == k: stack.pop() else: stack.append([ch, 1]) return "".join(c * n for c, n in stack)

记:连续相同的元素要整段处理: stack 里存 (值, 连续个数)。

9. Simplify Path

题目在问什么

给一个 Unix 风格的绝对路径, 化简它: . 表示当前目录 (不动), .. 表示回到上一级, 连续的 / 当成一个。结果以 / 开头, 末尾没有 /。

看例子

Brute force

反复用字符串替换去掉 /./、//、/xxx/../。规则多, 容易漏, 而且每次替换 O(n)。

Intuition: stack 就是"当前所在的目录链"

先用 split('/') 把路径切成一段一段。然后想象自己在走目录: 进入一个目录就 push 它的名字; .. 就是退回上一级, pop; . 和空字符串 (连续 / 切出来的) 不动。

走完之后, stack 从底到顶就是最终所在的目录。用 '/' + '/'.join(stack) 拼起来。

算法

  1. for part in path.split('/'):
  2. part == '..': 栈不空就 pop。part 是空串或 '.': 跳过。其他: push。
  3. 返回 '/' + '/'.join(stack)。

手动走一遍

复杂度

Time O(n), Space O(n)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def simplify_path(path): # invariant: 栈 = 当前目录从根到现在的每一层名字 stack = [] for part in path.split('/'): # "//" 会切出空串 '' if part == '..': if stack: stack.pop() # 回上一层; 已经在根 '/' 就忽略 elif part and part != '.': # '' 和 '.' 什么都不做; 其余是目录名 stack.append(part) return '/' + '/'.join(stack)

记:进入 / 退出、前进 / 撤销 (目录、浏览器历史、undo): 用 stack。
