06 · Stack

主线: stack = "最近的、还没被匹配/处理完的东西"。后进先出 (LIFO) 正好对应嵌套结构 —— 括号、表达式、子字符串、路径、碰撞 —— 遇到 '开' 就把现场 push, 遇到 '关' 就 pop 回来, 用 O(1) 取代 '往回扫'。

概念链: 括号匹配 → Min Stack (元素带额外状态) → Decode String (push 外层上下文) → RPN (栈里存操作数) → Basic Calculator II (延迟 + -, 立即 * /) → Basic Calculator (括号 = push result 和 sign) → Asteroid Collision (碰撞抵消) → Remove Duplicates II (存 (char, count)) → Simplify Path。Monotonic stack 单独在 07。

0. 第一性原理:brute force 在浪费什么,stack 怎么消掉

先问一个最小的问题:s 里每个 ')' 该和哪个 '(' 配对?规则只有一句 —— 左边最近的、还没被配对过的 '('。

brute force:每个 ')' 都从自己的位置往左扫,跳过已经用掉的,找到第一个可用的 '('。一次扫描 O(n),n 个 ')',共 O(n²)。浪费的是:左边哪些 '(' 还没被用掉,这份信息每次都重新扫一遍才知道,而这个集合其实只在两种时刻变化 —— 读到 '(' 时加一个,读到 ')' 时拿走最近的那个。

stack 把这份信息一直维护着:栈里存的就是 "往左扫会依次碰到的候选",而且已经按 "最近优先" 排好,栈顶就是最近的。读到 ')' 直接 pop,O(1)。后开的先关(LIFO),所以嵌套结构(括号、表达式、递归调用)天然是 stack。

# O(n^2): 每个 ')' 都往左扫, 找最近的、还没被用掉的 '('def match_brute(s): used, pairs = set(), [] for j, ch in enumerate(s): if ch == ')': # 往左扫 —— 每个 ')' 都重扫一遍 for i in range(j - 1, -1, -1): if s[i] == '(' and i not in used: used.add(i) pairs.append((i, j)) break return pairs# O(n): 栈 = "往左扫会依次碰到的候选", 已经按"最近优先"排好def match_stack(s): stack, pairs = [], [] for j, ch in enumerate(s): if ch == '(': stack.append(j) # 还没被匹配的 '(' 入栈, 栈顶 = 最近的 elif ch == ')' and stack: # pop = 最近的、没被用掉的 '(' , O(1), 不用扫 pairs.append((stack.pop(), j)) return pairs# 通用模板 —— 三种形状, 后面每道题都是其中一种:# 1) 开/关配对: 开 → push 现场; 关 → pop 回来配# (Valid Parentheses, Decode String, Calculator, Simplify Path)# 2) 操作数/运算符: 操作数 → push; 运算符 → pop 几个, 算完 push 回去# (RPN, Calculator II)# 3) 新元素 vs 栈顶: while 冲突/抵消: pop; 然后 push 新元素# (Asteroid, Remove Duplicates)# 变体: push 的不是单个值而是 (val, extra) 元组# (Min Stack, Remove Duplicates II, Decode String)

时间:每个元素最多 push 一次、pop 一次,所以不管 while 套多深,总共 O(n)。空间:栈最深 O(n)。

记:看到 "最近的、还没处理完的"、"嵌套"、"撤销上一步" → 想 stack。它把 "往回扫" 的 O(n) 换成 pop 的 O(1)。

1. Valid Parentheses:栈顶 = 最内层没闭合的开括号

题目:字符串只含 ()[]{},判断括号是否正确闭合、嵌套。例:"{[()]}" → True,"([)]" → False。

Brute force:反复 s.replace("()", "")(以及 []、{})直到不再变化,看是否剩空串。每轮扫 O(n),最多 n/2 轮,O(n²)。浪费:每次删完又从头扫,而每次能被删掉的,一定是 最内层、紧挨着的一对 —— 那正是 "最近没配对的开括号"。

关键观察:读到闭括号时,能和它配的只有 "最近一个没闭合的开括号"。如果它不配,后面再也没机会修正(交叉了)。所以 push 开括号,闭括号时和栈顶比。

def is_valid(s): pair = {')': '(', ']': '[', '}': '{'} # invariant: 从底到顶 = 还没闭合的开括号, 栈顶是最内层的 stack = [] for ch in s: # 闭括号: 只能和"最近一个没闭合的开括号"配对 if ch in pair: # 栈空 = 多余的闭括号; pop 出来不对 = 交叉 if not stack or stack.pop() != pair[ch]: return False else: stack.append(ch) # 开括号: 先存着, 等后面的闭括号来找它 return not stack # 结尾栈非空 = 有开括号一直没被闭合

时间 O(n):每个字符 push / pop 最多一次。空间 O(n):全是开括号时栈里有 n 个。

记:栈空时来闭括号 → False;结尾栈非空 → False;pop 出来不配 → False。三个 False 出口,一个 True 出口 (not stack)。

2. Min Stack:每个元素带额外状态 (val, min_so_far)

题目:设计一个 stack,支持 push / pop / top / get_min,全部 O(1)。例:push 5, 3, 7 后 get_min = 3;pop 两次后 get_min = 5。

Brute force:get_min() 里 min(self.stack),O(n)。想到只存一个 min 变量,但 pop 掉最小值后,不知道新的最小值是谁,还得重扫 O(n)。浪费(丢掉的信息):"栈只有这么高时的最小值" 每次 pop 都丢了,下次要再算。

关键观察:栈里每个元素下面的东西在它存在期间都不会变。所以 "从栈底到它的最小值" 在 push 时算一次,就永远对。把它和元素一起存成 (val, min_so_far)。这是 stack 的第一个变体:push 的不是单个值,而是值加额外状态。

class MinStack: def __init__(self): # 每个元素 (val, min_so_far): min_so_far = 从栈底到它自己的最小值 self.stack = [] def push(self, val): # 只看下面的元素, 写入后永不改变 cur_min = min(val, self.stack[-1][1]) if self.stack else val self.stack.append((val, cur_min)) def pop(self): # min_so_far 跟着元素一起走; 新栈顶的 min_so_far 本来就是对的 self.stack.pop() def top(self): return self.stack[-1][0] def get_min(self): return self.stack[-1][1] # O(1): 不用扫整个栈

时间:四个操作都 O(1)。空间 O(n):每个元素多存一个 int。(另一种写法:再开一个 min 栈,只在 val <= 当前 min 时 push,省空间,但核心思想一样。)

记:"O(1) 取某个聚合量(min/max)且支持撤销" → 栈元素带 (val, 聚合量),聚合量只依赖下面的元素。

3. Decode String:遇到 '[' push 外层上下文,遇到 ']' pop 回来

题目:k[encoded] 表示 encoded 重复 k 次,可以嵌套。例:"3[a2[c]]" → "accaccacc"。

Brute force:反复用正则找最内层 \d+\[[a-z]*\] 展开替换,直到没有括号。每轮扫整个字符串,嵌套 d 层就是 d 轮,O(n·d) 再加上字符串反复重建。浪费:"最内层" 其实就是 "最近开的、还没关的 '['" —— 和括号匹配同一个问题。

关键观察:进入 [ 时,外层有两件事被暂停了:外层已经拼好的字符串 prev_str,和这个括号的重复次数 k。把它们作为一个现场 push 进栈,内层从空字符串开始拼。读到 ],pop 现场,把内层结果接回去:cur = prev_str + cur * k。这是 stack 的第二个变体:栈里存的是被暂停的外层上下文。

def decode_string(s): # 每层存 (prev_str, k): 进入 '[' 之前外层拼好的字符串, 和这个 '[' 的重复次数 stack = [] # cur = 当前这层 [] 里已经拼出的字符串; num = 正在读的数字 cur, num = "", 0 for ch in s: if ch.isdigit(): num = num * 10 + int(ch) # 多位数 "12[a]" elif ch == '[': stack.append((cur, num)) # 保存外层现场 cur, num = "", 0 # 进入内层: 从空字符串重新拼 elif ch == ']': prev_str, k = stack.pop() # 回到外层 # 内层拼好的 cur 重复 k 次, 接在外层字符串后面 cur = prev_str + cur * k else: cur += ch return cur

时间:每个字符处理一次,加上每个 ] 构造一次新字符串,长度之和约为输出长度 (嵌套层数不多时看作 O(输出长度))。空间:栈深 = 嵌套层数,加上 cur。

记:"嵌套结构 + 内层先算完" → '开' 时 push 外层现场并清零,'关' 时 pop 并把内层结果合并回去。

4. Evaluate Reverse Polish Notation:栈里存已经算好的操作数

题目:后缀表达式求值。例:["4","13","5","/","+","2","*"] = (4 + 13/5) × 2 = 12。

Brute force:在 tokens 里反复找第一个运算符,把它和前面两个数替换成结果(list 切片),O(n²)。浪费:每次要找 "第一个运算符",而它前面的两个操作数就是 "左边最近算好的两个数"。

关键观察:后缀式里,运算符出现时,它的两个操作数就是左边最近的两个值 —— 栈顶两个。所以数字 push,运算符 pop 两次算完再 push 回去,栈里始终是 "已算好、等待被消耗" 的值。注意顺序:先 pop 的是右操作数 b,后 pop 的是左操作数 a,减法和除法写 a - b、a / b。

def eval_rpn(tokens): # invariant: 栈里 = 已经算出来的操作数, 栈顶是最近算出的 stack = [] for t in tokens: if t in ("+", "-", "*", "/"): # 运算符: 它的两个操作数一定是栈顶两个 b = stack.pop() # 先 pop 出来的是右操作数 a = stack.pop() # 再 pop 出来的是左操作数 if t == "+": stack.append(a + b) # 顺序: a - b, 不是 b - a elif t == "-": stack.append(a - b) elif t == "*": stack.append(a * b) # 向 0 取整; 不能用 // (负数会向下取整) else: stack.append(int(a / b)) else: stack.append(int(t)) # 数字: 先存着, 等运算符来取 return stack[0]

时间 O(n):每个 token 处理一次。空间 O(n):最坏全是数字在栈里。

记:表达式求值的最小模板: 操作数栈。pop 顺序 b 先 a 后; 除法用 int(a / b) 向 0 取整。

5. Basic Calculator II:延迟处理 + -,立即处理 * /

题目:字符串里只有非负整数和 + - * /(无括号,整数除向 0 取整),求值。例:"3+5*2-6/3" = 3 + 10 - 2 = 11。

Brute force:两遍扫描,第一遍把所有 * / 算掉并重建表达式,第二遍从左到右算 + -;或者反复找优先级最高的运算符替换,O(n²)。浪费:优先级信息是 "晚到" 的 —— 读到 - 时,不知道后面是不是 *。

关键观察:整个表达式是若干 项 (term) 的和,项与项之间只有 + -。* / 只在项内部起作用。所以:读到 + - 时只把这一项 带符号 push(延迟,等项算完);读到 * / 时,左操作数正好是栈顶那一项,立即和它合并。最后 sum(stack)。技巧:变量 op 记着 "num 前面的运算符",等读到下一个运算符(或结尾)才处理 op num。

def calculate(s): # op = num 前面的运算符; 要等 num 读完 (遇到下一个运算符) 才能处理它 stack, num, op = [], 0, '+' for i, ch in enumerate(s): if ch.isdigit(): num = num * 10 + int(ch) # 读到下一个运算符 (或到结尾): 处理 "op num" if ch in '+-*/' or i == len(s) - 1: # + - 先记成带符号的项, 后面可能有 * / 抢先 if op == '+': stack.append(num) elif op == '-': stack.append(-num) # * / 立即和栈顶那一项合并 elif op == '*': stack.append(stack.pop() * num) else: stack.append(int(stack.pop() / num)) op, num = ch, 0 return sum(stack) # 栈里全是 "项", 最后一次性相加

时间 O(n):每个字符一次,每项 push / pop 常数次。空间 O(n):项的个数。(因为只关心最后一项,也可以用 last 变量代替栈做到 O(1) 空间,但栈版本是下一题的基础。)

记:延迟处理: 优先级低的 (+ -) 先存起来; 立即处理: 优先级高的 (* /) 马上和栈顶合并。最后一遍 sum。

6. Basic Calculator:括号 = push 当前 (result, sign),出括号时 pop 回来

题目:字符串含非负整数、+ -、括号和空格,求值。例:"1-(2+(3-1))" = 1 - (2 + 2) = -3。

Brute force:反复找最内层括号,算出值,替换回字符串,O(n·d)(d 为嵌套深度,最坏 O(n²))。浪费:"最内层括号" 又是 "最近开的、还没关的 '('"。

关键观察:只有 + -,没有优先级问题,所以不需要 "项" 的栈,一个累加器 result 加一个 sign 就够。括号的作用是:括号整体是一个数,前面带着符号。读到 (:把外层现场 (result, sign) push 进栈,内层从 0 重新算(和 Decode String 同一招)。读到 ):先把括号内最后一个数并进来,pop 现场,result = prev_result + prev_sign * result。和上一题相比,栈里放的不再是 "项",而是 "外层的现场"。

def calculate(s): stack = [] # result = 当前括号层已累加的值; sign = num 前面的符号 (+1 / -1) result, num, sign = 0, 0, 1 for ch in s: if ch.isdigit(): num = num * 10 + int(ch) elif ch in '+-': result += sign * num # 把刚读完的 num 并进 result num, sign = 0, (1 if ch == '+' else -1) elif ch == '(': # 保存外层: 外层累加到哪了, 以及 '(' 前面的符号 stack.append((result, sign)) result, sign = 0, 1 # 括号内部从 0 重新算 elif ch == ')': result += sign * num # 先把括号内最后一个 num 并进来 num = 0 prev_result, prev_sign = stack.pop() # 整个括号当成一个数, 乘上 '(' 前面的符号 result = prev_result + prev_sign * result return result + sign * num

时间 O(n):每个字符一次。空间 O(d):栈深 = 括号嵌套深度。

记:( 压栈 (result, sign) 并清零; ) 弹出并合并: result = prev_result + prev_sign * result。Calculator III (带 * / 和括号) = 这两题合起来: 递归或再叠一层栈,模板不变。

7. Asteroid Collision:新元素和栈顶 "冲突" 就 pop

题目:数组里每个数是一颗小行星,绝对值是大小,正数向右、负数向左,速度相同。相撞时小的炸,一样大都炸,求最后剩下的。例:[5, 10, -8, -12, 3] → [-12, 3]。

Brute force:反复扫描数组,找到第一对 a[i] > 0 > a[i+1],按规则删掉,重复直到没有相撞,O(n²)。浪费:每次从头扫,但相撞只可能发生在 "当前最右边活着的向右的那个" 和 "新来的向左的" 之间。

关键观察:从左到右处理,栈里是 "到目前为止活着的"。新来的 x 只可能和栈顶相撞,而且只有 栈顶 > 0 且 x < 0 才撞。撞完如果栈顶炸了,露出来的下一个又是 "最近的",继续比 —— 用 while。这是 stack 的第三种形状:新元素和栈顶冲突就 pop,直到不冲突才 push。

def asteroid_collision(asteroids): # invariant: 栈里没有会相撞的一对 (栈顶向右 + 下一个向左) stack = [] for a in asteroids: alive = True # 只有 "栈顶向右 + 新来的向左" 才会撞 while alive and a < 0 and stack and stack[-1] > 0: # 栈顶更小: 栈顶炸掉, 新来的继续去撞下一个 if stack[-1] < -a: stack.pop() elif stack[-1] == -a: # 一样大: 同归于尽 stack.pop() alive = False else: # 栈顶更大: 新来的炸掉 alive = False if alive: stack.append(a) return stack

时间 O(n):每颗行星最多 push 一次、pop 一次(while 的总迭代数被 pop 次数限制)。空间 O(n)。

记:while 冲突: pop 再 push。一个元素可能 pop 好几个,但摊销下来每个元素只 pop 一次 → O(n)。

8. Remove All Adjacent Duplicates II:栈元素存 (char, count)

题目:反复删除 s 中连续 k 个相同字符,直到不能再删。例:s = "abbbaac", k = 3 → "c"(删 bbb 后 a 和 aa 相邻,凑成 aaa 再删)。

Brute force:反复扫描找连续 k 个相同的删掉,每轮 O(n),最多 n/k 轮,O(n²/k)。浪费:删掉一段后,左右两边变成相邻,但这件事要靠重新扫描才发现。

关键观察:用栈的话,删掉一段就是 pop,下面的元素自动变成栈顶,和后面的新字符继续比较 —— "相邻" 关系被栈结构保持着。如果栈里只存单个字符,凑够 k 个要回头数 O(k);所以栈元素存 [char, count](连续的一段),栈顶的 count 直接就是答案。这和 Min Stack 是同一个套路:额外状态跟着元素一起存。

def remove_duplicates(s, k): # 每个元素 [char, count]: 栈顶这一段 char 已经连续出现 count 次 stack = [] for ch in s: if stack and stack[-1][0] == ch: stack[-1][1] += 1 # 和栈顶同字符: 这一段变长 (不用回头数) # 凑够 k 个: 整段删掉, 它下面的段自然变成相邻 if stack[-1][1] == k: stack.pop() else: stack.append([ch, 1]) return "".join(c * n for c, n in stack)

时间 O(n):每个字符处理一次,push / pop 各最多一次。空间 O(n)。(k = 2 就是 Remove All Adjacent Duplicates In String:栈里存字符,和栈顶相同就 pop。)

记:"删掉一段后两边会合并" → stack,元素存 (值, 连续次数)。删除 = pop,合并 = 下一个元素和新栈顶比。

9. Simplify Path:目录栈,'..' = pop

题目:把 Unix 绝对路径化简成规范形式。例:"/a/./b/../../c/" → "/c"。'.' 是当前目录,'..' 是上一级,多个 '/' 当作一个。

Brute force:反复用字符串替换去掉 "/./"、"//" 和 "/x/../",每轮 O(n),可能 O(n) 轮 → O(n²)。浪费:"/x/.." 里的 x 就是 "最近进入的目录"。

关键观察:走路径就是在目录树里移动:进目录 = push,'..' = 回上一层 = pop(已在根就不动)。split('/') 之后每个 part 只有三类:'..' → pop;空串或 '.' → 什么都不做;其余 → push。

def simplify_path(path): # invariant: 栈 = 当前目录从根到现在的每一层名字 stack = [] for part in path.split('/'): # "//" 会切出空串 '' if part == '..': if stack: stack.pop() # 回上一层; 已经在根 '/' 就忽略 elif part and part != '.': # '' 和 '.' 什么都不做; 其余是目录名 stack.append(part) return '/' + '/'.join(stack)

时间 O(n):split 和 join 各 O(n),每个 part 常数次栈操作。空间 O(n)。

记:"路径 / 导航 / 撤销上一步" → stack。'..' 就是 undo。Backspace String Compare 也是同一个模板: 字母 push, '#' pop。

函数调用 / 日志 start-end 嵌套start push, end pop (Exclusive Time of Functions)O(n·d) → O(n)
递归 DFS 爆栈 / 想手动控制用显式 stack 代替递归同 O(n), 避免 recursion limit

通用判断:题目出现 "最近的 / 上一个 / 还没处理完 / 嵌套 / 撤销",就问自己 "栈里应该存什么"。栈里存的东西有四类:(1) 开括号 / 位置 (2) 已算好的值 (3) 被暂停的外层现场 (4) 带额外状态的元组。
