12 · Graph: BFS / DFS / Topological Sort / Union-Find / Dijkstra

主线: graph 遍历 = 从已知的点出发, 用 visited 保证每个点只处理一次 → O(V + E)。BFS 按层扩 = 无权最短路; 入度归零 = 拓扑序; Union-Find 回答"连没连通"; heap 贪心 = 带权最短路。

概念链: Number of Islands (grid DFS) → Rotting Oranges (multi-source BFS) → Word Ladder (隐式图 BFS 最短路) → Course Schedule (Kahn 拓扑排序) → Course Schedule II (拓扑顺序 + 有环) → Clone Graph (DFS + Hash Table) → Number of Provinces (Union-Find) → Network Delay Time (Dijkstra)

0. 第一性原理: 不记 visited, 就是在重复劳动

Brute force: 从 start 出发, 对每个邻居递归 (或入队), 不记走过哪里。图里有环 → 永远走不完; 即使没有环, 多条路汇合到同一个点时, 那个点和它后面的整片区域会被重复处理。上图: 两层 diamond 就有 13 次处理, 每多一层翻一倍 → O(2^k)。

浪费在哪: 同一个点被处理多次。点的结果只和"它是谁"有关, 和"从哪条路来的"无关, 第二次处理是白做。

消掉它: 一个 visited 集合。点第一次出现就标记, 之后看到就跳过 → 每个点只处理一次, 每条边只检查一次 → O(V + E)。grid 是隐式 graph: 格子是点, 上下左右是边, 邻居靠 (dr, dc) 现算, 不用建邻接表。

BFS vs DFS 怎么选: 只要"最少几步 / 最短路 (边权相同)" 就用 BFS: queue 里永远只有相邻两层, 第 k 层的点离起点正好 k 条边, 第一次碰到目标就是最短。只要"有没有 / 有几块 / 复制 / 收集" 两个都行, DFS 写起来更短。

from collections import deque# ---- BFS: 从 start 一层一层往外扩 (无权图最短路) ----def bfs(start, neighbors): visited = {start} # 入队时就标记 (不是出队时), 否则同一点会重复入队 q = deque([start]) while q: u = q.popleft() for v in neighbors(u): # neighbors(u): 邻接表 / grid 四个方向 / 改一个字母 if v not in visited: visited.add(v) # 每个点只会入队一次 → 总工作量 O(V + E) q.append(v)# ---- DFS: 沿一条路走到底, 走不动再回头 ----def dfs(u, neighbors, visited): visited.add(u) # 进来就标记 for v in neighbors(u): if v not in visited: dfs(v, neighbors, visited)# ---- grid 是隐式 graph: 格子 = 点, 上下左右 = 边, 不用建邻接表 ----DIRS = ((1, 0), (-1, 0), (0, 1), (0, -1))def grid_neighbors(r, c, m, n): for dr, dc in DIRS: nr, nc = r + dr, c + dc if 0 <= nr < m and 0 <= nc < n: # 出界 = 没有这条边 yield nr, nc

记:visited 是 graph 题的第一反应。BFS 在入队时标记, DFS 在进入时标记。点数 V, 边数 E, 总是 O(V + E)。

1. Number of Islands: grid DFS flood fill, 进来先 sink

题目: grid 里 "1" 是陆地, "0" 是水, 上下左右相连的陆地算一个 island, 数有几个。例: ["11000","10010","00110","00001"] → 3。

Brute force: 对每个陆地格子各跑一次搜索, 各自找出它的连通块, 再给连通块去重 → 最坏 O((mn)²)。浪费: 同一个 island 里的每个格子都把整块 island 重新搜一遍。

关键观察: 搜过的格子就不会再有新信息。让所有搜索共享一份 visited (直接把 "1" 改成 "0"), 那么扫描时遇到的 "1" 一定属于一个没见过的 island, 一次 dfs 把整块吃掉。

def numIslands(grid): # grid[r][c] 是 "1" (陆) 或 "0" (水) m, n = len(grid), len(grid[0]) def dfs(r, c): if r < 0 or r >= m or c < 0 or c >= n or grid[r][c] != "1": return # 出界 / 水 / 已经 sink 过, 都不用再走 grid[r][c] = "0" # 进来先 sink: 这一行就是 visited 标记 for dr, dc in DIRS: # 4 个方向 = 4 条边 dfs(r + dr, c + dc) count = 0 for r in range(m): for c in range(n): if grid[r][c] == "1": # 遇到还没处理的陆地 = 发现一个新 island count += 1 # 每个 island 只会在它的第一个格子触发一次 dfs(r, c) # 把整块 island sink 掉, 之后扫描不会再碰到它 return count

Time O(mn): 外层扫描每格一次; dfs 每个陆地格只会"真正展开"一次 (进入即 sink), 每格检查 4 个邻居。Space O(mn): 整个 grid 是一个 island 时递归栈最深 mn。Python 默认递归深度 1000, grid 很大时换成显式 stack 或 BFS, 逻辑不变。

变体 Max Area of Island: 同样的 dfs, 让它返回"这块有多少格", 外层取 max。只改一行:

def maxAreaOfIsland(grid): m, n = len(grid), len(grid[0]) def dfs(r, c): # 返回: 从 (r, c) 能走到的陆地格数 if r < 0 or r >= m or c < 0 or c >= n or grid[r][c] != 1: return 0 grid[r][c] = 0 return 1 + sum(dfs(r + dr, c + dc) for dr, dc in DIRS) # 改动: void → 返回面积 return max(dfs(r, c) for r in range(m) for c in range(n))

记:grid 连通块 = 外层扫描 + dfs 原地标记。数块数: 触发次数; 求面积: dfs 返回格数。

2. Rotting Oranges: multi-source BFS, 所有源点一起入队

题目: 0 空, 1 新鲜, 2 烂。每分钟烂橘子把上下左右的新鲜橘子变烂。问全部变烂要几分钟, 不可能返回 -1。和上一题的区别: 起点不止一个, 而且要"最短时间"。

Brute force: 每分钟把整个 grid 扫一遍, 让烂橘子感染邻居, 直到没变化 → 每分钟 O(mn), 最多 mn 分钟 → O((mn)²)。浪费: 每分钟都重新扫所有格子, 但真正会传染的只有"刚变烂的"那一圈, 烂了很久的早就没有新鲜邻居了。

关键观察: 只保留"刚变烂的那一圈" = BFS 的一层。每一层 = 1 分钟, len(q) 就是这一层的大小。多个源点怎么办? 想象一个虚拟起点连到所有烂橘子, 距离 0 → 实际上就是把所有初始烂橘子一起放进 queue 当作第 0 层。

def orangesRotting(grid): # 0 空, 1 新鲜, 2 烂 m, n = len(grid), len(grid[0]) q, fresh = deque(), 0 for r in range(m): for c in range(n): if grid[r][c] == 2: q.append((r, c)) # 所有初始烂橘子一起入队 = 第 0 层 (multi-source) elif grid[r][c] == 1: fresh += 1 minutes = 0 while q and fresh: for _ in range(len(q)): # 只处理"当前这一层", 新入队的留给下一分钟 r, c = q.popleft() for dr, dc in DIRS: nr, nc = r + dr, c + dc if 0 <= nr < m and 0 <= nc < n and grid[nr][nc] == 1: grid[nr][nc] = 2 # 变烂 = 标记 visited fresh -= 1 q.append((nr, nc)) minutes += 1 # 一层 = 一分钟 return -1 if fresh else minutes # 还有新鲜的 = 被墙/空格隔开, 永远烂不到

Time O(mn): 每个橘子变烂时入队一次、出队一次。Space O(mn): queue 最大是一层的大小。

记:"离最近的 X 有多远" / "同时扩散" → 所有源点一起入队。层数 = 距离。分层写法: for _ in range(len(q))。

3. Word Ladder: 隐式图上的 BFS 最短路

题目: 每次只能改一个字母, 且改完的词必须在词典里。求 beginWord 变到 endWord 的最短序列长度 (单词个数)。例: hit → cog, 词典 [hot, dot, dog, lot, log, cog] → 5 (hit → hot → dot → dog → cog)。和上一题的区别: 没有 grid, 点是单词, 邻居"改一个字母"要自己生成。

Brute force: DFS 枚举所有变换路径取最短 → 指数级。或者先两两比较建 graph, O(N² L), 再 BFS。浪费: 枚举路径是在重复探索同一个词; 两两比较则为了建一张只用一次的图付了 N²。

关键观察: 无权最短路 → BFS。邻居不用预先建图: 对当前词的每一位换 26 个字母, 在不在词典里直接查 set, 一个词有 26L 个候选。把 words 当作"没访问过的词", 找到一个就 remove → remove 就是 visited。

def ladderLength(beginWord, endWord, wordList): words = set(wordList) # 同时充当 "没访问过的点集合" if endWord not in words: return 0 q, level = deque([beginWord]), 1 # level = 路径上的单词个数 while q: for _ in range(len(q)): # 一层一层: 同层的单词离 beginWord 一样远 w = q.popleft() if w == endWord: return level # BFS 第一次碰到 endWord 就是最短 for i in range(len(w)): # 邻居 = 改一个字母后还在词典里的词 for ch in "abcdefghijklmnopqrstuvwxyz": nw = w[:i] + ch + w[i + 1:] if nw in words: words.remove(nw) # remove = 标记 visited, 之后不会再入队 q.append(nw) level += 1 return 0

Time O(N × L × 26 × L): 每个词最多出队一次 (入队前已 remove), 每个词 26L 个候选, 每个候选拼字符串 + 查 set 是 O(L)。Space O(NL)。

变体 Open the Lock: 点 = 4 位数字串 "0000".."9999", 邻居 = 某一位 ±1 (8 个), deadends 一开始就放进 visited。其余和这题一模一样。

记:状态本身当节点 (单词 / 密码锁 / 位置+钥匙) + 无权最短路 → 隐式图 BFS。邻居现算, visited 存状态, 层数 = 答案。

4. Course Schedule: 拓扑排序 (Kahn), indegree 归零才入队

题目: numCourses 门课, [a, b] 表示上 a 之前必须先上 b。问能不能全部上完 (有环就不行)。例: n = 6, prerequisites = [[2,0],[2,1],[3,2],[4,2],[5,3],[5,4]] → True。和上一题的区别: 边有方向, 问的是"依赖是否满足", 不是最短路。

Brute force: 每一轮扫描所有课, 找"前置课都上完了"的课去上, 直到没有可上的 → 每轮 O(V + E), 最多 V 轮 → O(V(V+E))。浪费: 每轮都在重新数每门课还差几门前置课, 而上完一门课只会影响它的后继。

关键观察: 维护 indegree[v] = v 还没上完的前置课数。上完 u 时, 只给 u 的后继 −1; 减到 0 就入队。每条边恰好减一次 → O(V + E)。

def canFinish(numCourses, prerequisites): # prerequisites[i] = [course, pre]: 先 pre 后 course graph = [[] for _ in range(numCourses)] indegree = [0] * numCourses # indegree[v] = v 还有几门前置课没上完 for course, pre in prerequisites: graph[pre].append(course) # 边 pre → course indegree[course] += 1 q = deque(i for i in range(numCourses) if indegree[i] == 0) # 没有前置的先上 done = 0 while q: u = q.popleft() done += 1 # u 上完了 for v in graph[u]: indegree[v] -= 1 # v 少了一门前置 if indegree[v] == 0: # 前置全上完 → v 可以上了 q.append(v) return done == numCourses # 有环 → 环上的点 indegree 永远 > 0 → done 不够

Time O(V + E): 建图 O(V + E), 每个点入队一次, 每条边减一次。Space O(V + E): 邻接表 + indegree + queue。

记:有依赖顺序 / 能不能完成 / 编译顺序 → 拓扑排序。入度为 0 的先入队, 每 pop 一个就把后继的入度减 1。

5. Course Schedule II: 同一个模板, 记下 pop 的顺序

题目: 和上一题一样, 但要返回一个合法的上课顺序; 有环返回 []。改哪里: 把 done 计数换成 order 列表, 最后检查 len(order) == numCourses。

Brute force: 枚举 V! 种排列逐个检查依赖 → 指数级。关键观察: Kahn 里每个点"入队 ⇔ 所有前置课都已经在 order 里", 所以 pop 的顺序本身就是合法顺序, 不用额外生成。有环时, 环上的点互相等对方, indegree 永远减不到 0, 永远进不了 queue → order 不够长。

def findOrder(numCourses, prerequisites): graph = [[] for _ in range(numCourses)] indegree = [0] * numCourses for course, pre in prerequisites: graph[pre].append(course) indegree[course] += 1 q = deque(i for i in range(numCourses) if indegree[i] == 0) order = [] # 改动 1: done 计数 → 记录 pop 的顺序 while q: u = q.popleft() order.append(u) for v in graph[u]: indegree[v] -= 1 if indegree[v] == 0: q.append(v) return order if len(order) == numCourses else [] # 改动 2: 有环就没有合法顺序

Time O(V + E), Space O(V + E)。

同模板的题: Alien Dictionary — 先比较相邻两个单词, 第一个不同的字母给出一条边 a → b, 再对字母图跑 Kahn。另一种有环检测: DFS 三色标记 (未访问 / 访问中 / 已完成), 走到"访问中"的点就是有环。

记:Kahn 的 pop 顺序 = 拓扑序; len(order) < n = 有环。要字典序最小就把 queue 换成 heap。

6. Clone Graph: DFS + Hash Table (old → new)

题目: 给一个无向连通图的一个节点 (有 .val 和 .neighbors), 返回整个图的深拷贝。和前面的区别: 遍历的同时要构造一个新图, 还需要记住"这个旧节点对应哪个新节点"。

Brute force: 走到哪就 Node(old.val) 新建一个, 再递归复制 neighbors, 不记录。环 → 无限递归; 就算没有死循环, 同一个旧节点被不同的邻居走到时会生成多个副本, 图的结构就错了。浪费 / 丢掉的信息: 没记住"这个旧节点已经有副本了, 副本是谁"。

关键观察: Hash Table old2new 同时扮演两个角色: visited (有没有复制过) + 副本查找 (它的副本是谁)。关键顺序: 先登记, 再递归 neighbors。

def cloneGraph(node): # Node 有 .val 和 .neighbors (list[Node]) if not node: return None old2new = {} # Hash Table: 原节点 → 它的副本 (同时当 visited) def dfs(old): if old in old2new: # 已经复制过 → 直接返回副本, 不再递归 return old2new[old] copy = Node(old.val) old2new[old] = copy # 必须在递归 neighbor 之前登记, 否则环会无限递归 for nb in old.neighbors: copy.neighbors.append(dfs(nb)) # 副本的 neighbor 也必须是副本 return copy return dfs(node)

Time O(V + E): 每个节点复制一次, 每条边 (neighbors 列表项) 处理一次。Space O(V): old2new + 递归栈。

记:复制 / 序列化带环的结构 → old2new 字典, 创建后立刻登记, 再递归。同样适用于 Copy List with Random Pointer。

7. Number of Provinces: Union-Find (path compression + union by size)

题目: n 个城市, isConnected[i][j] == 1 表示直接相连 (相连关系可以传递)。问有几个 province (连通块)。例 (trace): n = 7, 边 (0,1) (2,3) (0,2) (4,5) (3,5) → 2 个 (0..5 一块, 6 一块)。

Brute force: 这一题用 DFS/BFS 数连通块一次就是 O(V + E), 没问题。但如果边是一条条加进来、随时问"a 和 b 连通吗", 每次问都重新 BFS 就是 O(V + E) 一次。浪费: 上一次已经算出的连通信息没有保存。

关键观察: 只需要保存"谁和谁在同一个集合": 每个集合选一个 root, 每个点存 parent, 顺着 parent 走到 root。find(a) == find(b) 就是连通。两个优化让它几乎 O(1): union by size (小树挂大树, 树高 ≤ log n), path compression (find 时把路径上的点直接挂到 root)。

class DSU: def __init__(self, n): self.parent = list(range(n)) # parent[x] == x 表示 x 是所在集合的 root self.size = [1] * n # size[root] = 集合大小 (只对 root 有意义) def find(self, x): while self.parent[x] != x: self.parent[x] = self.parent[self.parent[x]] # path compression (halving): 爷爷接管 x = self.parent[x] return x def union(self, a, b): ra, rb = self.find(a), self.find(b) if ra == rb: return False # 已经在同一集合 → 这条边没有合并任何东西 if self.size[ra] < self.size[rb]: # union by size: 小树挂到大树的 root 下 ra, rb = rb, ra self.parent[rb] = ra self.size[ra] += self.size[rb] return True
def findCircleNum(isConnected): # isConnected[i][j] == 1: i 和 j 直接相连 n = len(isConnected) dsu = DSU(n) count = n # 开始: 每个人自己一个 province for i in range(n): for j in range(i + 1, n): if isConnected[i][j] and dsu.union(i, j): count -= 1 # 每成功合并一次, 集合数少 1 return count

Time O(n² × α(n)) (要读完整个矩阵 n²; 若输入是边列表则是 O((n + E)α(n)), α 是反 Ackermann, 实际 ≤ 4)。Space O(n)。

变体 Accounts Merge: 点 = account 下标, 两个 account 共用一个 email 就 union; 最后按 root 把 email 归并、排序。只多了一个 email → 第一次见到它的 account 的字典:

def accountsMerge(accounts): # accounts[i] = [name, email1, email2, ...] dsu = DSU(len(accounts)) owner = {} # email → 第一次见到它的 account 下标 for i, acc in enumerate(accounts): for email in acc[1:]: if email in owner: dsu.union(i, owner[email]) # 共用 email → 同一个人 else: owner[email] = i groups = defaultdict(set) for email, i in owner.items(): groups[dsu.find(i)].add(email) # 按 root 归并 email return [[accounts[r][0]] + sorted(es) for r, es in groups.items()]

记:"连通块 / 合并集合 / 动态加边问连不连通 / 无向图有没有环" → Union-Find。union 返回 False = 这条边的两端早已连通 = 成环 (Graph Valid Tree)。

8. Network Delay Time: Dijkstra (heap)

题目: n 个点, times[i] = [u, v, w] 表示 u → v 耗时 w。从 k 发信号, 问所有点都收到至少要多久, 收不到返回 -1。例: n = 5, k = 1, 6 条边 (见图) → 7。和前面的区别: 边有权重, BFS 的"层数"不再等于距离。

Brute force: Bellman-Ford: 对所有边重复松弛 V - 1 轮 → O(VE)。浪费: 每一轮都把所有边再松弛一遍, 但绝大多数边的起点 dist 这一轮根本没变。

关键观察 (贪心): 所有候选距离里最小的那个一定已经是最终答案 (边权 ≥ 0, 绕路只会更长)。所以用 min-heap 每次取出当前最近的点, 只对它的出边松弛一次。heap 里的旧记录不删, 弹出时发现 d > dist[u] 就跳过 (lazy deletion)。

def networkDelayTime(times, n, k): # times[i] = [u, v, w]: u → v 耗时 w graph = defaultdict(list) for u, v, w in times: graph[u].append((v, w)) INF = float("inf") dist = [INF] * (n + 1) # dist[v] = 目前已知从 k 到 v 的最短时间 dist[k] = 0 heap = [(0, k)] # min-heap, 按 (dist, node) 排: 先拿"当前最近"的 while heap: d, u = heapq.heappop(heap) if d > dist[u]: # 这是个过期记录: u 之后找到了更短的路 continue for v, w in graph[u]: # relax: 经过 u 到 v 会不会更短? nd = d + w if nd < dist[v]: dist[v] = nd heapq.heappush(heap, (nd, v)) # 不删旧记录, 只加新的 (lazy deletion) ans = max(dist[1:]) return -1 if ans == INF else ans # 有点到不了 → -1

Time O(E log V): 每条边最多 push 一次, heap 操作 O(log)。Space O(V + E)。

变体 Cheapest Flights Within K Stops: 限制最多 k 次中转 = 最多 k+1 条边。Dijkstra 的"最小的就是最终"在有边数限制时不成立 (便宜但绕远的路可能把边数用光), 改用 Bellman-Ford 只松弛 k+1 轮 (或 BFS, 状态带"已用边数"):

def findCheapestPrice(n, flights, src, dst, k): # 最多 k 次中转 = 最多 k+1 条边 dist = [float("inf")] * n dist[src] = 0 for _ in range(k + 1): # Bellman-Ford: 一轮 = 多允许走 1 条边 nxt = dist[:] # 用上一轮的 dist 算, 防止一轮里连走多条边 for u, v, w in flights: if dist[u] + w < nxt[v]: nxt[v] = dist[u] + w dist = nxt return -1 if dist[dst] == float("inf") else dist[dst]

记:边权不同 + 非负 → Dijkstra: heap 存 (dist, node), 弹出时过期就 skip, 对出边 relax。边权全 1 → 普通 BFS 就够。有边数限制 → Bellman-Ford 跑 k+1 轮。

9. 识别信号: 看到什么 → 试什么

特征做法complexity 从 → 到
