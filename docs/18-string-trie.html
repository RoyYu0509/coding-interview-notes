18 · String 基本功 + Trie

这篇讲什么

这一篇分两部分。

前半部分是 Python 处理字符串的基本功。很多 string 题本身不难, 但写的时候容易在细节上出错 (空格、符号、越界), 或者不小心写出 O(n²)。这部分讲两个通用的写法: 用 list + join 拼字符串, 用一个指针 i 一段一段地 parse。

后半部分是 Trie (前缀树)。当有很多个字符串, 而且它们有共同的前缀时, 把它们存成一棵树, 共同的前缀只存一次。查一个前缀、或者同时找很多个词, 都会快很多。

0. 基本功: str 不可变, 拼接要用 list + join

Python 的 str 是不可变的 (immutable): 一旦创建就不能修改。s += c 看起来是在 s 后面加了一个字符, 实际上是新建了一个字符串, 把 s 的内容和 c 都复制进去。

所以在循环里写 s += c, 第 1 次复制 1 个字符, 第 2 次复制 2 个……第 n 次复制 n 个, 总共 O(n²)。(CPython 有时会偷偷优化成原地追加, 但这是实现细节, 面试里不能依赖。)

正确的写法: 把每一段放进一个 list (append 是 O(1)), 最后用 ''.join(parts) 一次拼起来, 总共 O(n)。

代码: += vs join, 以及常用的 string 工具
# str 不可变: s[0] = 'x' 会 TypeError, s += c 其实是 "新建一个 string"res = ''for c in s: # 每次: 新 string = 旧 string 全部复制 + 1 个字符 -> O(n^2) res += cparts = []for c in s: parts.append(c) # list.append 摊销 O(1), 旧元素不动res = ''.join(parts) # 最后一次性分配 + 复制, O(n)
# ['a', 'b'] 不带参数: 连续空白当一个分隔符, 空串丢掉" a b ".split()# ['', '', 'a', '', 'b', ''] 带 ' ': 每个空格都切一刀, 留下空串" a b ".split(' ')ord('d') - ord('a') # 3 字母 -> 0..25, 拿来当 count[26] 的下标# 字母或数字 (isdigit 对 '²' 之类也为 True, 要严格用 '0' <= c <= '9')c.isalnum()s[::-1] # reverse, 返回新 string, O(n)

常用工具: s.split() (不带参数, 按任意空白切, 自动去掉空串)、s.split(' ') (只按单个空格切, 会留下空串)、ord(c) - ord('a') (字母转 0..25)、c.isalnum()、c.isdigit()、s[::-1] (反转)。

记:循环里拼字符串: list.append + ''.join, 不要 s += c。

1. Longest Common Prefix

题目在问什么

给一组字符串, 找它们共同的最长前缀。没有就返回空字符串。

看例子

Brute force

先拿第一个字符串当候选前缀, 再和每个字符串比, 不断缩短。最坏 O(S), S 是所有字符的总数。这题本身已经是线性的, 重点是写法清楚。

Intuition: 把字符串上下对齐, 一列一列看

把所有字符串左对齐, 上下排好。从第 0 列开始, 看这一列所有字符串的字符是不是都一样。都一样就继续看下一列; 一旦有一个不一样, 或者某个字符串已经没有这一列了 (太短), 就停。前面的那些列就是答案。

这道题引出一个想法: 如果有很多字符串, 并且经常要问"有没有以 xxx 开头的", 每次都这样一列一列比就太慢了。把它们共同的前缀合并起来存, 就是后面要讲的 Trie。

算法

  1. j 从 0 开始, 以 strs[0][j] 为标准。
  2. 对其他每个字符串: 如果 j 越界, 或者字符不同, 返回 strs[0][:j]。
  3. 全部看完, 返回 strs[0]。

手动走一遍

复杂度

Time O(S), Space O(1)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def longestCommonPrefix(strs): first = strs[0] for j in range(len(first)): # 一列一列往右走: 第 j 列 c = first[j] # 以 strs[0] 这一列的字符当标准 for s in strs[1:]: if j == len(s) or s[j] != c: # s 太短 或 字符不同 -> 第 j 列失败 return first[:j] # 前 j 列都过了, 答案就是 first[:j] return first # first 整个都是公共前缀

记:多个字符串比较前缀: 纵向对齐, 一列一列比。

2. String to Integer (atoi)

题目在问什么

把字符串转成一个 32 位有符号整数, 规则是:

  1. 跳过开头的空格。
  2. 读一个可选的 + 或 -。
  3. 读连续的数字, 遇到不是数字的字符就停, 后面的全部忽略。
  4. 结果超出 [-2³¹, 2³¹ - 1] 就截到边界。什么数字都没读到就返回 0。

看例子

Brute force

这题没有算法上的难度, 难在规则多、容易漏边界。用一堆 if 判断各种情况很容易写乱。

Intuition: 一个指针 i, 每个阶段一个循环

用一个下标 i 从左往右走, 把规则拆成几个阶段, 每个阶段只负责一件事, 做完了 i 停在下一阶段的开头:

  • 阶段 1: while s[i] == ' ', i 往前走。
  • 阶段 2: 如果 s[i] 是 + 或 -, 记下符号, i 往前一格。
  • 阶段 3: while s[i] 是数字, num = num * 10 + 这个数字, i 往前走。
  • 最后乘上符号, 截到范围内。

每个 while 都要先检查 i < n, 防止越界。这个"一个指针、分阶段"的写法可以用在所有 parse 类的题上 (解析表达式、解析路径、解析版本号)。

算法

  1. 跳空格 → 读符号 → 读数字 → 乘符号 → 截断。

手动走一遍

复杂度

Time O(n), Space O(1)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def myAtoi(s): INT_MAX, INT_MIN = 2**31 - 1, -2**31 # i = parse 指针, 只向右走, 每个字符只看一次 i, n = 0, len(s) while i < n and s[i] == ' ': # 阶段 1: 跳空格 i += 1 sign = 1 if i < n and s[i] in '+-': # 阶段 2: 符号, 最多吃 1 个 sign = -1 if s[i] == '-' else 1 i += 1 num = 0 # 阶段 3: 数字, 遇到第一个非数字就停 while i < n and '0' <= s[i] <= '9': num = num * 10 + (ord(s[i]) - ord('0')) if sign * num > INT_MAX: return INT_MAX # clamp: 一旦超界立刻返回, if sign * num < INT_MIN: return INT_MIN # 后面的数字不用再看 i += 1 return sign * num

记:parse 字符串: 一个指针 i, 每个阶段一个 while, 每个 while 先检查 i < n。

3. Reverse Words in a String

题目在问什么

把字符串里的单词顺序倒过来。单词之间可能有多个空格, 开头和结尾也可能有空格。结果里, 单词之间只留一个空格, 开头结尾没有空格。

看例子

最简单的做法

' '.join(reversed(s.split())), 一行。split() 不带参数时, 会按任意多个空白切, 并且自动去掉空字符串, 正好满足要求。

常见的错误是写成 split(' '): 它只按单个空格切, 连续的空格会切出空字符串, join 回去就会多出空格。

如果面试官不让用 split

用第 2 题的写法, 一个指针从右往左走: 先跳过空格, 然后一直走到下一个空格, 中间这一段就是一个单词, 放进结果 list。重复直到走完。

手动走一遍

复杂度

Time O(n), Space O(n)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def reverseWords(s): # split() 不带参数: 按连续空白切并丢掉空串 return ' '.join(s.split()[::-1])
def reverseWords(s): # 同一个 parse 指针模板, 只是从右往左 words, i = [], len(s) - 1 while i >= 0: while i >= 0 and s[i] == ' ': # 阶段 1: 跳空格 i -= 1 if i < 0: break j = i # j = 单词最后一个字符 while i >= 0 and s[i] != ' ': # 阶段 2: 吃一个单词 i -= 1 # i 停在单词前一格, 单词 = s[i+1 .. j] words.append(s[i + 1:j + 1]) return ' '.join(words) # 已经是倒序的了, join 一次

记:按空白切单词用 split() 不带参数。手写的话: 指针跳空格 → 读单词, 重复。

4. Implement Trie (Prefix Tree)

题目在问什么

实现一个 Trie, 支持三个操作: insert(word) 存一个词; search(word) 这个完整的词有没有存过; startsWith(prefix) 有没有存过的词以 prefix 开头。

看例子

Brute force

把所有词存在一个 list (或 set) 里。search 用 set 是 O(L); 但 startsWith 要把所有词都检查一遍, O(N · L)。

浪费: "apple"、"app"、"apply" 都以 "app" 开头, 这个前缀被存了很多遍, 每次查询也要重复比较很多遍。

Intuition: 共同的前缀只存一次

把所有词存成一棵树: 每个 node 代表一个字符, 从 root 往下走的一条路径就拼出一个前缀。共同前缀的词共用同一段路径。

  • 每个 node 有一个 children dict: 下一个字符 → 下一个 node。
  • 每个 node 有一个 is_end 标记: 有没有某个词正好在这里结束。这就是 search("app") 和 startsWith("app") 的区别。

insert: 从 root 开始, 一个字符一个字符往下走, 没有对应的 child 就新建一个。走到最后一个字符, 标记 is_end = True。

search / startsWith: 同样往下走, 中途找不到 child 就返回 False。走完之后, search 还要检查 is_end, startsWith 不用。

算法

  1. insert: node = root; 每个字符 c: 不在 children 里就新建; node = node.children[c]。最后 node.is_end = True。
  2. 查找前缀 (共用的辅助函数): 往下走, 找不到返回 None, 找到返回最后的 node。
  3. search: 找到了并且 is_end。startsWith: 找到了就行。

手动走一遍

复杂度

每个操作 Time O(L), L 是词的长度, 和存了多少个词无关。Space 是所有词的字符总数 (共同前缀只算一次)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
class TrieNode: def __init__(self): self.children = {} # char -> TrieNode self.is_end = False # 有一个 word 刚好在这个 node 结束class Trie: def __init__(self): self.root = TrieNode() def insert(self, word): node = self.root for c in word: # 这条边不存在 -> 新建 node (图里的绿色) if c not in node.children: node.children[c] = TrieNode() # 边已存在 -> 直接复用, 这就是 "共享前缀" node = node.children[c] node.is_end = True # 只在最后一个 node 标记 def _walk(self, s): # 沿着 s 往下走, 走不通返回 None node = self.root for c in s: node = node.children.get(c) if node is None: return None return node def search(self, word): # 整个 word 存在吗 node = self._walk(word) # 走得通还不够: "ap" 是前缀, 不一定是 word return node is not None and node.is_end def startsWith(self, prefix): # 有 word 以 prefix 开头吗 return self._walk(prefix) is not None # 走得通就够了

记:很多字符串、要按前缀查: Trie。node 有 children (dict) 和 is_end。

5. Search Suggestions System

题目在问什么

一组产品名 products 和一个搜索词 searchWord。用户一个字母一个字母地输入 searchWord, 每输入一个字母, 返回以当前已输入的部分为前缀的产品里, 字典序最小的最多 3 个。

看例子

Brute force

每输入一个字母, 都把所有产品扫一遍, 找出以它开头的, 排序取前 3。O(L · N · L)。

Intuition: 在 Trie 的每个 node 里直接存好答案

每输入一个字母, 就是在 Trie 上往下走一步。走到的那个 node 代表"当前输入的前缀", 它下面的所有词就是以这个前缀开头的产品。

与其每次都去遍历它下面所有的词, 不如在 insert 的时候, 就让每个经过的 node 记住"以我为前缀的、字典序最小的 3 个词"。

怎么保证是字典序最小的 3 个? 先把 products 排序, 再按顺序 insert。每个 node 只在它的 list 还不满 3 个时才加进去, 这样留下的一定是最小的 3 个。

算法

  1. products 排序。
  2. insert 每个产品: 往下走的路上, 每个 node 的 top list 如果少于 3 个, 就把这个产品加进去。
  3. 查询: 沿着 searchWord 往下走, 每走一步输出那个 node 的 top; 走不下去之后都输出空 list。

手动走一遍

复杂度

建树 O(N · L) (加上排序), 查询 O(L)。另一种做法: 排序后对每个前缀用二分 (bisect) 找第一个 ≥ 前缀的位置, 往后看 3 个。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
class Node: def __init__(self): self.children = {} # 经过这个 node 的 product 里, 字典序最小的 3 个 self.top3 = []def suggestedProducts(products, searchWord): root = Node() # 先排序: 之后 append 的顺序天然就是字典序 for p in sorted(products): node = root for c in p: node = node.children.setdefault(c, Node()) # 已经满 3 个 -> 后来的更大, 直接忽略 if len(node.top3) < 3: node.top3.append(p) res, node = [], root for c in searchWord: # 每敲一个字符, 往下走一步 # 走丢了 -> 之后每一步都是 [] node = node.children.get(c) if node else None res.append(node.top3 if node else []) return res

记:每个前缀都要一个答案: 在 Trie 的 node 里预先存好答案。

6. Design Add and Search Words Data Structure

题目在问什么

addWord(word) 加一个词。search(word): 有没有加过的词能匹配 word, 其中 . 可以匹配任意一个字母。

看例子

Brute force

把所有词存进 list, search 时逐个比较 (. 跳过)。O(N · L)。

Intuition: 普通字母走一条路, . 就每条路都试

用 Trie 存。search 时, 普通字母和第 4 题一样, 只有一条路可走。遇到 . 时, 它可以是任何字母, 所以要对当前 node 的每个 child 都试一次, 有一个能匹配成功就行。

这就是在 Trie 上做 DFS。没有 . 的时候是一条直线; 每个 . 会让搜索分叉。

算法

  1. dfs(node, i): i == len(word), 返回 node.is_end。
  2. word[i] 是 .: 对每个 child, 有一个 dfs(child, i + 1) 为 True 就返回 True。
  3. 否则: word[i] 在 children 里就继续 dfs, 不在就返回 False。

手动走一遍

复杂度

没有 . 时 O(L); 最坏 (全是 .) 要遍历整棵 Trie。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
class WordDictionary: # TrieNode 同上 def __init__(self): self.root = TrieNode() def addWord(self, word): # 和 Trie.insert 一模一样 node = self.root for c in word: node = node.children.setdefault(c, TrieNode()) node.is_end = True def search(self, word): # node = 已经匹配了 word[:i] 的 node def dfs(node, i): if i == len(word): return node.is_end c = word[i] # 通配: 任何 child 都可能 -> 分叉, 有一条成功就行 if c == '.': return any(dfs(ch, i + 1) for ch in node.children.values()) ch = node.children.get(c) # 普通字符: 只有一条路, O(1) return ch is not None and dfs(ch, i + 1) return dfs(self.root, 0)

记:Trie + 通配符: DFS, 遇到通配符就对所有 child 分叉。

7. Word Search II

题目在问什么

和 13 的 Word Search 规则一样 (在字母 grid 上上下左右走, 同一个格子不能重复用), 但这次给的是一组 words, 返回所有能在 board 上找到的词。

看例子

Brute force

对每个 word 都跑一遍 13 里的 Word Search。k 个词就跑 k 遍, 每遍 O(m·n · 3^L)。

浪费: 很多词有共同的前缀 (比如 oath、oat、oak)。在 board 上找 "oa" 这段路径的工作, 被每个词重复做了一遍。

Intuition: 把所有 words 放进 Trie, 一次搜索找所有的词

把所有 words 建成一棵 Trie。然后从 board 的每个格子出发做 backtracking, 一边在 board 上走, 一边在 Trie 上往下走:

  • 下一个格子的字母, 必须是当前 Trie node 的一个 child, 否则这条路上不可能有任何 word, 直接剪掉。
  • 走到一个 is_end 的 node (在代码里是 node.word 不为空), 就找到了一个词, 加进结果。

这样所有共同前缀的词在 board 上只搜一次。

两个额外的剪枝:

  • 找到一个词之后, 把它从 Trie 里标记掉 (node.word = None), 防止重复加入结果。
  • 如果一个 node 已经没有 children 也没有 word 了, 说明它下面不会再有答案, 把它从 Trie 上摘掉。后面的搜索会越来越快。

board 上的访问标记和 13 一样: 进去时改成 #, 出来时恢复。

算法

  1. 所有 words 建 Trie, 每个词的结尾 node 存这个词。
  2. 对每个格子: 如果它的字母在 root 的 children 里, 开始 dfs。
  3. dfs(r, c, parent): node = parent.children[字母]。有 word 就加进结果并清掉。标记格子, 对四个邻居 (字母在 node.children 里的) 继续 dfs, 恢复格子。node 变空了就从 parent 里删掉。

手动走一遍

复杂度

最坏 Time O(m·n · 3^L), 但因为共享前缀和剪枝, 实际比逐个 word 搜快得多。Space 是 Trie 的大小。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
class Node: def __init__(self): self.children = {} # 在这里结束的 word (存整个 word, 找到时直接用) self.word = Nonedef findWords(board, words): root = Node() for w in words: # 先把所有 word 建成一棵 trie node = root for c in w: node = node.children.setdefault(c, Node()) node.word = w R, C, res = len(board), len(board[0]), [] def dfs(r, c, parent): ch = board[r][c] # 调用前已保证 ch 在 parent.children 里 node = parent.children[ch] if node.word: res.append(node.word) # 找到后删 word: 不重复收, node 也能被摘掉 node.word = None # choose: 标记已访问 ('#' 不在任何 children 里) board[r][c] = '#' for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)): nr, nc = r + dr, c + dc if 0 <= nr < R and 0 <= nc < C and board[nr][nc] in node.children: # 剪枝 1: trie 里没有这个字符 -> 根本不进去 dfs(nr, nc, node) board[r][c] = ch # un-choose: 回溯 if not node.children and node.word is None: # 剪枝 2: node 变成死胡同 -> 从 trie 摘掉 del parent.children[ch] for r in range(R): for c in range(C): if board[r][c] in root.children: dfs(r, c, root) return res

记:在同一个结构上找很多个词: 把词建成 Trie, 一次 backtracking 同时在 board 和 Trie 上走。
