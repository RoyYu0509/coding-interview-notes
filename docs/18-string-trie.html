18 · String 基本功 + Trie

主线: String 题的本质是一根只向右走的指针 (或一列一列地扫), 每个字符只看一次。当很多 string 共享前缀时, 把前缀合并成一棵 Trie, 所有和 '前缀' 有关的操作都变成沿着一条路走。

概念链: str 不可变 (拼接用 list + join) → Longest Common Prefix (纵向逐列) → String to Integer (parse 指针 i) → Reverse Words (同模板, 从右往左) → Implement Trie (children + is_end) → Search Suggestions (node 里直接存答案) → Add and Search Words ('.' 分叉 DFS) → Word Search II (Trie + backtracking + 摘枝)。

0. 第一性原理: str 不可变, 所以拼接要用 list + join

Brute force: 在循环里写 res += c。看起来每次只加 1 个字符, 实际上 Python 的 str 不可变, += 是新建一个 string, 把旧内容整个复制过去再接上 c。第 i 次复制 i 个字符, 总共 1 + 2 + ... + n = n(n+1)/2, 是 O(n^2)。

浪费在哪: 每次都把已经拼好的部分重新复制一遍。CPython 有时会在引用计数为 1 时原地 realloc, 让 += 看起来是线性的, 但这是实现细节, 换个写法 (或别的 Python 实现) 就失效, 面试里不能依赖。同理 s[i:j] 也要复制 j - i 个字符, 在循环里到处 slice 会悄悄变成 O(n^2)。

消掉浪费: 先把小段放进 list (append 摊销 O(1), 旧元素不动), 最后 ''.join 一次性分配、一次性复制。

# str 不可变: s[0] = 'x' 会 TypeError, s += c 其实是 "新建一个 string"res = ''for c in s: res += c # 每次: 新 string = 旧 string 全部复制 + 1 个字符 -> O(n^2)parts = []for c in s: parts.append(c) # list.append 摊销 O(1), 旧元素不动res = ''.join(parts) # 最后一次性分配 + 复制, O(n)

下面是这份文档里反复会用的几个工具 (全部实际跑过):

" a b ".split() # ['a', 'b'] 不带参数: 连续空白当一个分隔符, 空串丢掉" a b ".split(' ') # ['', '', 'a', '', 'b', ''] 带 ' ': 每个空格都切一刀, 留下空串ord('d') - ord('a') # 3 字母 -> 0..25, 拿来当 count[26] 的下标c.isalnum() # 字母或数字 (isdigit 对 '²' 之类也为 True, 要严格用 '0' <= c <= '9')s[::-1] # reverse, 返回新 string, O(n)

Time: join 版 O(n), += 版 O(n^2)。Space: 都是 O(n)。

记:拼 string 用 list + join; 别在循环里 += 或 slice; 要去掉多余空格用不带参数的 split()。

1. Longest Common Prefix: 纵向逐列比较, 第一列不同就停

题目: 求一组 string 的最长公共前缀。例: [interview, internet, interval, intern] → 'inter'。

Brute force: 从 first 的最长前缀开始试: 对每个长度 L (m 到 0), 检查所有 n 个 string 是否都以 first[:L] 开头。每次 startswith 要比 L 个字符, 总共 O(n · m^2)。

浪费在哪: 试 L = 4 时已经确认过前 4 个字符全相同, 试 L = 5 又把这 4 个字符重新比一遍。

关键观察: 换个方向。不是按 '前缀长度' 横着试, 而是按 '列' 竖着比: 第 j 列所有 string 的字符都相同, 才有资格进第 j + 1 列。每个字符最多比 1 次, 第一个不同的列就是答案的终点。

def longestCommonPrefix(strs): first = strs[0] for j in range(len(first)): # 一列一列往右走: 第 j 列 c = first[j] # 以 strs[0] 这一列的字符当标准 for s in strs[1:]: if j == len(s) or s[j] != c: # s 太短 或 字符不同 -> 第 j 列失败 return first[:j] # 前 j 列都过了, 答案就是 first[:j] return first # first 整个都是公共前缀

Time: O(n · m), m 是最短 string 的长度, 也就是 O(所有字符数 S), 已经读不了更少了。Space: O(1) (不算返回的 slice)。

引出 Trie: 这题只问 '全体' 的公共前缀, 一次扫描就够。但如果同一批 string 要反复被问 '有哪些 string 以 xxx 开头', 每次都把所有 string 扫一遍就太慢了。很多 string 共享前缀 → 把共享的前缀只存一份 → Trie (第 4 节)。

记:多个 string 逐位对齐比较 → 纵向扫描, 一列一列走, 不回头; 越界也算不同。

2. String to Integer (atoi): 一根 parse 指针 i, 每个阶段一个 while

题目: 实现 atoi: 先跳过前导空格, 再读一个可选的 +/-, 再读连续数字, 遇到非数字就停; 结果超出 32-bit 要 clamp 到 [-2^31, 2^31 - 1]。例: ' -42x' → -42。

Brute force: 先 strip() 再 slice 出符号、再 slice 出数字部分、再转 int: 多次 slice 产生多份拷贝, 各种 if/else 混在一起, 'words and 987'、'+-12'、'0-1' 这类边界很容易漏。

关键观察: 这是一个只会往前走的状态机: 空格 → 符号 → 数字 → 结束, 不会倒回去。用一根指针 i 表示 '已经处理到哪', 每个阶段写成一个 while i < n and 条件 (符号最多一个, 用 if)。条件不满足时 i 就停在原地, 交给下一个阶段。这是所有 '逐字符解析' 题的通用模板。

def myAtoi(s): INT_MAX, INT_MIN = 2**31 - 1, -2**31 i, n = 0, len(s) # i = parse 指针, 只向右走, 每个字符只看一次 while i < n and s[i] == ' ': # 阶段 1: 跳空格 i += 1 sign = 1 if i < n and s[i] in '+-': # 阶段 2: 符号, 最多吃 1 个 sign = -1 if s[i] == '-' else 1 i += 1 num = 0 while i < n and '0' <= s[i] <= '9': # 阶段 3: 数字, 遇到第一个非数字就停 num = num * 10 + (ord(s[i]) - ord('0')) if sign * num > INT_MAX: return INT_MAX # clamp: 一旦超界立刻返回, if sign * num < INT_MIN: return INT_MIN # 后面的数字不用再看 i += 1 return sign * num

Time: O(n), i 只向右走。Space: O(1)。Python 的 int 不会溢出, 在循环里提前 return 是为了和 C++/Java 的写法一致, 也避免对超长数字串做无意义的大数运算。判断数字用 '0' <= c <= '9', 不要用 isdigit() (对 '²' 之类的字符也是 True)。

记:逐字符解析 = 一根指针 i + 每个阶段一个 while; 条件不满足就把 i 留给下一阶段; 不要 slice。

3. Reverse Words in a String: split → 倒序 → join, 或同一个模板从右往左

题目: 把句子里的单词倒序, 去掉多余空格。例: ' the sky is blue ' → 'blue is sky the'。

Brute force: 逐字符扫, 遇到非空格就 word += c, 遇到空格就把 word 放进 list; 空格的各种组合 (开头、结尾、连续) 全靠 if 补。word += c 在单词很长时又是第 0 节的 O(L^2)。

关键观察: '按空白切成单词' 是内置操作: split() (不带参数) 把连续空白当一个分隔符, 并丢掉空串。切完之后就是 list 倒序 + join。注意 split(' ') 会留下空串, 是这题最常见的 bug。

面试官如果不让用 split, 就用第 2 节同一个 parse 指针模板, 只是从右往左: 跳空格 → 吃一个单词 → append, 这样 words 天然就是倒序。

def reverseWords(s): return ' '.join(s.split()[::-1]) # split() 不带参数: 按连续空白切并丢掉空串
def reverseWords(s): words, i = [], len(s) - 1 # 同一个 parse 指针模板, 只是从右往左 while i >= 0: while i >= 0 and s[i] == ' ': # 阶段 1: 跳空格 i -= 1 if i < 0: break j = i # j = 单词最后一个字符 while i >= 0 and s[i] != ' ': # 阶段 2: 吃一个单词 i -= 1 words.append(s[i + 1:j + 1]) # i 停在单词前一格, 单词 = s[i+1 .. j] return ' '.join(words) # 已经是倒序的了, join 一次

Time: O(n)。Space: O(n)。str 不可变, Python 里做不到 O(1) 额外空间; C++ 里可以先整体 reverse 再逐词 reverse, 这是语言差异, 不是新的 pattern。

记:按空白切词用 s.split() (不带参数); 手写就用 parse 指针模板, 方向反过来而已。

4. Implement Trie: 每个字符一个 node, children 是 dict, is_end 标记 word 的末尾

题目: 实现 insert(word), search(word), startsWith(prefix)。例: insert 'app', 'apple', 'apt', 'bat' 之后, search('ap') = False, startsWith('ap') = True。

Brute force: 所有 word 放进 list 或 set。search 用 set 可以 O(L), 但 startsWith 只能扫一遍所有 word: O(N · L)。

浪费在哪: 'app', 'apple', 'apt' 都以 'ap' 开头, 这个前缀存了 3 次, 查询时也被比较了 3 次。

关键观察: 把共享的前缀合并: 每个字符是一条边, 指向一个 node; 前缀相同的 word 走同一条路径, 在分叉的地方才分开。查询时只沿着字符往下走, 步数 = 前缀长度 L, 和 word 总数 N 无关。is_end 回答 '这条路径的终点是不是一个完整的 word' (区分 'ap' 只是前缀, 'app' 是 word)。

class TrieNode: def __init__(self): self.children = {} # char -> TrieNode self.is_end = False # 有一个 word 刚好在这个 node 结束class Trie: def __init__(self): self.root = TrieNode() def insert(self, word): node = self.root for c in word: if c not in node.children: # 这条边不存在 -> 新建 node (图里的绿色) node.children[c] = TrieNode() node = node.children[c] # 边已存在 -> 直接复用, 这就是 "共享前缀" node.is_end = True # 只在最后一个 node 标记 def _walk(self, s): # 沿着 s 往下走, 走不通返回 None node = self.root for c in s: node = node.children.get(c) if node is None: return None return node def search(self, word): # 整个 word 存在吗 node = self._walk(word) return node is not None and node.is_end # 走得通还不够: "ap" 是前缀, 不一定是 word def startsWith(self, prefix): # 有 word 以 prefix 开头吗 return self._walk(prefix) is not None # 走得通就够了

Time: insert / search / startsWith 都是 O(L)。Space: O(所有 word 的总字符数) 最坏, 共享前缀越多越省。children 用 dict 最通用; 字母表固定 (小写字母) 时也可以用长度 26 的 list。

记:Trie = 每个字符一个 node + children dict + is_end。insert 时 '不存在才新建', 共享前缀自动实现; search 要检查 is_end, startsWith 不用。

5. Search Suggestions System: 在 Trie 的每个 node 里直接存答案 (top 3)

题目: 给 products 和 searchWord, 用户每敲一个字符, 返回以当前前缀开头、字典序最小的最多 3 个 product。例: products = [mobile, mouse, moneypot, monitor, mousepad], searchWord = 'mouse' → 前两步 [mobile, moneypot, monitor], 后三步 [mouse, mousepad]。

Brute force: 对每个前缀 (L 个) 扫一遍所有 N 个 product, 过滤 startswith, 排序, 取 3 个: O(L · N · L) 级别。

浪费在哪: 'mou' 的候选集一定是 'mo' 的候选集的子集, 却每次都从全部 product 重新筛。

相比上一题多了什么: node 里除了 children 还要存 top3。技巧: 先把 products 排序, 再依次 insert; 这样沿路每个 node 先到的就是字典序最小的, len < 3 就 append, 满了就忽略, 不需要任何比较。查询时每敲一个字符往下走一步, 直接读答案。

class Node: def __init__(self): self.children = {} self.top3 = [] # 经过这个 node 的 product 里, 字典序最小的 3 个def suggestedProducts(products, searchWord): root = Node() for p in sorted(products): # 先排序: 之后 append 的顺序天然就是字典序 node = root for c in p: node = node.children.setdefault(c, Node()) if len(node.top3) < 3: # 已经满 3 个 -> 后来的更大, 直接忽略 node.top3.append(p) res, node = [], root for c in searchWord: # 每敲一个字符, 往下走一步 node = node.children.get(c) if node else None # 走丢了 -> 之后每一步都是 [] res.append(node.top3 if node else []) return res

Time: 建树: 排序 O(N · L · log N) (比较两个 string 最多 L 步) + insert O(总字符数); 每次查询 O(L)。Space: O(总字符数 × 3)。

另一种常见写法: 排序后对每个前缀用 bisect_left 找到起点, 取后面 3 个检查前缀。不需要 Trie, 也是 O(L log N); 思路是 '排序后同一前缀的 string 在一段连续区间里'。

记:autocomplete / top-k 前缀 → Trie, 答案直接存在 node 上; 先排序再 insert 就不用比较。

6. Design Add and Search Words: 通配符 '.' = 在 Trie 上 DFS 分叉

题目: addWord(word) 和 search(pattern), pattern 里的 '.' 可以匹配任意一个字母。例: 加入 bad, dad, mad, mid 之后, search('.id') = True, search('b..') = True, search('....') = False。

Brute force: 所有 word 放 list, search 时对每个长度相同的 word 逐字符匹配 (遇到 '.' 跳过比较): O(N · L)。

浪费在哪: 和第 4 节一样, 共享前缀被反复比较。而且 pattern 前面的普通字符其实已经能排除大多数 word。

相比上一题多了什么: addWord 和 insert 完全一样。只有 search 变了: 普通字符沿 1 条边走 (和 search 一样), 遇到 '.' 就对所有 children 各试一次 → 写成递归 dfs(node, i), 只要有一条分支返回 True 就成功。

class WordDictionary: # TrieNode 同上 def __init__(self): self.root = TrieNode() def addWord(self, word): # 和 Trie.insert 一模一样 node = self.root for c in word: node = node.children.setdefault(c, TrieNode()) node.is_end = True def search(self, word): def dfs(node, i): # node = 已经匹配了 word[:i] 的 node if i == len(word): return node.is_end c = word[i] if c == '.': # 通配: 任何 child 都可能 -> 分叉, 有一条成功就行 return any(dfs(ch, i + 1) for ch in node.children.values()) ch = node.children.get(c) # 普通字符: 只有一条路, O(1) return ch is not None and dfs(ch, i + 1) return dfs(self.root, 0)

Time: addWord O(L); search 没有 '.' 时 O(L), 有 '.' 时最坏遍历整棵 trie, 上界是 node 数 (≤ 总字符数)。Space: O(总字符数) + 递归深度 O(L)。

记:pattern 带通配符 → Trie + DFS: 普通字符一条路, '.' 对所有 child 分叉, any(...) 短路。

7. Word Search II: Trie + backtracking, 所有 word 共享前缀一起搜

题目: 给一个字符 board 和一组 words, 找出所有能在 board 上沿相邻格子 (上下左右, 每格最多用一次) 拼出来的 word。例: 4×4 board, words = [oath, pea, eat, rain] → ['oath', 'eat']。

Brute force: 对每个 word 单独跑一遍 Word Search I (backtracking): O(W · M · N · 3^L), W 是 word 个数, L 是 word 长度。

浪费在哪: 每个 word 都从头搜一遍, 共享前缀的 word (oath / oat / oats ...) 把同样的路径重复走; 而且 board 上明明没有以 'z' 开头的格子, 也要为每个 word 各试一次。

相比上一题多了什么: 把 words 建成 Trie (node 里存 word 而不是 is_end), 对 board 只跑一次 DFS: board 每走一格, trie 也往下走一层。三个关键点: (1) 下一格的字符不在 node.children 里 → 不进 dfs (剪枝 1); (2) 走到 node.word 非空 → 收集, 然后清空 (同一个 word 不会重复收); (3) 回溯时 node 没有 children 且 word 为空 → 从 parent 里 del (摘枝), 这条路以后不会再被走。

class Node: def __init__(self): self.children = {} self.word = None # 在这里结束的 word (存整个 word, 找到时直接用)def findWords(board, words): root = Node() for w in words: # 先把所有 word 建成一棵 trie node = root for c in w: node = node.children.setdefault(c, Node()) node.word = w R, C, res = len(board), len(board[0]), [] def dfs(r, c, parent): ch = board[r][c] node = parent.children[ch] # 调用前已保证 ch 在 parent.children 里 if node.word: res.append(node.word) node.word = None # 找到后删 word: 不重复收, node 也能被摘掉 board[r][c] = '#' # choose: 标记已访问 ('#' 不在任何 children 里) for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)): nr, nc = r + dr, c + dc if 0 <= nr < R and 0 <= nc < C and board[nr][nc] in node.children: dfs(nr, nc, node) # 剪枝 1: trie 里没有这个字符 -> 根本不进去 board[r][c] = ch # un-choose: 回溯 if not node.children and node.word is None: del parent.children[ch] # 剪枝 2: node 变成死胡同 -> 从 trie 摘掉 for r in range(R): for c in range(C): if board[r][c] in root.children: dfs(r, c, root) return res

Time: 最坏 O(M · N · 3^L) (每格出发, 第一步 4 个方向, 之后最多 3 个), 但 W 不再是乘数; 剪枝让实际远小于它。Space: trie O(所有 word 的总字符数) + 递归栈 O(L)。

记:多个 word 在 grid 上找 → 先建 Trie, 一次 DFS; 剪枝靠 children, 去重靠清空 word, 提速靠摘枝。
