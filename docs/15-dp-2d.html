15 · Dynamic Programming (2): Grid / Two Strings / Interval

这篇讲什么

14 里的 DP, state 只需要一个下标。这篇的题, 一个子问题需要两个下标才能描述清楚, 所以 dp 是一个二维表格 dp[i][j]。常见的有三种:

  • grid: dp[i][j] 表示走到格子 (i, j) 的答案。
  • 两个字符串: dp[i][j] 表示第一个字符串的前 i 个字符和第二个字符串的前 j 个字符的答案。
  • 一个字符串的区间: dp[i][j] 表示子串 s[i..j] 的答案。

思考方法和 14 一样: 先想"最后一步做了什么", 推出 transition。新的难点是填表的顺序: 要保证填 dp[i][j] 的时候, 它依赖的格子都已经填好了。画出依赖的方向, 顺序就清楚了。

2D DP 通用模板
def solve(A, B): # A, B: 两个 string / 一个 grid 的行列 m, n = len(A), len(B) # dp[i][j] = 只看 A 的前 i 个、B 的前 j 个时, 子问题的答案 (两个 index → # 2D) dp = [[0] * (n + 1) for _ in range(m + 1)] # base: dp[0][*] 和 dp[*][0] = 其中一边为空时的答案 (先填好) for i in range(1, m + 1): # 填表顺序 = 依赖的反方向: # dp[i][j] 依赖 (i-1, j) (i, j-1) (i-1, j-1) for j in range(1, n + 1): # 问 "最后一步做了什么"? 每种选择 → 一个更小的子问题 → 取 min / # max / sum dp[i][j] = f(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1]) return dp[m][n] # 答案在右下角# 滚动数组: dp[i] 只读 dp[i-1] → 只留 prev, cur 两行, space O(m*n) → O(n)

1. Unique Paths

题目在问什么

一个 m × n 的 grid, 机器人从左上角出发, 每一步只能往右或往下走。走到右下角一共有多少条不同的路径?

看例子

Brute force

recursion: 到达 (i, j) 的最后一步, 要么从上面 (i-1, j) 下来, 要么从左边 (i, j-1) 过来。所以 f(i, j) = f(i-1, j) + f(i, j-1)。直接 recursion 会重复计算, 指数级。

Intuition: 两个参数 → 二维表

recursion 有两个参数 i 和 j, 所以 state 是二维的: dp[i][j] = 走到 (i, j) 的路径数。

transition: dp[i][j] = dp[i-1][j] + dp[i][j-1]。base case: 第一行和第一列都只有一种走法 (一直往右或一直往下), 都是 1。

填表顺序: 每个格子依赖上面和左边, 所以一行一行、从左往右填, 用到的格子一定已经填好了。

省空间: 每一行只依赖上一行和本行左边, 所以只留一行数组就够了: row[j] += row[j-1] (加号左边的 row[j] 是上一行的值, row[j-1] 是本行刚更新的值)。

算法

  1. dp 全部初始化为 1 (第一行、第一列都是 1)。
  2. i 从 1 到 m-1, j 从 1 到 n-1: dp[i][j] = dp[i-1][j] + dp[i][j-1]。
  3. 返回 dp[m-1][n-1]。

手动走一遍

复杂度

Time O(m·n), Space O(n) (一行)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def unique_paths(m, n): # 第 0 行 / 第 0 列只有 1 种走法 (一直直走) dp = [[1] * n for _ in range(m)] for i in range(1, m): for j in range(1, n): # 最后一步要么从上面 (i-1, j) 下来, 要么从左边 (i, j-1) 过来 # 两类路径互不重叠, 而且已经包含了所有路径 → 相加 dp[i][j] = dp[i - 1][j] + dp[i][j - 1] return dp[m - 1][n - 1]# 滚动数组: 只依赖上一行 → 一维就够def unique_paths_1row(m, n): row = [1] * n # row 当前代表 "上一行" for _ in range(m - 1): for j in range(1, n): # row[j] 旧值 = 上面, row[j-1] 新值 = 左边 row[j] += row[j - 1] return row[-1]

记:grid 上只能往右 / 往下: dp[i][j] 由上面和左边推出, 一行一行填, 可以压成一行。

2. Minimum Path Sum

题目在问什么

grid 里每格有一个非负整数。从左上走到右下, 只能往右或往下。求路径上所有数加起来的最小值。

看例子

Brute force

枚举所有路径, 和第 1 题一样是指数级的。

Intuition: 和第 1 题一样, 相加换成 min

到达 (i, j) 还是只能从上面或左边来。这次要的是最小和, 所以选两者里小的那个, 再加上自己: dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])。

base case: 第一行只能从左边来, 第一列只能从上面来, 都是一路累加。

算法

  1. 第一行、第一列做累加。
  2. 其他格子: dp[i][j] = grid[i][j] + min(上, 左)。
  3. 返回右下角。

手动走一遍

复杂度

Time O(m·n), Space O(n) 或者直接在 grid 上改 O(1)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def min_path_sum(grid): m, n = len(grid), len(grid[0]) dp = [[0] * n for _ in range(m)] dp[0][0] = grid[0][0] for j in range(1, n): # 第 0 行: 只能从左边来 dp[0][j] = dp[0][j - 1] + grid[0][j] for i in range(1, m): # 第 0 列: 只能从上面来 dp[i][0] = dp[i - 1][0] + grid[i][0] for i in range(1, m): for j in range(1, n): # 改的就是这一行: 相加 → min。到 (i, j) 的最小和 = 两个来路里小的 # 那个 + 自己 dp[i][j] = min(dp[i - 1][j], dp[i][j - 1]) + grid[i][j] return dp[m - 1][n - 1]# 滚动数组: inf 当哨兵, 不用单独处理第 0 行def min_path_sum_1row(grid): n = len(grid[0]) row = [float("inf")] * n row[0] = 0 for r in grid: row[0] += r[0] # 第 0 列: 只能从上面来 for j in range(1, n): # 旧 row[j] = 上, row[j-1] = 左 row[j] = min(row[j], row[j - 1]) + r[j] return row[-1]

记:同一个依赖方向, 换一个运算: 计数用 +, 最优用 min / max。

3. Maximal Square

题目在问什么

一个只有 0 和 1 的矩阵, 找出只包含 1 的最大正方形, 返回它的面积。

看例子

Brute force

枚举每个格子作为正方形的左上角, 再枚举边长, 检查里面是不是全是 1。O((m·n)²) 左右。

Intuition: 以 (i, j) 为右下角的最大正方形

state: dp[i][j] = 以 (i, j) 为右下角的、全是 1 的最大正方形的边长。

如果 matrix[i][j] 是 0, dp 就是 0。如果是 1, 它能形成多大的正方形, 取决于三个邻居: 上面 dp[i-1][j]、左边 dp[i][j-1]、左上 dp[i-1][j-1]。

dp[i][j] = min(上, 左, 左上) + 1。为什么是 min? 想象要在 (i, j) 拼一个边长 k 的正方形, 需要它上面、左边、左上这三个方向都至少有边长 k - 1 的正方形。三个里最小的那个, 决定了能拼多大。

答案是所有 dp 里最大的边长, 平方就是面积。

算法

  1. 多开一行一列 0 当边界。
  2. matrix[i][j] == '1' 时: dp[i+1][j+1] = min(dp[i][j+1], dp[i+1][j], dp[i][j]) + 1, 更新最大边长。
  3. 返回最大边长的平方。

手动走一遍

复杂度

Time O(m·n), Space O(m·n) (可以压成一行)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def maximal_square(matrix): # matrix 里是 "0" / "1" 字符 m, n = len(matrix), len(matrix[0]) # dp[i][j] = 以 matrix[i-1][j-1] 为右下角的全 1 正方形, 最大边长 # 多一圈 0 当边界, 省掉 if i == 0 dp = [[0] * (n + 1) for _ in range(m + 1)] best = 0 for i in range(1, m + 1): for j in range(1, n + 1): if matrix[i - 1][j - 1] == "1": # 上 / 左 / 左上 三个邻居里最小的那个, 决定先撞墙的方向 → 边 # 长 = 最小 + 1 dp[i][j] = min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1]) + 1 best = max(best, dp[i][j]) # 是 "0" 就保持 0: 这个格子不能当任何正方形的右下角 return best * best # 题目要面积

记:以 (i, j) 为右下角的最大正方形: min(上, 左, 左上) + 1。

4. Longest Common Subsequence

题目在问什么

两个字符串 text1 和 text2, 求它们最长的公共子序列的长度。子序列可以跳着选字符, 但不能改变顺序。

看例子

Brute force

枚举 text1 的所有子序列 (2^m 个), 检查是不是 text2 的子序列。指数级。

Intuition: 比较两个前缀的最后一个字符

两个字符串, 子问题就是"两个前缀": dp[i][j] = text1[:i] 和 text2[:j] 的 LCS 长度。

transition 看两个前缀的最后一个字符 text1[i-1] 和 text2[j-1]:

  • 相同: 这个字符一定可以放进 LCS 里。去掉两个末尾, 剩下的问题是 dp[i-1][j-1], 再加 1。
  • 不同: 这两个字符不可能都在 LCS 的末尾。至少有一个要丢掉: 丢 text1 的末尾 (dp[i-1][j]), 或者丢 text2 的末尾 (dp[i][j-1]), 取大的。

base case: 任何一个前缀是空的, LCS 是 0, 所以 dp 第 0 行、第 0 列都是 0。

依赖: 左上、上、左。所以还是一行一行、从左往右填。

算法

  1. dp 是 (m+1) × (n+1), 全 0。
  2. i 从 1 到 m, j 从 1 到 n: 相同则 dp[i][j] = dp[i-1][j-1] + 1; 不同则 max(dp[i-1][j], dp[i][j-1])。
  3. 返回 dp[m][n]。

手动走一遍

复杂度

Time O(m·n), Space O(m·n) (可以压成两行)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def longest_common_subsequence(text1, text2): m, n = len(text1), len(text2) # dp[i][j] = text1[:i] 和 text2[:j] 的 LCS 长度 # dp[0][*] = dp[*][0] = 0: 有一边是空串 dp = [[0] * (n + 1) for _ in range(m + 1)] for i in range(1, m + 1): for j in range(1, n + 1): if text1[i - 1] == text2[j - 1]: # 最后一个字符相同 → 一定可以配对, 去掉这一对, 看左上角 dp[i][j] = dp[i - 1][j - 1] + 1 else: # 不同 → 至少有一个字符没用上: 丢 text1 的最后一个, 或丢 text # 2 的最后一个 dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]) return dp[m][n]# 滚动数组: 只留上一行 prev 和当前行 curdef lcs_2rows(text1, text2): n = len(text2) prev = [0] * (n + 1) for ch in text1: cur = [0] * (n + 1) for j in range(1, n + 1): if ch == text2[j - 1]: cur[j] = prev[j - 1] + 1 else: cur[j] = max(prev[j], cur[j - 1]) prev = cur return prev[n]

记:两个字符串的 DP: dp[i][j] = 前 i 个和前 j 个; 看两个末尾字符相同还是不同。

5. Edit Distance

题目在问什么

把 word1 变成 word2, 每一步可以做三种操作之一: 插入一个字符、删除一个字符、替换一个字符。最少需要几步?

看例子

Brute force

recursion 试所有操作序列, 指数级。

Intuition: 和 LCS 一样看末尾, 三种操作对应三个方向

state: dp[i][j] = 把 word1[:i] 变成 word2[:j] 的最少步数。

看两个末尾字符:

  • 相同: 不用动, dp[i][j] = dp[i-1][j-1]。
  • 不同: 最后一步是三种操作之一, 取最少的再加 1:
  • 　替换 word1 的末尾成 word2 的末尾 → 剩下 dp[i-1][j-1] (左上)
  • 　删掉 word1 的末尾 → 剩下 dp[i-1][j] (上)
  • 　在 word1 末尾插入 word2 的末尾 → 剩下 dp[i][j-1] (左)

base case: dp[i][0] = i (删掉 i 个字符), dp[0][j] = j (插入 j 个字符)。

算法

  1. 初始化第 0 行、第 0 列。
  2. 相同: dp[i][j] = dp[i-1][j-1]; 不同: 1 + min(dp[i-1][j-1], dp[i-1][j], dp[i][j-1])。
  3. 返回 dp[m][n]。

手动走一遍

复杂度

Time O(m·n), Space O(m·n)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def min_distance(word1, word2): m, n = len(word1), len(word2) # dp[i][j] = word1[:i] 变成 word2[:j] 的最少操作数 dp = [[0] * (n + 1) for _ in range(m + 1)] for i in range(m + 1): dp[i][0] = i # word1[:i] → "": 删 i 次 for j in range(n + 1): dp[0][j] = j # "" → word2[:j]: 插 j 次 for i in range(1, m + 1): for j in range(1, n + 1): if word1[i - 1] == word2[j - 1]: # 最后一个字符已经一样: 不用操作, 白拿左上角 dp[i][j] = dp[i - 1][j - 1] else: dp[i][j] = 1 + min( # replace: 改成 word2[j-1], 两边各缩 1 dp[i - 1][j - 1], # delete: 删掉 word1[i-1], word1 缩短 1 dp[i - 1][j], # insert: 在末尾补上 word2[j-1], word2 缩短 1 dp[i][j - 1], ) return dp[m][n]

记:编辑距离: 末尾相同直接拿左上; 不同则 1 + min(替换 = 左上, 删除 = 上, 插入 = 左)。

6. Longest Palindromic Substring

题目在问什么

找 s 里最长的 palindrome substring (连续的, 正着读和反着读一样)。

看例子

Brute force

枚举所有 substring (O(n²) 个), 每个检查是不是 palindrome (O(n))。O(n³)。

Intuition 1: 从中心往两边扩

palindrome 是左右对称的, 有一个中心。所以反过来: 枚举中心, 从中心往两边扩, 两边字符相同就继续扩, 不同就停。

中心有两种: 一个字符 (奇数长度, 比如 "aba"), 或者两个字符之间 (偶数长度, 比如 "abba")。一共 2n - 1 个中心, 每个最多扩 O(n), 总共 O(n²), 空间 O(1)。这是面试里最实用的写法。

代码: 中心扩展
def longest_palindrome(s): # 当前最长 palindrome 的闭区间 [start, end] start, end = 0, 0 # 从中心往两边扩, 直到越界或两端不同 def expand(l, r): while l >= 0 and r < len(s) and s[l] == s[r]: l -= 1 r += 1 # 循环停下时 l, r 已经多走了一步, 退回来 return l + 1, r - 1 # 2n-1 个中心: n 个字符 + n-1 个缝 for c in range(len(s)): for l, r in (expand(c, c), expand(c, c + 1)): # 奇数长度 / 偶数长度 if r - l > end - start: start, end = l, r return s[start:end + 1]

Intuition 2: 区间 DP

也可以用 DP: dp[i][j] = s[i..j] 是不是 palindrome。它是 palindrome, 当且仅当两端相同 s[i] == s[j], 并且里面的 s[i+1..j-1] 也是 palindrome。

dp[i][j] 依赖 dp[i+1][j-1] (左下方的格子)。所以 i 要从大到小填 (从下往上), j 从小到大。这是区间 DP 典型的填表顺序: 短的区间先算, 长的后算。

手动走一遍

复杂度

两种都是 Time O(n²)。中心扩展 Space O(1), DP 是 O(n²)。

代码: 区间 DP
def longest_palindrome_dp(s): n = len(s) # dp[i][j] = s[i..j] (闭区间) 是不是 palindrome dp = [[False] * n for _ in range(n)] start, best = 0, 1 # i 从大到小: dp[i+1][j-1] 在 "下一行" for i in range(n - 1, -1, -1): for j in range(i, n): # 两端相同 + 里面 s[i+1..j-1] 也是 palindrome; 长度 <= 2 时里面是 # 空的, 直接成立 if s[i] == s[j] and (j - i < 2 or dp[i + 1][j - 1]): dp[i][j] = True if j - i + 1 > best: start, best = i, j - i + 1 return s[start:start + best]

记:回文子串: 优先用中心扩展 (2n - 1 个中心)。区间 DP 的 dp[i][j] 依赖 dp[i+1][j-1], 所以 i 从大到小填。

7. Palindromic Substrings

题目在问什么

数一数 s 里有多少个 substring 是 palindrome。位置不同的算不同的。

看例子

Intuition: 第 6 题的中心扩展, 改成计数

每个 palindrome 都有唯一的中心。从每个中心往外扩, 每扩成功一次, 就多找到一个 palindrome, count 加 1。

算法

  1. 对每个中心 (2n - 1 个): l, r 从中心开始, 当 s[l] == s[r]: count += 1, l -= 1, r += 1。

手动走一遍

复杂度

Time O(n²), Space O(1)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def count_substrings(s): count = 0 for c in range(len(s)): for l, r in ((c, c), (c, c + 1)): # 奇数中心 / 偶数中心 while l >= 0 and r < len(s) and s[l] == s[r]: # 每成功扩一步 = 发现一个新的 palindrome count += 1 l -= 1 r += 1 return count

记:数回文子串: 中心扩展, 每扩成功一次 count + 1。

8. Regular Expression Matching

题目在问什么

实现一个简单的正则匹配: pattern p 里, . 匹配任意一个字符, x* 匹配 0 个或多个 x (* 总是跟在一个字符后面)。判断 p 能不能匹配整个 s。

看例子

Brute force

recursion: 遇到 x* 就试匹配 0 个、1 个、2 个……, 分支很多, 指数级。

Intuition: 两个字符串的 DP, 难点只在 *

和第 4、5 题一样: dp[i][j] = s[:i] 能不能被 p[:j] 完全匹配。看 p 的最后一个字符 p[j-1]:

  • 普通字符或 .: 和 s 的最后一个字符匹配 (相同或者是 .), 并且前面也匹配: dp[i-1][j-1]。
  • *: 它和前一个字符 x 一起算 (x*)。有两种选择:
  • 　匹配 0 次: 把 x* 整个扔掉 → dp[i][j-2] (往左跳两格)。
  • 　匹配至少 1 次: s 的最后一个字符要能和 x 匹配, 吃掉它, 但 x* 保留 (还可以继续吃) → dp[i-1][j] (往上一格)。
  • 　两个选择有一个成立就行。

base case: dp[0][0] = True。空的 s 也可能被 p 匹配, 比如 a*b*, 所以第 0 行要按 * 的规则填: dp[0][j] = dp[0][j-2] (p[j-1] 是 * 时)。

算法

  1. dp 是 (m+1) × (n+1)。dp[0][0] = True, 按 * 填第 0 行。
  2. p[j-1] 不是 *: dp[i][j] = 匹配(s[i-1], p[j-1]) and dp[i-1][j-1]。
  3. p[j-1] 是 *: dp[i][j] = dp[i][j-2] or (匹配(s[i-1], p[j-2]) and dp[i-1][j])。
  4. 返回 dp[m][n]。

复杂度

Time O(m·n), Space O(m·n)。

def is_match(s, p): m, n = len(s), len(p) # dp[i][j] = s[:i] 能不能被 p[:j] 完整匹配 dp = [[False] * (n + 1) for _ in range(m + 1)] dp[0][0] = True # 空 pattern 匹配空 string # s 为空: 只有 "a*b*" 这类全匹配 0 次的能过 for j in range(2, n + 1): if p[j - 1] == "*": dp[0][j] = dp[0][j - 2] for i in range(1, m + 1): for j in range(1, n + 1): # p[j-2] 是被 * 修饰的字符, 比如 "a*" 里的 a if p[j - 1] == "*": # 选择 1: a* 匹配 0 次 → 把 "a*" 整个去掉 dp[i][j] = dp[i][j - 2] if p[j - 2] in (s[i - 1], "."): # 选择 2: a* 匹配 s[i-1] 这一个, 但 pattern 保留 (还能继续 # 匹配更多) dp[i][j] = dp[i][j] or dp[i - 1][j] elif p[j - 1] in (s[i - 1], "."): dp[i][j] = dp[i - 1][j - 1] # 普通字符 / "." 匹配: 各吃一个 return dp[m][n]

记:x*: 匹配 0 次 → dp[i][j-2]; 匹配至少 1 次 → 当前字符能配 x 并且 dp[i-1][j]。

9. 识别信号: 看到什么, 就想到 2D DP

题目特征statetransition / 填表顺序
grid 上只能往右 / 往下, 数路径或求最优dp[i][j] = 到 (i, j)上 + 左 (或 min); 一行一行填
0/1 矩阵最大正方形以 (i, j) 为右下角的边长min(上, 左, 左上) + 1
两个字符串: 公共子序列、编辑距离、匹配dp[i][j] = 前 i 个和前 j 个看两个末尾字符; 左上 / 上 / 左
回文子串 (最长 / 个数)中心扩展; 或 dp[i][j] = s[i..j] 是否回文dp[i+1][j-1]; i 从大到小
正则 / 通配符匹配dp[i][j] = 前 i 个能否被前 j 个匹配* 两种选择: 0 次 / 至少 1 次
区间上的最优 (戳气球、合并石头)dp[i][j] = 区间 [i, j] 的最优枚举最后一步 k; 按区间长度从短到长

判断 dp 是几维: 看 brute force recursion 里有几个参数在变。两个字符串几乎一定是 dp[i][j]。
