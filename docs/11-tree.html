11 · Binary Tree / BST

主线: tree 题 = "假设左、右子树已经算好, 当前 node 怎么合并"。信息从下往上流 → post-order 返回值; 从上往下流 → pre-order 传参数。

概念链: 第一性原理 → Maximum Depth (最基础的 post-order) → Diameter (返回值 ≠ 答案, nonlocal) → Max Path Sum (返回单边, 拐点更新答案) → Validate BST (自顶向下传区间) → Level Order / Right Side View / Zigzag (BFS 分层) → LCA (返回值语义: 找到的 p/q) → Kth Smallest (BST inorder = sorted) → Serialize / Deserialize (pre-order + None 标记)。

0. 第一性原理: tree 题只有两种信息流向

tree 是递归定义的: 一棵树 = 一个 node + 左子树 + 右子树。所以几乎所有 tree 题都能写成 "我只管当前这个 node, 子树的事交给递归"。关键是想清楚: 当前 node 需要谁告诉它什么。

brute force 在浪费什么。对每个 node 单独问一遍"以你为根, 答案是多少" (比如重新数一遍 height, 重新扫一遍子树找 max/min), 每次都从这个 node 往下重新走。子树里的信息本来可以被算一次、带上来复用, 暴力却让每个 node 被它的所有祖先各走一遍: 总共 O(n · h), 链状时 O(n²)。

pattern 怎么消掉它。两种做法, 对应两种信息流向:

(1) 自底向上 (post-order): 先递归拿到 L、R, 再合并。子树的信息作为返回值被带上来, 每个 node 只访问一次。(2) 自顶向下 (pre-order): 先用祖先传来的参数检查自己, 再把更新后的参数传给孩子。祖先的信息作为参数被带下去, 同样每个 node 只访问一次。

class TreeNode: def __init__(self, val=0, left=None, right=None): self.val, self.left, self.right = val, left, right# 模板 A: 自底向上 (post-order)。返回值 = 这棵子树的"摘要"def solve(node): if not node: return BASE # None 的摘要: depth 0 / gain 0 / None L = solve(node.left) # 假设: 左子树已经算好 R = solve(node.right) # 假设: 右子树已经算好 return merge(node.val, L, R) # 当前 node 只做合并: L、R -> 自己的摘要# 模板 B: 自顶向下 (pre-order)。参数 = 祖先传下来的"约束"def check(node, constraint): if not node: return True if violates(node, constraint): # 先用约束检查自己 return False return (check(node.left, tighten(constraint, node, "L")) and check(node.right, tighten(constraint, node, "R"))) # 把更严的约束传给孩子

两个常见补充: (a) 答案不一定等于返回值 (见 Diameter / Max Path Sum), 这时答案放在 nonlocal 变量里, 在 node 处更新; (b) 需要"按层"的题用 BFS (deque), 不用递归。

Python 注意: 递归深度默认约 1000, 链状 tree 会 RecursionError。面试里先口头说一句, 需要时 sys.setrecursionlimit(10**5)。

记:看到 tree 先问两句: node 需要祖先给它什么 (参数)? 需要子树给它什么 (返回值)? 答完这两句, 代码骨架就出来了。

1. Maximum Depth of Binary Tree: post-order 最小模板

题目: 求 tree 的最大深度 (root 到最远 leaf 的 node 数)。例: [3, 9, 20, None, None, 15, 7] → 3。

Brute force: 枚举每条 root → leaf 路径, 数 node 个数取最大。每条路径都重新走一遍共同的前缀, O(叶子数 × h), 还要存路径。浪费: 上面几层被每条路径重复走。

关键观察: 一棵树的深度只取决于它两个孩子子树的深度, 和上面是什么无关。所以让每个 node 返回自己子树的深度, 父亲拿到后 +1 即可。

def maxDepth(root): if not root: return 0 # base: None 的深度是 0 return 1 + max(maxDepth(root.left), # 左子树已算好 maxDepth(root.right)) # 右子树已算好; +1 = 自己这层

Time O(n): 每个 node 恰好进来一次, 做 O(1) 合并。Space O(h): 递归栈深度 = tree 高度 (平衡 O(log n), 链状 O(n))。

记:post-order = 先 L、R, 后合并。None → base case, 通常是 0。后面每一题只是把 "摘要" 换了。

2. Diameter of Binary Tree: 返回值 ≠ 答案

题目: 求 tree 中任意两个 node 之间最长路径的边数 (路径不一定过 root)。例: [1,2,3,4,5,None,None,6,None,None,7] → 4 (路径 6-4-2-5-7)。

相比上一题: 多了一个条件 —— 答案不再是根的返回值。最长路径可能在任何一个 node "拐弯"。改动: 递归函数仍返回 height, 另用 nonlocal best 记答案。

Brute force: 对每个 node, 调一次 height(left) 和 height(right) 算 L + R, 再递归到孩子。每个 node 被它所有祖先的 height() 各走一次, 总共 Σ(depth + 1), 链状 O(n²)。

关键观察: 经过 node 的最长路径 = 左链 + 右链 = height(L) + height(R)。而 height(L)、height(R) 恰好是后序遍历本来就要算的返回值 —— 顺手用一下就行。

def diameterOfBinaryTree(root): best = 0 # 答案: 全局记录, 不是递归的返回值 def height(node): # 返回值: 以 node 为顶向下的最长链 (点数) nonlocal best if not node: return 0 L = height(node.left) R = height(node.right) best = max(best, L + R) # 拐点: 经过 node 的路径 = 左链 + 右链 (边数) return 1 + max(L, R) # 给父亲: 路径不能分叉, 只能带一边上去 height(root) return best

Time O(n)。Space O(h)。注意两个量的差别: 返回给父亲的 1 + max(L, R) 只能走一边 (路径不能分叉), 而答案候选 L + R 两边都用。

记:递归返回的是 "能延伸给父亲的东西", 答案是 "在这个 node 拐弯的东西"。两者不同就用 nonlocal 记答案。

3. Binary Tree Maximum Path Sum: 返回单边最大贡献

题目: 路径 = 树里任意相连的 node 序列 (不能分叉, 不一定过 root), 求路径上 node 值之和的最大值。node 值可以为负。例: [-10,-5,20,None,None,15,7] → 42 (15 + 20 + 7)。

相比上一题: 把 "边数" 换成 "node 值之和", 多了负数。改两行: (1) 孩子的 gain 取 max(·, 0), 负的链不如不接; (2) best 初值是 -inf。

Brute force: 枚举所有 node 对 (u, v), 沿树求路径和: O(n²) 对, 每对 O(n) → O(n³) (稍优化 O(n²))。浪费: 同一条向下的链被不同的 (u, v) 反复求和; 而"以 node 为顶向下的最大链和"只取决于子树, 算一次就够。

关键观察: 路径有一个最高的 node (拐点)。枚举拐点 = 枚举所有 node, 在拐点处答案 = node.val + 左链 + 右链。而给父亲返回的链只能选一边。

def maxPathSum(root): best = float("-inf") # 答案: 全局; 值可负, 初值是 -inf 不是 0 def gain(node): # 返回值: 以 node 为顶、只往下走一条链的最大和 nonlocal best if not node: return 0 L = max(gain(node.left), 0) # 改动 1: 负的链不如不要 (clamp 到 0) R = max(gain(node.right), 0) best = max(best, node.val + L + R) # 拐点: 两边都用 -> 候选答案 return node.val + max(L, R) # 给父亲: 只能选一边 gain(root) return best

Time O(n)。Space O(h)。

记:path 类题固定写法: gain 返回单边 (含 clamp), 答案在拐点用 node.val + L + R 更新 nonlocal。

4. Validate Binary Search Tree: 自顶向下传区间

题目: 判断是否是合法 BST (每个 node 的左子树全部 < node < 右子树全部)。例: [5,3,8,2,6,None,None,1] → False (6 在 5 的左子树里却 > 5)。

相比前面: 信息流向反过来了。node 是否合法取决于祖先, 不取决于子树, 所以用 pre-order 传参数。改动: 递归多两个参数 (low, high)。

Brute force: 对每个 node, 扫描整棵左子树确认最大值 < node, 扫描整棵右子树确认最小值 > node。每个 node 扫一遍子树, O(n · h), 链状 O(n²)。浪费: 反复遍历子树, 只为得到一个 max / min。

关键观察: 向左走一步, 上界收紧成 node.val; 向右走一步, 下界收紧成 node.val。把所有祖先的约束压成一个开区间, 每个 node 只做一次比较。

def isValidBST(root): def ok(node, low, high): # 参数: node 必须在开区间 (low, high) 内 if not node: return True if not (low < node.val < high): # 违反祖先传下来的约束 return False return (ok(node.left, low, node.val) and # 向左: 上界收紧成 node.val ok(node.right, node.val, high)) # 向右: 下界收紧成 node.val return ok(root, float("-inf"), float("inf"))

Time O(n)。Space O(h)。区间必须是开区间 (BST 通常不允许重复值)。另一种写法: inorder 遍历检查严格递增, 见第 7 节。

记:每个 node 的合法性依赖祖先 → 自顶向下传参数。传的是"压缩后的约束", 不是整条祖先链。

5. Level Order / Right Side View / Zigzag: BFS 分层

题目: 按层输出 node 值。例: [1,2,3,4,5,None,None,6] → [[1],[2,3],[4,5],[6]]。变体: Right Side View 每层只取最右一个 ([1,3,5,6]); Zigzag 奇数层反向 ([[1],[3,2],[4,5],[6]])。

相比前面: 信号变了 —— 题目问的是"按层 / 第几层 / 最短", 这不是子树性质, 是层的性质。用 deque 做 BFS, 关键是怎么知道"这一层结束了"。

Brute force: 对每个深度 d, 从 root 重新往下走 d 层收集 node: O(n · h)。浪费: 每一层都重新走一遍上面所有层。BFS 的队列天然按层推进: 弹出一层的同时把下一层排到队尾。

关键观察: 每轮 while 开始时, queue 里恰好是一整层。先记下 len(q), 恰好弹 n 个, 就是这一层; 这期间 push 进去的孩子留给下一轮。

from collections import dequedef levelOrder(root): res = [] if not root: return res q = deque([root]) while q: level = [] for _ in range(len(q)): # len(q) 只算一次 = 这一层的 node 数 node = q.popleft() level.append(node.val) if node.left: q.append(node.left) # 孩子排在队尾 = 下一层 if node.right: q.append(node.right) res.append(level) return resdef rightSideView(root): # 变体 1: 每层只留最后一个 res = [] if not root: return res q = deque([root]) while q: last = None for _ in range(len(q)): node = q.popleft() last = node.val # 改动: 不收集整层, 只记最后弹出的 if node.left: q.append(node.left) if node.right: q.append(node.right) res.append(last) return resdef zigzagLevelOrder(root): # 变体 2: 奇数层反转 res = [] if not root: return res q = deque([root]) while q: level = [] for _ in range(len(q)): node = q.popleft() level.append(node.val) if node.left: q.append(node.left) if node.right: q.append(node.right) if len(res) % 2 == 1: # 改动: 第 0 层不反转, 第 1 层反转 ... level.reverse() res.append(level) return res

Time O(n): 每个 node 入队、出队各一次。Space O(w): queue 最大 = 最宽的一层 (完全二叉树约 n / 2)。

Right Side View 的陷阱: 右边没有 node 时, 左子树的 node 会露出来 (本例的 5、6)。所以不能只沿着 right 指针走, 要取每层最后一个。

记:按层 → deque + for _ in range(len(q))。变体只改一行: 每层收集什么 (整层 / 最后一个 / 反转)。

6. Lowest Common Ancestor of a Binary Tree: 返回值的语义

题目: 给定 tree 和 node p、q, 求它们的最近公共祖先 (一个 node 也算自己的祖先)。例: [3,5,1,6,2], p = 6, q = 2 → 5。

相比 Diameter: 返回的不再是数字, 而是 node。要先定义返回值的语义: "在 root 这棵子树里找到的 p 或 q; 都没找到返回 None; 两个都找到了返回它们的 LCA"。

Brute force: 对每个 node, 检查 p、q 是否都在它的子树里, 取最深的那个: O(n²)。更好一点: 找出 root → p 和 root → q 两条路径再比较公共前缀, O(n) 但要存路径。浪费: 反复问"p 在我下面吗"; 返回值可以一次把答案带上来。

关键观察: 合并只有三种情况 (见图): 左右都找到 → 当前 node 就是拐点; 只有一边 → 原样往上传; node 自己就是 p/q → 直接返回自己。

def lowestCommonAncestor(root, p, q): # 返回值语义: root 子树里"找到的 p 或 q"; 两个都在 -> 它们的 LCA; 都不在 -> None if not root or root is p or root is q: return root # 遇到 p/q 直接返回 (另一个在下面则它就是 LCA) L = lowestCommonAncestor(root.left, p, q) R = lowestCommonAncestor(root.right, p, q) if L and R: # p、q 分居两侧: root 就是拐点 return root return L or R # 只有一侧有: 原样往上传; 都没有: Nonedef lcaBST(root, p, q): # BST 版: 大小关系直接告诉你往哪走 while root: if p.val < root.val and q.val < root.val: root = root.left elif p.val > root.val and q.val > root.val: root = root.right else: return root # 分叉点

Time O(n)。Space O(h)。BST 版本不需要返回值: 大小关系直接告诉你往哪走, O(h)。

记:返回值语义写清楚就不会乱: "这棵子树里找到的 p/q"。合并 = if L and R: return root; return L or R。

7. Kth Smallest Element in a BST: inorder = sorted

题目: BST 里第 k 小的值。例: [5,3,6,2,4,None,None,1], k = 3 → 3。

相比前面: 第一次用到 BST 的性质。BST 保证 "左子树全部 < node < 右子树全部", 所以 inorder (左 → 自己 → 右) 读出来就是升序。

Brute force: 遍历全部 node 收集进 list, sort, 取第 k 个: O(n log n) 时间, O(n) 空间。浪费: BST 本来就是有序的, sort 白做; 而且只要前 k 个, 却遍历了全部。

关键观察: 用显式 stack 做 iterative inorder, 弹出的顺序就是从小到大, 弹到第 k 个就停。

def kthSmallest(root, k): stack = [] # 栈里是"还没处理自己、但已经在往左走的祖先" node = root while stack or node: while node: # 一路往左走到底, 路上的祖先全压栈 stack.append(node) node = node.left node = stack.pop() # 弹出 = inorder 的下一个 (比已弹出的都大) k -= 1 if k == 0: return node.val # 数到第 k 个就停, 不用遍历完 node = node.right # 处理完自己, 转去右子树

Time O(h + k): 先往左走 h 层, 然后弹 k 次 (每次弹出摊到的 push 总共不超过 n)。Space O(h)。

顺带: Validate BST 也可以用 inorder, 遍历时检查每个值严格大于上一个值。多次查询第 k 小 / 频繁插入删除时, 在每个 node 额外存子树大小 (一句话带过, 不展开)。

记:BST + 有序 / 第 k / 范围 → inorder。iterative 版 stack 可以提前停, 不用遍历完。

8. Serialize and Deserialize Binary Tree: pre-order + None 标记

题目: 把 tree 转成字符串, 再从字符串还原成同样的 tree。例: [1,2,3,None,None,4,5] ↔ "1,2,#,#,3,4,#,#,5,#,#"。

相比前面: 综合题。把 pre-order 的递归结构拍平成线性序列, 再用同样的递归结构还原。新东西只有一个: None 也要写一个标记。

Brute force: 层序存成数组, 下标 2i+1、2i+2 找孩子。完全树没问题, 但链状 tree 要 O(2^h) 个格子。浪费: 为不存在的位置留了一大堆空格。pre-order + "#" 只为每个 None 存一个 token, 总共 n 个 node + (n+1) 个 None = O(n)。

关键观察: 有了 "#" 之后, 每棵子树都是一段连续 token 且自己知道在哪里结束。deserialize 时 left = build() 吃掉左子树的所有 token, 剩下的正好是右子树的。

class Codec: def serialize(self, root): out = [] def dfs(node): # pre-order: 先写自己, 再写左, 再写右 if not node: out.append("#") # None 也写一个标记: 子树边界靠它确定 return out.append(str(node.val)) dfs(node.left) dfs(node.right) dfs(root) return ",".join(out) def deserialize(self, data): it = iter(data.split(",")) # iterator: next() 消费一个 token, 共享读指针 def build(): v = next(it) if v == "#": return None node = TreeNode(int(v)) node.left = build() # 先建左 (吃掉左子树的所有 token) ... node.right = build() # ... 剩下的 token 正好是右子树的 return node return build()

Time O(n) (serialize 和 deserialize 都是每个 node / token 一次)。Space O(n) 存输出, 递归栈 O(h)。

值里如果有逗号或负号, 用 "," 分隔就够了 (int("-5") 没问题); 另有 BFS 层序版本, 思路一样, 这里不展开。

记:序列化 = 先序 + None 标记; 反序列化 = iterator + 同样的递归。left = build() 在 right = build() 之前, 顺序不能换。

面试提醒: (1) 递归写完先走一个 None 和一个单 node 的 case; (2) 全局答案用 nonlocal, 初值要想清楚 (-inf 还是 0); (3) 链状 tree 会撞递归上限, 口头提一句; (4) BFS 里 for _ in range(len(q)) 的 len(q) 不要写成每次重新算的 while 条件。
