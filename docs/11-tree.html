11 · Binary Tree / BST

这篇讲什么

binary tree (二叉树) 的每个 node 最多有两个孩子: left 和 right。面试里的 tree 题, 几乎都能用 recursion (递归) 解决, 而且写法很固定。

关键的思路是: 不要去想整棵树。只想一个 node: 假设它的左子树、右子树的答案已经算好了, 当前这个 node 要怎么用这两个答案, 算出自己的答案? 剩下的交给 recursion。

信息在 tree 里只有两种流向:

  • 自底向上 (post-order): 先算孩子, 孩子把结果返回给 parent。比如高度、子树的和。本篇大部分题是这种。
  • 自顶向下 (pre-order): parent 把信息当成参数传给孩子。比如"你的值必须在 (low, high) 之间"。

另外一种是一层一层地处理, 用 BFS (queue), 第 5 题会讲。

1. Maximum Depth of Binary Tree

题目在问什么

给一棵 binary tree, 求它的最大深度: 从 root 走到最远的叶子, 一路上经过几个 node (包括 root 和叶子)。

看例子

Brute force

列出从 root 到每个叶子的所有路径, 取最长的。这其实已经是 O(n) 了 (每个 node 走一次), 但写起来要维护路径, 很麻烦。这题重点不在优化, 而在学会 recursion 的思考方式。

Intuition: 只想一个 node

站在某个 node 上想: 如果我已经知道左子树的深度是 L, 右子树的深度是 R, 那么以我为根的这棵树, 深度是多少?

答案是 1 + max(L, R): 我自己算 1 层, 再加上更深的那一边。

至于 L 和 R 怎么来的, 不用管, 它们就是对左、右孩子调用同一个函数。recursion 会负责把它们算出来。

最后要想清楚最简单的情况 (base case): 空树的深度是 0。

算法

  1. maxDepth(node): 如果 node 是 None, 返回 0。
  2. 否则返回 1 + max(maxDepth(node.left), maxDepth(node.right))。

手动走一遍

复杂度

Time O(n): 每个 node 访问一次。Space O(h): recursion 的深度是树高 h, 最坏 (一条链) 是 O(n)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def maxDepth(root): if not root: return 0 # base: None 的深度是 0 return 1 + max(maxDepth(root.left), # 左子树已算好 # 右子树已算好; +1 = 自己这层 maxDepth(root.right))

记:tree recursion: 假设左右子树的答案已经算好, 只想当前 node 怎么合并。别忘了 base case (None)。

把第 1 题抽象一下: tree recursion 的模板

每道 tree 题写之前, 先回答三个问题:

  1. 函数返回什么? (第 1 题: 这棵子树的深度)
  2. 当前 node 怎么用左右孩子的返回值? (第 1 题: 1 + max(L, R))
  3. 空 node 返回什么? (第 1 题: 0)

如果信息是从上往下传的 (比如第 4 题的范围), 就把它写成函数的参数。

两种模板的代码
class TreeNode: def __init__(self, val=0, left=None, right=None): self.val, self.left, self.right = val, left, right# 模板 A: 自底向上 (post-order)。返回值 = 这棵子树的"摘要"def solve(node): if not node: return BASE # None 的摘要: depth 0 / gain 0 / None L = solve(node.left) # 假设: 左子树已经算好 R = solve(node.right) # 假设: 右子树已经算好 return merge(node.val, L, R) # 当前 node 只做合并: L、R -> 自己的摘要# 模板 B: 自顶向下 (pre-order)。参数 = 祖先传下来的"约束"def check(node, constraint): if not node: return True if violates(node, constraint): # 先用约束检查自己 return False return (check(node.left, tighten(constraint, node, "L")) and # 把更严的约束传给孩子 check(node.right, tighten(constraint, node, "R")))

记:写 tree recursion 前先定三件事: 返回什么、怎么合并、空 node 返回什么。

2. Diameter of Binary Tree

题目在问什么

diameter (直径) 是 tree 里任意两个 node 之间最长的路径, 用边的条数来算。这条路径不一定经过 root。

看例子

注意路径可以"拐弯": 从左子树往上走到某个 node, 再往下走到右子树。

Brute force

对每个 node, 都把它当成拐弯的点: 算它左子树的深度 L 和右子树的深度 R, 经过它的最长路径是 L + R。取所有 node 里最大的。

如果每个 node 都单独调用第 1 题去算深度, 每次是 O(n), 总共 O(n²)。浪费: 下面的 node 的深度被反复算了很多次。

Intuition: 算深度的同时, 顺便更新答案

第 1 题的 recursion 本来就会对每个 node 算出 L 和 R。那就在算的时候, 顺便看一下 L + R, 更新一个全局的最大值 best。

这里出现了一个很重要的区别: 函数返回的东西 (深度), 和最终要的答案 (直径), 不是同一个东西。

  • 返回给 parent 的是深度 1 + max(L, R): parent 只能接上其中一边, 路径不能分叉。
  • 答案是在当前 node 拐弯的路径 L + R: 两边都用上。它不返回, 只用来更新 best。

算法

  1. best = 0。height(node): None 返回 0。
  2. L = height(left), R = height(right)。best = max(best, L + R)。
  3. 返回 1 + max(L, R)。调用 height(root), 返回 best。

手动走一遍

复杂度

Time O(n), Space O(h)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def diameterOfBinaryTree(root): best = 0 # 答案: 全局记录, 不是递归的返回值 def height(node): # 返回值: 以 node 为顶向下的最长链 (点数) nonlocal best if not node: return 0 L = height(node.left) R = height(node.right) # 拐点: 经过 node 的路径 = 左链 + 右链 (边数) best = max(best, L + R) return 1 + max(L, R) # 给父亲: 路径不能分叉, 只能带一边上去 height(root) return best

记:返回值 ≠ 答案: 返回给 parent 的只能是一边 (不能分叉); 在当前 node 拐弯的路径用两边, 用来更新全局 best。

3. Binary Tree Maximum Path Sum

题目在问什么

path 是沿着边走的一串 node, 每个 node 最多经过一次, 可以拐弯, 不必经过 root。求 node 值加起来最大的 path。node 的值可能是负数。

看例子

Brute force

枚举所有两个 node 之间的路径, O(n²) 条, 每条求和。

Intuition: 和第 2 题一模一样的结构

还是"返回一边, 答案用两边":

  • 函数返回: 从当前 node 往下走 (只走一边) 能得到的最大和, 叫 gain。
  • 答案: 在当前 node 拐弯 = node.val + 左边的 gain + 右边的 gain, 用来更新 best。

新问题是负数: 如果某一边的 gain 是负的, 接上它只会更小, 不如不接。所以用 max(gain, 0), 负的就当 0 (不走那边)。

best 的初始值要是 -∞, 不能是 0: 如果所有 node 都是负数, 答案是最大的那个负数。

算法

  1. best = -inf。gain(node): None 返回 0。
  2. L = max(gain(left), 0), R = max(gain(right), 0)。
  3. best = max(best, node.val + L + R)。返回 node.val + max(L, R)。

手动走一遍

复杂度

Time O(n), Space O(h)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def maxPathSum(root): best = float("-inf") # 答案: 全局; 值可负, 初值是 -inf 不是 0 # 返回值: 以 node 为顶、只往下走一条链的最大和 def gain(node): nonlocal best if not node: return 0 L = max(gain(node.left), 0) # 改动 1: 负的链不如不要 (clamp 到 0) R = max(gain(node.right), 0) best = max(best, node.val + L + R) # 拐点: 两边都用 -> 候选答案 return node.val + max(L, R) # 给父亲: 只能选一边 gain(root) return best

记:path 类的 tree 题: 返回"单边最大", 在拐弯处用两边更新答案。负的贡献用 max(·, 0) 去掉, best 从 -inf 开始。

4. Validate Binary Search Tree

题目在问什么

判断一棵 binary tree 是不是 BST (binary search tree)。BST 的规则: 每个 node 的左子树里所有 node 都比它小, 右子树里所有 node 都比它大。

看例子

Example 3 是最容易错的地方: 3 和它的 parent 6 比没问题 (3 < 6), 但 3 在 5 的右子树里, 必须大于 5。所以只和 parent 比是不够的。

Brute force

对每个 node, 找出它左子树的最大值和右子树的最小值, 检查是否满足规则。每个 node 都要扫一遍子树, O(n²)。

Intuition: 往下传一个"合法范围"

换个角度: 每个 node 的值都必须落在一个范围 (low, high) 里, 这个范围是由它所有的祖先决定的。

  • root 的范围是 (-∞, +∞)。
  • 往左走: 孩子必须比当前 node 小, 所以上界变成当前值: (low, node.val)。
  • 往右走: 孩子必须比当前 node 大, 所以下界变成当前值: (node.val, high)。

这次信息是从上往下流的, 所以把范围写成函数的参数 (pre-order)。和前三题的方向相反。

算法

  1. ok(node, low, high): None 返回 True。
  2. 如果 not (low < node.val < high), 返回 False。
  3. 返回 ok(left, low, node.val) and ok(right, node.val, high)。调用 ok(root, -inf, inf)。

手动走一遍

复杂度

Time O(n), Space O(h)。另一种做法: BST 的 inorder 一定是严格递增的 (见第 7 题), 检查 inorder 是否递增也可以。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def isValidBST(root): # 参数: node 必须在开区间 (low, high) 内 def ok(node, low, high): if not node: return True if not (low < node.val < high): # 违反祖先传下来的约束 return False # 向左: 上界收紧成 node.val return (ok(node.left, low, node.val) and # 向右: 下界收紧成 node.val ok(node.right, node.val, high)) return ok(root, float("-inf"), float("inf"))

记:约束来自所有祖先, 而不只是 parent: 把约束写成参数, 从上往下传。

5. Binary Tree Level Order Traversal (+ Right Side View, Zigzag)

题目在问什么

Level Order: 按层输出 node 的值, 每层从左到右, 返回一个 list of list。

两个常见变体: Right Side View (从右边看过去, 每层只能看到最右边的那个); Zigzag (第一层从左到右, 第二层从右到左, 交替)。

看例子

Brute force

用 recursion 记录每个 node 的深度, 按深度分组。可以做, 但"一层一层"本身就是 BFS 的天然顺序, 用 queue 更直接。

Intuition: BFS, 每一轮处理一整层

BFS (breadth-first search, 广度优先) 用一个 queue: 先放进 root; 每次从队头取一个 node, 把它的孩子放到队尾。这样 node 出队的顺序就是一层一层、从左到右的。

但我们还需要知道"一层在哪里结束"。技巧是: 每一轮开始时, 先记下 len(q), 它正好是这一层的 node 数。然后只 pop 这么多个, 这一轮 pop 出来的就是完整的一层。这一轮里新加进去的孩子, 留给下一轮。

有了"一层"之后, 两个变体都很简单: Right Side View 只取每层的最后一个; Zigzag 把奇数层反过来。

算法

  1. q = deque([root])。
  2. 当 q 不空: size = len(q), level = []。循环 size 次: popleft 一个 node, 值放进 level, 把它的孩子 append 到 q。
  3. 把 level 放进结果。

手动走一遍

复杂度

Time O(n), Space O(w), w 是最宽那一层的 node 数。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
from collections import dequedef levelOrder(root): res = [] if not root: return res q = deque([root]) while q: level = [] for _ in range(len(q)): # len(q) 只算一次 = 这一层的 node 数 node = q.popleft() level.append(node.val) if node.left: q.append(node.left) # 孩子排在队尾 = 下一层 if node.right: q.append(node.right) res.append(level) return resdef rightSideView(root): # 变体 1: 每层只留最后一个 res = [] if not root: return res q = deque([root]) while q: last = None for _ in range(len(q)): node = q.popleft() last = node.val # 改动: 不收集整层, 只记最后弹出的 if node.left: q.append(node.left) if node.right: q.append(node.right) res.append(last) return resdef zigzagLevelOrder(root): # 变体 2: 奇数层反转 res = [] if not root: return res q = deque([root]) while q: level = [] for _ in range(len(q)): node = q.popleft() level.append(node.val) if node.left: q.append(node.left) if node.right: q.append(node.right) if len(res) % 2 == 1: # 改动: 第 0 层不反转, 第 1 层反转 ... level.reverse() res.append(level) return res

记:按层处理: BFS + 每轮先记 len(q)。右视图取每层最后一个, zigzag 把奇数层反转。

6. Lowest Common Ancestor of a Binary Tree

题目在问什么

给一棵 binary tree (不是 BST) 和其中两个 node p、q。找它们的 LCA (lowest common ancestor, 最近公共祖先): 同时是 p 和 q 的祖先的 node 里, 最深的那个。一个 node 也算是它自己的祖先。

看例子

Example 2 里 q = 4 在 p = 5 的子树里, 所以 LCA 就是 p 自己。

Brute force

分别找出从 root 到 p 和到 q 的路径 (两次 DFS), 然后比较两条路径, 最后一个相同的 node 就是 LCA。O(n) 时间, 但要存两条路径。

Intuition: 让每个子树报告"我这里有没有 p 或 q"

设计函数的返回值: lca(node) 在 node 这棵子树里找 p 和 q, 返回:

  • 如果 node 本身就是 p 或 q, 返回 node。
  • 否则看左右孩子的返回值。两边都不是 None: p 和 q 分别在左右两边, 当前 node 就是 LCA, 返回 node。
  • 只有一边不是 None: 把那一边的结果原样往上传。
  • 两边都是 None: 返回 None。

返回值的意思是"这棵子树里找到的 p、q 或者 LCA"。第一次出现"两边都不是 None"的那个 node, 就是 LCA, 之后它会被一路原样传到 root。

算法

  1. node 是 None、p 或 q: 返回 node。
  2. L = lca(left), R = lca(right)。
  3. L 和 R 都有: 返回 node。否则返回 L or R。

手动走一遍

复杂度

Time O(n), Space O(h)。如果是 BST, 可以直接比大小: p、q 都比当前小就往左, 都大就往右, 否则当前就是 LCA, O(h)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def lowestCommonAncestor(root, p, q): # 返回值语义: root 子树里"找到的 p 或 q"; 两个都在 -> 它们的 LCA; 都不在 -> None if not root or root is p or root is q: # 遇到 p/q 直接返回 (另一个在下面则它就是 LCA) return root L = lowestCommonAncestor(root.left, p, q) R = lowestCommonAncestor(root.right, p, q) if L and R: # p、q 分居两侧: root 就是拐点 return root return L or R # 只有一侧有: 原样往上传; 都没有: Nonedef lcaBST(root, p, q): # BST 版: 大小关系直接告诉你往哪走 while root: if p.val < root.val and q.val < root.val: root = root.left elif p.val > root.val and q.val > root.val: root = root.right else: return root # 分叉点

记:返回值的含义可以自己设计。LCA: 子树里找到了 p / q 就返回它; 左右都找到了, 当前 node 就是答案。

7. Kth Smallest Element in a BST

题目在问什么

给一棵 BST 和整数 k, 返回第 k 小的值 (k 从 1 开始)。

看例子

Brute force

遍历所有 node, 收集值, 排序, 取第 k 个。O(n log n)。浪费: BST 本身已经包含了大小顺序。

Intuition: BST 的 inorder 就是从小到大

inorder (中序) 遍历的顺序是: 先左子树, 再当前 node, 再右子树。

在 BST 里, 左子树都比当前小, 右子树都比当前大。所以 inorder 访问的顺序正好是从小到大。第 k 个访问到的就是答案, 访问到就可以停, 不用遍历完。

用 stack 写 iterative 的 inorder, 方便在第 k 个时停下: 一路往左走, 把经过的 node 都 push; 走到底就 pop 一个 (这就是下一个最小的), 然后转去它的右子树。

算法

  1. stack = [], cur = root。
  2. 当 cur 或 stack 不空: 一路往左, 把 cur push 进 stack, cur = cur.left。
  3. pop 出一个 node, k 减 1; k 变成 0 就返回 node.val。否则 cur = node.right。

手动走一遍

复杂度

Time O(h + k): 先往左走到底 h 步, 再 pop k 次。Space O(h)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def kthSmallest(root, k): # 栈里是"还没处理自己、但已经在往左走的祖先" stack = [] node = root while stack or node: while node: # 一路往左走到底, 路上的祖先全压栈 stack.append(node) node = node.left # 弹出 = inorder 的下一个 (比已弹出的都大) node = stack.pop() k -= 1 if k == 0: return node.val # 数到第 k 个就停, 不用遍历完 node = node.right # 处理完自己, 转去右子树

记:BST + 第 k 小 / 有序 / 检查合法: 用 inorder, 它就是从小到大的顺序。

8. Serialize and Deserialize Binary Tree

题目在问什么

设计两个函数: serialize 把一棵 tree 变成一个字符串, deserialize 把这个字符串变回一模一样的 tree。字符串的格式由你自己决定。

看例子

Brute force

只记录值的遍历顺序 (比如只有 pre-order) 是不够的: 不同形状的 tree 可能得到同样的序列, 没法还原。比如 [1,2] (2 是左孩子) 和 [1,null,2] (2 是右孩子) 的 pre-order 都是 1, 2。

Intuition: pre-order, 并且把空的位置也写出来

问题出在不知道哪里是空的。只要把空 node 也写下来 (用 #), 序列就唯一确定了 tree 的形状。

用 pre-order 写: 先写当前 node, 再写整个左子树, 再写整个右子树。空 node 写 #。

还原的时候按同样的顺序读: 读到一个值, 就新建 node; 然后递归地读出它的左子树 (左子树的 token 正好接在后面), 再读出右子树。读到 # 就返回 None。

算法

  1. serialize(node): None 写 #; 否则写 node.val, 再 serialize(left), serialize(right)。用逗号连起来。
  2. deserialize: 把字符串切成 token, 用一个 iterator 一个一个读。build(): 读一个 token, 是 # 返回 None; 否则新建 node, node.left = build(), node.right = build()。

复杂度

Time O(n), Space O(n)。也可以用 BFS (level order) 写, 就是 LeetCode 自己用的格式。

class Codec: def serialize(self, root): out = [] def dfs(node): # pre-order: 先写自己, 再写左, 再写右 if not node: out.append("#") # None 也写一个标记: 子树边界靠它确定 return out.append(str(node.val)) dfs(node.left) dfs(node.right) dfs(root) return ",".join(out) def deserialize(self, data): # iterator: next() 消费一个 token, 共享读指针 it = iter(data.split(",")) def build(): v = next(it) if v == "#": return None node = TreeNode(int(v)) node.left = build() # 先建左 (吃掉左子树的所有 token) ... node.right = build() # ... 剩下的 token 正好是右子树的 return node return build()

记:要能唯一还原 tree: 遍历时把空 node 也记下来。pre-order + # 最好写, 还原时按同样的 recursion 顺序读。

9. 识别信号: 看到什么, 就想到什么写法

题目特征做法complexity
高度、节点数、子树和、是否平衡post-order, 返回值往上O(n)
路径可以拐弯 (直径、最大路径和)返回单边, 在拐弯处用两边更新全局 bestO(n²) → O(n)
约束来自祖先 (BST 合法范围、从 root 来的路径和)pre-order, 参数往下传O(n²) → O(n)
按层输出、每层最右、最小深度BFS + 每轮记 len(q)O(n)
两个 node 的最近公共祖先返回"子树里找到的 p / q", 两边都有就是答案O(n)
BST + 有序 / 第 k 小 / 检查合法inorder = 从小到大O(n log n) → O(h + k)
tree 变字符串再还原pre-order + 空标记O(n)

一句话: 先想清楚信息往哪个方向流。往上 → 返回值; 往下 → 参数; 一层一层 → BFS。
