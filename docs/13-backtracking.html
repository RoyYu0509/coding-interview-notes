13 · Backtracking

主线: backtracking = 在 decision tree 上做 DFS。节点 = 一个 partial path, 边 = 一次选择。做选择 → 递归 → 撤销选择; 一定走不通的分支, 进去之前就剪掉。

概念链: Subsets (模板) → Permutations (+ used) → Combination Sum (+ 重复选, + remain 剪枝) → Combination Sum II (+ 同层去重) → Generate Parentheses (约束剪枝) → Letter Combinations (每层候选不同) → Word Search (grid, 原地标记) → N-Queens (多个约束 set)

0. 第一性原理: 暴力在浪费什么, backtracking 怎么消掉

题目要的是 所有 组合 / 排列 / 路径。答案个数本身就是指数级, 所以输出大小就是 time complexity 的下限。能优化的只有一件事: 不要展开一定没有答案的分支。

最直接的暴力是 n 层嵌套 for, 每层选一个, 最后检查合法。它有两个问题。

① n 是 input, 嵌套层数写不出来。解法: 一层递归 = 一层 for, 递归深度 = 层数。

② 先生成完整候选, 再检查。以 3 对括号为例: 一共 2^6 = 64 个串, 合法的只有 5 个。前缀是 ) 的串一开始就注定不合法, 却还要把后面 5 位全展开 (2^5 = 32 个)。backtracking 在每一步选择之前就检查约束, 一旦违反就不进这个分支。

把所有选择画成树就是 decision tree: 根 = 什么都没选; 每个节点 = 已做的选择 (path); 每条边 = 一个选择。backtracking 就是在这棵树上做 DFS: 往下走 = 做选择, 往回走 = 撤销选择。

三件事

path: 已经做过的选择, 一个共用的 list。choices: 此刻还能选什么 (每个选择是一条往下的边)。结束条件: path 什么时候是一个完整答案。

为什么必须撤销

path 只有一个 list, 递归的每一层都在改同一个对象。回到上一层之后, 兄弟分支要看到的是 做选择之前 的 path。不 pop, 兄弟分支就带着上一个分支的选择 (图 0: path 会变成 [1,2,2])。收集答案要 path[:] 复制一份, 否则 res 里存的全是同一个 list 的引用, 最后都变成空 list。

另一种写法是每次传新 list (path + [c]), 不用撤销, 代价是每个节点多 O(n) 的复制。面试默认写 mutate + undo。

通用模板

def backtrack(path, choices): if is_done(path): # 1. 结束条件: path 已经是一个完整答案 res.append(path[:]) # 必须 copy: path 还会继续被改 return for c in choices: # 2. choices: 此刻还能选什么 if not valid(path, c): # 约束剪枝: 这个选择一定走不通, 不进去 continue path.append(c) # 3. 做选择 backtrack(path, next_choices(path, c)) # 4. 递归: 树往下一层 path.pop() # 5. 撤销选择: path 回到 "做选择之前"

Complexity 怎么算

time = decision tree 的节点数 × 每个节点的工作 (通常是 path[:] 的 O(n))。space = 树的深度 (递归栈 + path), 不算输出。剪枝的价值就是让节点数从 "所有候选" 降到 "接近答案数"。

记:backtracking = 树上 DFS。path 是共用 list: 做选择 push, 回来 pop; 收集要 copy。complexity 数节点。

1. Subsets: 每个节点都是答案, start index 防重复

题: nums = [1,2,3] (无重复), 返回所有子集, 共 8 个: [], [1], [1,2], [1,2,3], [1,3], [2], [2,3], [3]。

Brute force: 枚举 bitmask 0 … 2^n−1, 每个 mask 扫 n 位, O(n·2^n)。这其实已经和输出大小一样大, 没有浪费; 但 bitmask 一遇到 "和等于 target" "去重" 这类约束就没法剪枝。所以先用这题把 backtracking 的骨架学会。

关键观察: 子集 = 每个元素选 / 不选。为了不生成 [1,2] 和 [2,1] 两个相同的子集, 规定只能往后选: 选了 nums[i] 之后, 下一层从 i+1 开始。这个 start 就是 choices。

def subsets(nums): res, path = [], [] def dfs(start): res.append(path[:]) # 每个节点本身就是一个答案; copy, 因为 path 之后还会变 for i in range(start, len(nums)): # 只能选 start 之后的: [1,2] 会出现, [2,1] 不会 path.append(nums[i]) # 做选择 dfs(i + 1) # 递归: 下一层只能选 i 之后的 path.pop() # 撤销: 回到做选择之前, 兄弟分支才看到干净的 path dfs(0) return res

等价的 "选 / 不选" 写法 (二叉树, 只有叶子是答案), 适合元素有额外状态的题:

def subsets(nums): # 另一种写法: 每个元素 "选 / 不选" (二叉树) res, path = [], [] def dfs(i): if i == len(nums): # 每个元素都决定完了, 才是叶子 res.append(path[:]) return dfs(i + 1) # 不选 nums[i]: path 不变 path.append(nums[i]) # 选 nums[i] dfs(i + 1) path.pop() # 撤销 dfs(0) return res

Time O(n·2^n): 2^n 个节点, 每个节点 path[:] 复制 O(n)。Space O(n): 递归深度 + path (不算输出)。

记:子集 / 组合: 每层只往后选 (range(start, n), 递归传 i+1); 每个节点都可能是答案。

2. Permutations: 每层从头看, 用 used[] 跳过已选

题: nums = [1,2,3], 返回所有排列, 共 3! = 6 个。

Brute force: 每个位置从 n 个数里选, 共 n^n = 27 个序列, 再过滤出没有重复数字的, O(n^n · n)。浪费: 第 2 层又选了 path 里已有的数, 整棵子树都是废的。

关键观察: 相比 Subsets, 顺序有意义 ([1,2] 和 [2,1] 是两个答案), 所以不能再 "只往后选", 每层都要从头看。改两处: range(start, n) → range(n); 加 used[i] 跳过 path 里已有的数。只有叶子 (len(path) == n) 是答案。

def permute(nums): res, path = [], [] used = [False] * len(nums) # used[i]: nums[i] 已经在 path 里 (比 "x in path" 的 O(n) 快) def dfs(): if len(path) == len(nums): # 每个位置都填好了 res.append(path[:]) return for i in range(len(nums)): # 每一层都从头看: 排列允许先选后面的元素 if used[i]: # 剪枝: 已经用过的不能再用 continue used[i] = True # 做选择: 两个状态一起改 (path 和 used) path.append(nums[i]) dfs() path.pop() # 撤销: 两个状态一起还原 used[i] = False dfs() return res

Time O(n·n!): 叶子 n! 个, 节点总数约 e·n!, 每个叶子复制 O(n)。Space O(n): path + used + 递归栈。

记:排列: 每层 range(n) + used[]; 做选择改两个状态 (path, used), 撤销也要改两个。

3. Combination Sum: 可重复选 => 递归传 i, 不是 i+1

题: candidates = [2,3,5], target = 6, 每个数可以用任意多次, 返回和为 target 的所有组合 (顺序不同算同一个)。答案: [[2,2,2],[3,3]]。

Brute force: 每个数枚举用 0 … target/c 次, 共 (6/2+1)·(6/3+1)·(6/5+1) = 4·3·2 = 24 种, 每种求和检查。浪费: 2 已经用了 4 次 (和 8 > 6), 却还要继续枚举 3 和 5 的次数。

关键观察: 这是 Subsets 加两处改动。① 同一个数能再选: 递归传 i (下一层仍可选 candidates[i]), 而不是 i+1; start 仍然保证不会出现 [3,2]。② 剪枝: 维护 remain = target − sum(path), 排序后一旦 c > remain, 后面更大的数也不行, 直接 break。

def combination_sum(candidates, target): candidates.sort() # 排序: 一旦 c > remain, 后面更大的也不行, 可以 break res, path = [], [] def dfs(start, remain): # remain = target - sum(path), 不用每次重算 sum if remain == 0: # 结束条件: 刚好凑够 res.append(path[:]) return for i in range(start, len(candidates)): c = candidates[i] if c > remain: # 剪枝: 超了; 排过序, 后面的更大, 直接 break break path.append(c) dfs(i, remain - c) # 关键: 传 i (不是 i+1) => 同一个数可以重复选 path.pop() dfs(0, target) return res

Time: 树深最多 target/min(c) 层, 每层最多 n 个分支, 上界 O(n^(target/min)), 实际因为剪枝和 start 小得多。Space O(target/min): 递归深度。

记:元素可重复用: 递归传 i; 每个数只能用一次: 传 i+1。有和的约束: sort + c > remain 就 break。

4. Combination Sum II: 排序 + 同层去重

题: candidates = [1,2,2,3], target = 5, 每个数最多用一次, 候选里有重复值, 答案不能有重复组合。答案: [[1,2,2],[2,3]]。

Brute force: 枚举 2^4 = 16 个子集, 筛出和为 5 的, 再用 set 去重, O(n·2^n)。浪费: 选第一个 2 和选第二个 2 生成的是完全相同的子树, 白白展开了两遍, 最后还要靠 set 去重。

关键观察: 先排序, 相同的值就挨在一起。在 同一层 (同一个 for 循环里), 如果 candidates[i] == candidates[i-1], 说明这个值在这一层已经试过, 子树会一模一样, 跳过。但 i == start 时是 "下一层的第一个", 不是同一层, 必须允许 — 否则 [1,2,2] 出不来。所以条件是 i > start and candidates[i] == candidates[i-1]。

相比上一题改两行: 递归传 i+1 (每个数只用一次); 加这一行去重。

def combination_sum2(candidates, target): candidates.sort() # 排序: 相同的数挨在一起, 才能 "和前一个比" 去重 res, path = [], [] def dfs(start, remain): if remain == 0: res.append(path[:]) return for i in range(start, len(candidates)): if i > start and candidates[i] == candidates[i - 1]: continue # 同一层 (同一个 for 里) 已经试过这个值了, 子树会完全一样 c = candidates[i] if c > remain: break path.append(c) dfs(i + 1, remain - c) # 每个数只能用一次 => 传 i + 1 path.pop() dfs(0, target) return res

Time O(2^n) 上界 (每个元素选 / 不选), 去重后实际更少, 不再需要 set。Space O(n)。

记:有重复元素又要去重: 先 sort, 循环里加 if i > start and nums[i] == nums[i-1]: continue。Subsets II 同样一行。

5. Generate Parentheses: 约束剪枝, 只生成合法前缀

题: 给 n, 生成所有 n 对合法括号。n = 2: ["(())", "()()"]。

Brute force: 2^(2n) 个由 ( ) 组成的串, 逐个检查合法, O(n·4^n)。n = 3 时 64 个串里只有 5 个合法。

关键观察: 一个串合法 ⟺ 每个前缀里 ) 的个数 ≤ ( 的个数, 且最后各 n 个。所以不用事后检查, 每一步只加 "不会破坏前缀" 的字符: ( 要 open_ < n; ) 要 close < open_。两个 if 就是约束剪枝, 树上每个叶子都是答案, 没有一个废叶子。

def generate_parenthesis(n): res, path = [], [] def dfs(open_, close): # open_ / close: path 里已有的 ( 和 ) 的个数 if len(path) == 2 * n: res.append("".join(path)) return if open_ < n: # 剪枝 1: ( 最多 n 个 path.append("(") dfs(open_ + 1, close) path.pop() if close < open_: # 剪枝 2: ) 不能比 ( 多, 否则前缀已经不合法 path.append(")") dfs(open_, close + 1) path.pop() dfs(0, 0) return res

Time O(4^n / √n) 量级 (Catalan 数个答案 × 每个 O(n) 的 join); Space O(n)。

记:构造的串有 "前缀合法性": 把条件写成 if 挡在 push 之前, 不要先生成再检查。

6. Letter Combinations of a Phone Number: 每层候选不同

题: digits = "23", 每个数字对应几个字母, 返回所有字母组合。"2"→abc, "3"→def, 共 3×3 = 9 个。

Brute force: 嵌套 for / itertools.product。问题是 digits 的长度是 input, 嵌套层数写不出来。这里没有任何东西可以剪枝 — 它是纯粹的笛卡尔积。

关键观察: 相比前面几题, choices 不再是 "从 start 往后" 或 "没用过的", 而是由 层数 idx 决定: 第 idx 层的候选 = PHONE[digits[idx]], 和 path 里选了什么无关。所以不需要 start 也不需要 used, 只要一个 idx。backtracking 在这里只是把 "层数不固定的嵌套 for" 写成递归。

def letter_combinations(digits): if not digits: return [] PHONE = {"2": "abc", "3": "def", "4": "ghi", "5": "jkl", "6": "mno", "7": "pqrs", "8": "tuv", "9": "wxyz"} res, path = [], [] def dfs(idx): # idx: 正在决定第几个数字; 层数 = len(digits), 固定 if idx == len(digits): res.append("".join(path)) return for ch in PHONE[digits[idx]]: # choices 取决于层数, 不是 start index: 每层是独立的 "槽" path.append(ch) dfs(idx + 1) path.pop() dfs(0) return res

Time O(4^n · n): n = len(digits), 每位最多 4 个字母, 叶子 ≤ 4^n 个, 每个 join 花 O(n)。Space O(n)。

记:每一位有各自的候选集: 递归的参数是层数 idx, choices = 第 idx 层的候选; 层数固定 = 笛卡尔积。

7. Word Search: grid 上的 backtracking, 原地标记再恢复

题: 在字符 grid 里找 word, 路径是相邻格子 (上下左右), 同一个格子不能用两次。例: board = ABA / BBD, word = ABAD → True。

Brute force: 从每个格子出发枚举所有长度为 L 的路径, 每步 4 个方向, O(R·C·4^L), 最后才比较字母。浪费有两处: 字母不对了还继续走; 每一步都允许走回头路。

关键观察: 这是 Permutations 的 grid 版本。path = 走过的格子序列, "同一格不能用两次" 就是 used[]。grid 里可以直接把 board 当 used: 做选择时把 board[r][c] 改成 "#", 撤销时改回原字母。没有额外的 visited set。剪枝: 越界 / 字母不对 / 已经是 # 都在同一个 if 里返回 False。

def exist(board, word): R, C = len(board), len(board[0]) def dfs(r, c, k): # k: 已经匹配了 word[:k]; 现在要让 (r, c) 匹配 word[k] if k == len(word): # 结束条件: word 全部匹配 return True if not (0 <= r < R and 0 <= c < C) or board[r][c] != word[k]: return False # 剪枝: 越界 / 字母不对 / 已经被标记成 "#" board[r][c] = "#" # 做选择: 原地标记, 当作 used[] (字母里不会有 "#") found = (dfs(r + 1, c, k + 1) or dfs(r - 1, c, k + 1) or dfs(r, c + 1, k + 1) or dfs(r, c - 1, k + 1)) board[r][c] = word[k] # 撤销: 恢复原字母; 找到了也要恢复, 不能留着改过的 board return found return any(dfs(r, c, 0) for r in range(R) for c in range(C))

Time O(R·C·3^L): R·C 个起点, 每个起点最多 L 层, 除第一步外每步最多 3 个方向 (第 4 个是来的方向, 已经是 #)。Space O(L): 只有递归栈, 原地标记不需要 O(R·C) 的 visited。

记:grid + 路径不能重复用: 原地改成 # 当 used, 递归之后改回。找到答案也要先恢复再 return。

8. N-Queens: 多个约束 => 多个 set

题: n×n 棋盘放 n 个皇后, 互相不能同行、同列、同一条对角线。返回所有摆法。n = 4 有 2 个解。

Brute force: 从 16 格里选 4 个, C(16,4) = 1820 种, 逐一检查。每行恰好放一个后是 4^4 = 256 种; 再要求列不重复就是 4! = 24 种 (和 Permutations 一样); 对角线冲突则要靠剪枝在中途发现。

关键观察: 一行放一个皇后, 所以 path[r] = 第 r 行的列, 层数 = 行数, 这就是 Permutations (列不能重复) 再加两个约束。同一条 \ 对角线上所有格子 r − c 相同; 同一条 / 对角线上 r + c 相同。所以用三个 set (cols / diag / anti) 记录已占用的值, 检查一个格子只要 3 次 O(1) 查询。做选择要往三个 set 各 add, 撤销要各 remove。

def solve_n_queens(n): res, path = [], [] # path[r] = 第 r 行的皇后放在第几列 cols, diag, anti = set(), set(), set() # 已占用的 列 / 主对角线 (r - c) / 副对角线 (r + c) def dfs(r): if r == n: # n 行都放好了 res.append(["." * c + "Q" + "." * (n - c - 1) for c in path]) return for c in range(n): if c in cols or (r - c) in diag or (r + c) in anti: continue # 剪枝: 同列 / 同一条 \ 对角线 / 同一条 / 对角线 cols.add(c); diag.add(r - c); anti.add(r + c) # 做选择: 三个 set + path path.append(c) dfs(r + 1) path.pop() # 撤销: 三个 set + path 全部还原 cols.remove(c); diag.remove(r - c); anti.remove(r + c) dfs(0) return res

Time O(n!) 上界 (第 r 行至多还有 n−r 列可选)。实际远小: n = 4 只访问 17 个节点 (4! = 24 个叶子位置); n = 8 访问 2057 个节点, 而 8! = 40320。Space O(n): path + 三个 set + 递归栈。

记:放置类约束题: 把每条约束写成一个 set (key = 它禁止的东西), 检查 O(1); 撤销时所有 set 同步还原。
