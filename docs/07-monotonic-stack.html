07 · Monotonic Stack / Queue

这篇讲什么

这一类题都在问同一件事的变形: 对每个元素, 找它右边 (或左边) 第一个比它大 (或小) 的元素。比如"要等几天才会更暖"、"这根柱子往左右能延伸多远"。

brute force 是每个元素都往右扫, 直到找到更大的, O(n²)。

Monotonic stack (单调栈) 是一个特殊的 stack (见 06): 栈里的元素从底到顶保持单调 (比如一直递减)。新元素来的时候, 把栈顶比它小的全部 pop 掉。神奇的地方在于: 被 pop 的那一刻, 正好就是它找到答案的那一刻。每个元素只进出一次, 所以是 O(n)。

如果窗口会滑动 (旧元素会过期), 就把 stack 换成两头都能 pop 的 deque, 叫 monotonic queue。

1. Daily Temperatures

题目在问什么

temperatures[i] 是第 i 天的温度。对每一天, 问: 要再等几天, 才会遇到一个更暖和的天? 如果之后都没有更暖的, 填 0。

换句话说: 对每个元素, 找它右边第一个比它大的元素, 返回下标之差。

看例子

Brute force

每一天 i, 从 i+1 开始往右扫, 遇到第一个更暖的就停。最坏 (温度一直下降) 每天都扫到最后, O(n²)。

浪费在哪: 看温度 75, 71, 69, 72。brute force 里, 71 往右扫看到 69、72; 69 往右扫又看到 72。72 被反复看了好几次。

Intuition: 让"还在等答案"的天排队, 来了一个暖的就一起结算

换个方向想: 不是每一天去找答案, 而是每来一个新的温度, 看看它能当谁的答案。

  1. 从左往右扫。还没找到更暖的那些天, 先放进一个 stack 里"等着"。
  2. 来了新的一天 x。栈顶的那一天如果比 x 冷, 那 x 就是它等的那个更暖的天! 结算它的答案, pop 掉。
  3. 继续看新的栈顶, 只要比 x 冷就一直 pop、一直结算。直到栈顶比 x 暖 (或者栈空了)。
  4. 最后把 x 自己 push 进去, 它也要开始等。

这样栈里的温度从底到顶一定是递减的 (比 x 冷的都被 pop 了, x 才放上去)。所以叫 monotonic stack。

为什么被 pop 的元素可以扔掉? 因为它已经找到答案了, 以后再也用不到。每个元素最多 push 一次、pop 一次, 总共 O(n)。

一个细节: 答案要的是"等几天", 所以栈里存下标, 不存温度。温度用 temperatures[下标] 去查。

算法

  1. ans = [0] * n, stack = [] (存下标)。
  2. i 从 0 到 n-1: 当栈不空且 T[stack[-1]] < T[i]: j = stack.pop(), ans[j] = i - j。
  3. stack.append(i)。
  4. 最后还在栈里的, 答案保持 0。

手动走一遍

复杂度

Time O(n): 每个下标最多 push 一次、pop 一次。Space O(n)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def daily_temperatures(T): ans = [0] * len(T) # 存 index (不存温度): 答案是 i - j, 需要位置 stack = [] for i, t in enumerate(T): while stack and T[stack[-1]] < t: # t 是栈顶那天等到的第一个更高温 j = stack.pop() ans[j] = i - j # 在 pop 时结算 j 的答案 stack.append(i) # 栈里剩下的天没等到更高温, ans 保持 0 return ans
def next_greater_brute(nums): # O(n^2) n = len(nums) ans = [-1] * n for i in range(n): for j in range(i + 1, n): # 每个 i 都从 i+1 重新往右扫 if nums[j] > nums[i]: ans[i] = nums[j] break return ans
def next_greater(nums): # O(n) ans = [-1] * len(nums) stack = [] # 存 index; 对应的值从底到顶递减 for i, x in enumerate(nums): # x 比栈顶大: x 就是栈顶的 next greater while stack and nums[stack[-1]] < x: # pop 的这一刻结算; 弹出的元素以后再也用不到 ans[stack.pop()] = x stack.append(i) # 栈里全是 "还没等到更大数" 的元素 return ans

记:找右边第一个更大的: 维护递减栈 (存下标)。新元素比栈顶大就 pop, pop 的那一刻就是栈顶找到答案的时候。

把第 1 题抽象一下: 递增栈还是递减栈

第 1 题的规律可以总结成两句:

  • 找更大的 → 维护递减栈 (来了一个大的, 就把比它小的 pop 掉)。找更小的 → 维护递增栈。
  • 右边的答案在 pop 的时候拿到 (pop 它的那个新元素就是答案)。左边的答案在 pop 完之后看栈顶 (新元素 push 之前, 栈顶就是它左边第一个更大 / 更小的)。

所以一次扫描可以同时拿到左右两边的答案, 第 3 题就要用到这一点。

代码: 一次扫描同时得到左边、右边第一个更小的
# 递增栈: 一次循环同时得到左右两个边界def nearest_smaller_both(nums): n = len(nums) left, right = [-1] * n, [n] * n # -1 / n 表示那一侧没有更小的 stack = [] for i, x in enumerate(nums): while stack and nums[stack[-1]] > x: right[stack.pop()] = i # 被 x pop: x 是它右边第一个更小的 # pop 完剩下的栈顶 = i 左边第一个 <= x 的 left[i] = stack[-1] if stack else -1 stack.append(i) return left, right

记:找更大用递减栈, 找更小用递增栈。右边的答案 pop 时拿, 左边的答案 push 前看栈顶。

2. Next Greater Element II

题目在问什么

和第 1 题一样找"右边第一个更大的数", 但数组是循环的: 最后一个元素后面接着第一个元素。没有更大的返回 -1。这题返回的是那个数的值, 不是距离。

看例子

Brute force

每个元素往后走 n-1 步 (用 % n 绕回开头), 找第一个更大的。O(n²)。

Intuition: 把数组走两遍

循环数组的常用技巧: 想象把数组复制一份接在后面, [1,2,1] 变成 [1,2,1,1,2,1]。在这个两倍长的数组上做第 1 题, 前 n 个元素的答案就是循环数组的答案。

不用真的复制: 循环 i 从 0 到 2n-1, 用 nums[i % n] 取值。第二圈的元素只负责"给别人当答案"(pop 别人), 不需要 push 自己, 因为它们的答案在第一圈已经处理过了。

算法

  1. ans = [-1] * n。i 从 0 到 2n-1, x = nums[i % n]。
  2. 当栈不空且 nums[stack[-1]] < x: ans[stack.pop()] = x。
  3. 如果 i < n, push i。

手动走一遍

复杂度

Time O(n), Space O(n)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def next_greater_elements(nums): n = len(nums) ans = [-1] * n stack = [] # 走 2 圈: 第 2 圈让右边没有的元素绕回去找 for i in range(2 * n): x = nums[i % n] # 用 i % n 取值, 不拷贝数组 while stack and nums[stack[-1]] < x: ans[stack.pop()] = x # 只在第 1 圈 push: 第 2 圈只负责结算 if i < n: stack.append(i) return ans

记:循环数组: 循环 2n 次, 用 i % n 取值; 第二圈只 pop 不 push。

3. Largest Rectangle in Histogram

题目在问什么

heights 是一排相邻的柱子, 每根宽 1。在这些柱子里面画一个矩形 (矩形不能超出柱子), 求最大面积。

看例子

关键观察: 一个矩形的高, 一定等于它覆盖的那些柱子里最矮的那根。

Brute force

枚举所有区间 [l, r], 找区间里最矮的柱子 h, 面积 = h × (r - l + 1)。O(n²) 个区间 (边扩边维护最小值)。

Intuition: 以每根柱子为"最矮", 它能延伸多宽?

换个枚举方式: 对每根柱子 i, 假设矩形的高就是 heights[i]。那么矩形可以往左右延伸, 直到碰到一根比它矮的柱子为止。

所以要知道: i 的左边第一个比它矮的在哪 (L), 右边第一个比它矮的在哪 (R)。宽度 = R - L - 1, 面积 = heights[i] × (R - L - 1)。

"左右第一个更小的" 正是上一节说的: 维护递增栈, 一次扫描同时拿到两边:

  • 新柱子 i 比栈顶矮时, pop 栈顶 top。i 就是 top 右边第一个比它矮的 (R = i)。
  • pop 之后的新栈顶, 就是 top 左边第一个比它矮的 (L = 新栈顶)。栈空了就是 L = -1。
  • 所以 pop 的那一刻, top 的面积就能算出来了。

最后在 heights 末尾加一根高度 0 的柱子 (哨兵)。它比所有柱子都矮, 会把栈里剩下的全部 pop 出来结算。

算法

  1. heights.append(0), stack = [], best = 0。
  2. i 从 0 到 n: 当栈不空且 heights[stack[-1]] > heights[i]: h = heights[stack.pop()]; L = stack[-1] if stack else -1; best = max(best, h × (i - L - 1))。
  3. push i。

手动走一遍

变体 Maximal Rectangle (0/1 矩阵里最大的全 1 矩形): 一行一行往下, 把每一列"连续的 1 有多高"当成柱子, 每一行都做一次这道题。

复杂度

Time O(n), Space O(n)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def largest_rectangle_area(heights): # 哨兵 0: 最后一步把栈里剩下的柱子全部 pop 出来 heights = heights + [0] stack = [] # 存 index; heights 从底到顶递增 best = 0 for i, h in enumerate(heights): # h 比栈顶矮 -> 栈顶的右边界就是 i while stack and heights[stack[-1]] > h: height = heights[stack.pop()] # pop 后的新栈顶 = 左边界 (空: -1) left = stack[-1] if stack else -1 width = i - left - 1 # 左右边界之间 (不含边界) 的柱子数 best = max(best, height * width) # 相等的柱子不 pop: 后面那根会把宽度补全 stack.append(i) return best
def maximal_rectangle(matrix): # 逐行套用 largest_rectangle_area if not matrix: return 0 heights = [0] * len(matrix[0]) best = 0 for row in matrix: for j, c in enumerate(row): # 这一列往上连续 1 的个数 heights[j] = heights[j] + 1 if c == "1" else 0 # 这一行就是一个直方图 best = max(best, largest_rectangle_area(heights)) return best

记:以每个元素为最小值能延伸多远: 递增栈, pop 时右边界 = 当前 i, 左边界 = 新栈顶。末尾加哨兵 0。

4. Remove K Digits

题目在问什么

num 是一个用字符串表示的非负整数。从中删掉 k 位数字, 剩下的数字保持原来的顺序, 让得到的数最小。结果去掉开头的 0, 全删光就返回 "0"。

看例子

Brute force

枚举所有删法 (从 n 位里选 k 位删), 比较大小。组合数 C(n, k), 指数级。

稍好一点的 greedy: 每次删一位, 试所有位置, 选结果最小的, 重复 k 次。O(n·k)。

Intuition: 高位越小越好

剩下的位数是固定的 (n - k 位), 所以比较大小就是从最高位开始比。要让结果最小, 高位要尽量小。

看 "1432" 删 1 位: 从左往右, 第一个"比它后面那位大"的数字是 4 (4 > 3)。删掉它, 3 就补到了它的位置, 高位变小了。删 4 得到 132, 是最小的。

推广: 从左往右扫, 维护一个递增栈。新数字 d 比栈顶小, 而且还有删除额度 (k > 0), 就 pop 栈顶 (删掉它), k 减 1。然后 push d。

这次栈里留下的东西就是答案, 不是用来查别人的。扫完之后 k 还没用完, 就从末尾删 (此时栈是递增的, 末尾最大)。

算法

  1. 对每个数字 d: 当 k > 0 且栈顶 > d: pop, k 减 1。然后 push d。
  2. 如果 k 还有剩, 删掉栈末尾的 k 个。
  3. 拼起来, 去掉开头的 0; 空了返回 "0"。

手动走一遍

复杂度

Time O(n), Space O(n)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
def remove_k_digits(num, k): # 栈就是答案本身 (数字字符), 从底到顶非递减 stack = [] for dig in num: # 前一位比当前大: 删前一位, 高位变小 while k and stack and stack[-1] > dig: stack.pop() k -= 1 # pop 一次 = 花掉 1 个删除名额 stack.append(dig) # 整串都是递增: 名额没花完, 删最末尾的 k 位 if k: stack = stack[:-k] return "".join(stack).lstrip("0") or "0" # 去前导零; 全删光时返回 "0"

记:删 / 选 k 个让结果的字典序最小 (顺序不能变): greedy + 递增栈, 栈就是答案, pop 次数受 k 限制。

5. Sliding Window Maximum

题目在问什么

一个长度为 k 的窗口从数组最左边开始, 每次往右滑一格。输出每个位置上窗口里的最大值。一共 n - k + 1 个答案。

看例子

Brute force

每个窗口都扫一遍求 max, O(n·k)。浪费: 相邻两个窗口有 k - 1 个元素是一样的, 却重新比较。

用 heap (见 09) 可以做到 O(n log n), 但要处理"堆顶已经滑出窗口"的情况。

Intuition: 又小又早过期的元素, 永远不会是最大值

看窗口里的两个元素 a 和 b, a 在 b 的左边, 而且 a ≤ b。那么从现在开始, 只要 a 还在窗口里, b 也一定在 (b 更晚离开), 而 b 更大。所以 a 永远不可能是最大值, 可以直接扔掉。

于是维护一个队列, 只保留"有可能成为最大值"的元素。扔掉之后, 剩下的从队头到队尾一定是递减的, 队头就是当前窗口的最大值。

和前面的 stack 不同, 这里元素会从两头离开:

  • 队尾: 新元素 x 来了, 队尾比 x 小 (或相等) 的都 pop 掉 (它们又小又早过期)。这和 monotonic stack 一样。
  • 队头: 队头的下标如果已经滑出窗口了, 也要 pop 掉。这是 stack 做不到的, 所以用 deque。

算法

  1. dq = deque() (存下标)。
  2. i 从 0 到 n-1: 如果 dq[0] <= i - k (队头过期), popleft。
  3. 当 dq 不空且 nums[dq[-1]] <= nums[i]: pop。然后 append i。
  4. 如果 i >= k - 1 (窗口满了), 输出 nums[dq[0]]。

手动走一遍

复杂度

Time O(n): 每个下标最多进出 deque 一次。Space O(k)。

参考代码 (先自己按上面的算法步骤写, 写不出来再展开)
from collections import dequedef max_sliding_window(nums, k): # 存 index; 值从头到尾递减, dq[0] = 窗口最大 dq = deque() ans = [] for i, x in enumerate(nums): # 队头已滑出窗口 [i-k+1, i]: 过期, 从头部出队 if dq and dq[0] <= i - k: dq.popleft() # 队尾比 x 小: 比 x 早过期又更小, 永远当不了最大 while dq and nums[dq[-1]] <= x: dq.pop() dq.append(i) if i >= k - 1: # 窗口满了才有答案 ans.append(nums[dq[0]]) # 队头 = 窗口最大, O(1) return ans

记:固定长度窗口的最大 / 最小值: monotonic deque。队尾 pop 掉比新元素小的, 队头 pop 掉过期的, 队头就是答案。

6. 识别信号: 看到什么, 就想到 monotonic stack / queue

题目特征做法complexity
每个元素找右边 / 左边第一个更大 / 更小的数或距离单调栈, 存下标, pop 时结算O(n²) → O(n)
数组是循环的循环 2n 次, i % n, 第二圈只 popO(n²) → O(n)
以每个元素为最大 / 最小值能延伸多远 (矩形面积)单调栈, pop 时右边界 = i, 左边界 = 新栈顶O(n²) → O(n)
0/1 矩阵里最大的全 1 矩形逐行变成柱子, 套第 3 题O(rows·cols)
删 / 选 k 个使结果最小, 顺序不变greedy + 单调栈, 栈就是答案指数 → O(n)
固定长度窗口的 max / min单调 deque: 队头过期出, 队尾小的出O(n·k) → O(n)

选方向的口诀: 找更大 → 递减栈; 找更小 → 递增栈。窗口会过期 → deque。
